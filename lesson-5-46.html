Для тех, кто хочет знать больше: Целая и дробная части числа

Урок 46 • Глава V, §14

📖 Материал по учебнику «Алгебра 8 класс» (§ 14, п. 46). Навигация — внизу страницы, полный список уроков — на главной странице курса.

🧠 Изучение нового материала

👋 Привет! В повседневной жизни мы постоянно «отбрасываем» дробную часть: «2 часа 40 минут — это 2 полных часа», «3,5 метра ткани — это 3 полных метра». Сегодня дадим этим интуитивным действиям строгое математическое определение и построим графики двух новых функций.

Определение.
Целой частью числа $x$ называется наибольшее целое число, не превосходящее $x$. Обозначение: $[x]$ (читают: «целая часть икс»).

Дробной частью числа $x$ называется разность между числом и его целой частью. Обозначение: $\{x\}$.
Таким образом, $\{x\} = x - [x]$.
Примеры целой части:
$[5{,}7] = 5$ (наибольшее целое, не превосходящее 5,7);
$[10] = 10$; $[-7] = -7$; $[-8{,}2] = -9$ — внимание: −9 не превосходит −8,2!

Примеры дробной части:
$\{12{,}4\} = 12{,}4 - 12 = 0{,}4$;
$\{-3{,}5\} = -3{,}5 - [-3{,}5] = -3{,}5 - (-4) = 0{,}5$;
$\{7\} = 7 - 7 = 0$.
Свойства:
• $0 \le \{x\} < 1$ для любого числа $x$;
• $x = [x] + \{x\}$ — любое число раскладывается на целую и дробную части;
• $[x] \le x < [x] + 1$.

📈 График функции $y = [x]$

Если $0 \le x < 1$, то $[x] = 0$ — на промежутке $[0;\ 1)$ график совпадает с прямой $y = 0$. Но так как $[1] = 1$, при $x = 1$ график совершает «скачок». Если $1 \le x < 2$, то $[x] = 1$, и т. д. Рассматривая последовательно все промежутки, получаем график, состоящий из «ступенек»:

Рис. 1. График функции y = [x] — «ступеньки» (закрашенные точки входят, светлые — нет).

📈 График функции $y = \{x\}$

Воспользуемся определением: $\{x\} = x - [x]$. Если $0 \le x < 1$, то $[x] = 0$, значит, $\{x\} = x$ — график совпадает с прямой $y = x$. Если $1 \le x < 2$, то $[x] = 1$, значит, $\{x\} = x - 1$ — график совпадает с прямой $y = x - 1$, и т. д. Получаем «пилообразный» график:

Рис. 2. График функции y = {x} — «пила».

🛠 Закрепление

Реши задачи, а затем нажми на них, чтобы проверить себя. Помни: целая часть — наибольшее целое, не превосходящее число (для отрицательных — не ошибись в знаке!).

🟢 База №1137. Найди [a], если a = 4,7; 98; −0,01

Решение:

$[4{,}7] = 4$; $[98] = 98$; $[-0{,}01] = -1$ (так как −1 — наибольшее целое, не превосходящее −0,01). ✅

🟢 База №1138. Найди {c}, если c = 5; 4; −0,95; 0; 1,17

Решение:

$\{5\} = 0$; $\{4\} = 0$; $\{-0{,}95\} = -0{,}95 - (-1) = 0{,}05$; $\{0\} = 0$; $\{1{,}17\} = 0{,}17$. ✅

🟢 База №1139. Найди целую и дробную части числа π

Решение:

$\pi \approx 3{,}14159\ldots$: $[\pi] = 3$, $\{\pi\} = \pi - 3 \approx 0{,}14159$. ✅

🔵 Средний №1140. Известно, что x = 2,7. Найди 2[x]; [2x]; [−2x]

Решение:

$2[x] = 2 \cdot 2 = 4$;

$[2x] = [5{,}4] = 5$;

$[-2x] = [-5{,}4] = -6$ (наибольшее целое, не превосходящее −5,4). ✅

🔵 Средний №1141. Известно, что x = −4,8. Найди {3x}; {−3x}

Решение:

$3x = -14{,}4$; $[-14{,}4] = -15$; $\{3x\} = -14{,}4 - (-15) = 0{,}6$.

$-3x = 14{,}4$; $[14{,}4] = 14$; $\{-3x\} = 14{,}4 - 14 = 0{,}4$. ✅

🟣 Продвинутый №1142. Построй график функции y = [2x]

Решение:

1. Функция постоянна на промежутках, где $2x$ попадает в один и тот же «коридор» целых значений.

2. $[2x] = 0$ при $0 \le 2x < 1$, то есть при $0 \le x < 0{,}5$; $[2x] = 1$ при $0{,}5 \le x < 1$; $[2x] = 2$ при $1 \le x < 1{,}5$, и т. д.

3. «Ступеньки» вдвое ýже, чем у $y = [x]$: ширина каждой равна 0,5. ✅

🏗 Практика: задача из реальной жизни (STEAM)

🚀 IT и программирование: В языках программирования целой части соответствует функция Math.floor(x) (округление вниз), а дробной части — выражение x - Math.floor(x). Оператор остатка от деления % тоже связан с дробной частью: остаток от деления $a$ на $b$ равен $b \cdot \{a/b\}$.

Вопрос: a) Сколько полных недель в 100 днях? б) Часы показывают 14:50 — какая часть часа «прожита»? в) Мобильный тариф берёт 1 ₽ за каждую начатую минуту. Сколько минут надо оплатить за разговор длительностью 3 мин 40 с?

Показать пошаговое решение

Решение:

а) $[100/7] = [14{,}28\ldots] = 14$ полных недель.

б) 14:50 — это $14 + \dfrac{50}{60} = 14 + \dfrac{5}{6}$ часа. Дробная часть: $\left\{\dfrac{5}{6}\right\} = \dfrac{5}{6} \approx 0{,}83$ — «прожито» 5/6 часа.

в) 3 мин 40 с = $3 + \dfrac{40}{60} = 3\frac{2}{3}$ мин. Начатые минуты: $[3\frac{2}{3}] + 1 = 3 + 1 = 4$ минуты (3 полные + 1 начатая). ✅

💡 Вывод: целая и дробная части — не просто абстрактные функции, а инструмент моделирования реальных процессов с дискретным «шагом».

📝 Итоги урока

Главное запомнить:

  • $[x]$ — целая часть: наибольшее целое число, не превосходящее $x$ (для отрицательных чисел двигаемся «влево»: $[-0{,}01] = -1$).
  • $\{x\}$ — дробная часть: $\{x\} = x - [x]$, причём $0 \le \{x\} < 1$.
  • Любое число раскладывается: $x = [x] + \{x\}$.
  • График $y = [x]$ — «ступеньки»; график $y = \{x\}$ — «пила».
  • Целая часть применяется везде, где считают «полные» единицы или «начатые» промежутки (тарифы, время, измерения).

💡 Методическая подсказка для учителя

Главная «ловушка» — целая часть отрицательных чисел: ученики часто пишут $[-0{,}01] = 0$ или $[-8{,}2] = -8$, забывая, что нужно наибольшее целое, не превосходящее данное число. Проговорите правило: «двигаемся по числовой прямой влево до ближайшего целого». Полезно построить графики $y = [x]$ и $y = \{x\}$ на доске по точкам: обратите внимание на «скачки» и на то, какая из граничных точек «закрашена», а какая нет. Связь с программированием (Math.floor, %) делает тему живой для интересующихся IT.
