Разложение квадратного трёхчлена на множители

Урок 25 • Глава 3, §8

📖 Материал по учебнику «Алгебра 8 класс» (§ 8, п. 25). Навигация — внизу страницы, полный список уроков — на главной странице курса.

🧠 Изучение нового материала

👋 Привет! На прошлом уроке мы научились находить корни квадратного трёхчлена. Сегодня мы сделаем следующий логический шаг: научимся раскладывать его на множители. Это суперсила, которая позволяет легко сокращать сложные алгебраические дроби!

ТЕОРЕМА:
Если x₁ и x₂ — корни квадратного трёхчлена ax² + bx + c, то
ax² + bx + c = a(x - x₁)(x - x₂)

💡 Как это работает (доказательство идеи):
1. Вынесем старший коэффициент a за скобки: a(x² + (b/a)x + c/a).
2. По теореме Виета: сумма корней x₁ + x₂ = -b/a, а произведение x₁ · x₂ = c/a.
3. Подставим это в скобку: x² - (x₁ + x₂)x + x₁x₂.
4. Сгруппируем: x(x - x₁) - x₂(x - x₁) = (x - x₁)(x - x₂).
5. Не забываем вернуть множитель a, который мы вынесли в начале!

Рис. 1. График трёхчлена. Красные точки показывают, что при x=1 и x=5 значение функции равно 0. Именно эти числа попадают в формулу разложения.

Важное правило:
Если дискриминант D = 0, трёхчлен имеет два равных корня (x₁ = x₂). В этом случае формула превращается в:
ax² + bx + c = a(x - x₁)²

Если D < 0, квадратный трёхчлен нельзя разложить на множители первой степени с действительными коэффициентами.

🛠 Закрепление

Реши задачи, а затем нажми на них, чтобы проверить себя. Помни: всегда проверяй ответ обратным раскрытием скобок!

🟢 База №617(а). Разложи на множители: 3x² - 24x + 21

Решение:

1. Сначала вынесем общий множитель 3 за скобки, чтобы упростить вычисления:
3(x² - 8x + 7).

2. Найдём корни трёхчлена в скобках: x² - 8x + 7 = 0.
По теореме Виета (или через D): x₁ = 1, x₂ = 7.

3. Применяем формулу разложения a(x - x₁)(x - x₂), где a = 3:
3(x - 1)(x - 7).

Проверка раскрытием: 3(x² - 7x - x + 7) = 3(x² - 8x + 7) = 3x² - 24x + 21. Всё верно! ✅

Ответ: 3(x - 1)(x - 7).

🔵 Средний №618(в). Разложи на множители: 16a² + 24a + 9

Решение:

1. Найдём дискриминант: D = 24² - 4 · 16 · 9 = 576 - 576 = 0.
Значит, у трёхчлена один (кратный) корень.

2. Находим корень: a = -24 / (2 · 16) = -24 / 32 = -3/4.

3. Применяем формулу для D = 0: a(x - x₁)².
16(a - (-3/4))² = 16(a + 3/4)².

4. Чтобы избавиться от дроби, внесём 16 внутрь квадрата как 4²:
(4(a + 3/4))² = (4a + 3)².

Проверка: (4a + 3)² = 16a² + 2·4a·3 + 9 = 16a² + 24a + 9. Верно! ✅

Ответ: (4a + 3)².

🟣 Продвинутый №624(а). Сократи дробь: (4x + 4) / (3x² + 2x - 1)

Решение:

1. Укажем ОДЗ: знаменатель не равен нулю. 3x² + 2x - 1 ≠ 0.
Найдём корни знаменателя: D = 2² - 4 · 3 · (-1) = 4 + 12 = 16.
x = (-2 ± 4) / 6. Корни: x₁ = 1/3, x₂ = -1.
ОДЗ: x ≠ 1/3, x ≠ -1.

2. Разложим знаменатель на множители по теореме:
3x² + 2x - 1 = 3(x - 1/3)(x - (-1)) = 3(x - 1/3)(x + 1).
Внесём 3 в первую скобку: (3x - 1)(x + 1).

3. Разложим числитель, вынеся 4 за скобки: 4(x + 1).

4. Запишем дробь и сократим на общий множитель (x + 1):
[4(x + 1)] / [(3x - 1)(x + 1)] = 4 / (3x - 1).

Ответ: 4 / (3x - 1) при условии x ≠ -1 и x ≠ 1/3.

🏗 Практика: зачем это нужно в реальной жизни?

🚀 Инженерия и оптимизация: Представь, что ты программист, пишущий физический движок для игры. Тебе нужно вычислить время столкновения объекта с землёй. Уравнение движения часто сводится к виду at² + bt + c = 0.

Разложение на множители a(t - t₁)(t - t₂) = 0 позволяет компьютеру мгновенно найти моменты времени t₁ и t₂, когда высота равна нулю (столкновение), без использования ресурсоёмких формул с извлечением корня на каждом кадре анимации. Это основа оптимизации кода!

📝 Итоги урока

Главное запомнить:

  • Формула разложения: ax² + bx + c = a(x - x₁)(x - x₂).
  • Множитель a (старший коэффициент) забывать нельзя! Это самая частая ошибка.
  • Если D = 0, разложение выглядит как a(x - x₁)².
  • Если D < 0, разложить на множители первой степени невозможно.
  • При сокращении дробей всегда сначала указывай ОДЗ, а потом сокращай.

💡 Методическая подсказка для учителя

При отработке навыка ученики часто совершают две системные ошибки: 1) забывают умножить итоговое выражение на старший коэффициент a; 2) при внесении a внутрь скобки для избавления от дроби (как в №618) забывают, что при внесении в квадрат скобки число возводится в квадрат (16 вносится как 4). Рекомендуется давать задание «Найди ошибку» с заранее подготовленными неверными решениями, содержащими именно эти ловушки.
