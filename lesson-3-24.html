Квадратный трёхчлен и его корни

Урок 24 • Глава 3, §8

📖 Материал по учебнику «Алгебра 8 класс» (§ 8, п. 24). Навигация — внизу страницы, полный список уроков — на главной странице курса.

🧠 Изучение нового материала

👋 Привет! Сегодня мы познакомимся с объектом, который описывает всё: от траектории брошенного мяча до максимальной площади участка. Это квадратный трёхчлен.

Определение: Квадратным трёхчленом называется многочлен вида
ax² + bx + c,
где x — переменная, a, b, c — некоторые числа, причём a ≠ 0.

Число a называют старшим коэффициентом, а число c — свободным членом. Квадратным трёхчленом также считаются выражения, где b=0 или c=0 (или оба сразу), главное, чтобы a ≠ 0 и степень была равна 2.

💡 Связь с уравнениями: Чтобы найти корни квадратного трёхчлена, нужно решить квадратное уравнение ax² + bx + c = 0. Количество корней зависит от дискриминанта D = b² - 4ac:

  • Если D > 0, трёхчлен имеет два корня.
  • Если D = 0, трёхчлен имеет один корень.
  • Если D < 0, трёхчлен не имеет действительных корней.

Рис. 1. График квадратного трёхчлена. Красные точки — корни (пересечение с осью x), жёлтая точка — вершина параболы. Построено строго по координатам формулы.

🛠 Выделение квадрата двучлена

Иногда квадратный трёхчлен удобно представить в виде a(x - m)² + n. Это называется выделением квадрата двучлена. Этот приём помогает находить наименьшее или наибольшее значение выражения.

Пример: Выделим квадрат двучлена из трёхчлена 3x² - 36x + 140.

Шаг 1. Вынесем старший коэффициент 3 за скобки в первых двух слагаемых:
3(x² - 12x) + 140

Шаг 2. Представим -12x как -2 · 6 · x. Чтобы получить полный квадрат (x - 6)², нам не хватает +36. Добавим и вычтем 36 внутри скобок:
3(x² - 2 · 6 · x + 36 - 36) + 140

Шаг 3. Свернём полный квадрат и упростим:
3((x - 6)² - 36) + 140 = 3(x - 6)² - 108 + 140 = 3(x - 6)² + 32.

Теперь видно, что наименьшее значение этого трёхчлена равно 32 (оно достигается при x = 6, так как 3(x - 6)² ≥ 0).

🛠 Закрепление

Реши задачи, а затем нажми на них, чтобы проверить себя. Не забывай проверять ответы подстановкой!

🟢 База №602(а). Найди корни квадратного трёхчлена: x² + x - 6

Решение: Приравняем трёхчлен к нулю: x² + x - 6 = 0.

Найдём дискриминант: D = b² - 4ac = 1² - 4 · 1 · (-6) = 1 + 24 = 25.

Так как D > 0, уравнение имеет два корня:

x = (-1 ± √25) / 2 = (-1 ± 5) / 2.

x₁ = (-1 + 5) / 2 = 4 / 2 = 2.

x₂ = (-1 - 5) / 2 = -6 / 2 = -3.

Проверка подстановкой:
При x = 2: 2² + 2 - 6 = 4 + 2 - 6 = 0. Верно! ✅
При x = -3: (-3)² + (-3) - 6 = 9 - 3 - 6 = 0. Верно! ✅

Ответ: 2; -3.

🔵 Средний №607(а). Выдели квадрат двучлена из трёхчлена: x² - 6x - 2

Решение:

1. Коэффициент при x² равен 1, выносить нечего. Работаем со всем выражением.

2. Представим -6x как -2 · 3 · x. Нам не хватает +3² = 9 для полного квадрата.

3. Добавим и вычтем 9: x² - 6x + 9 - 9 - 2.

4. Сворачиваем полный квадрат: (x - 3)² - 11.

Ответ: (x - 3)² - 11.

🟣 Продвинутый №613. Прямоугольный треугольник: сумма катетов равна 6 см. При каких длинах катетов площадь треугольника будет наибольшей? Найди эту площадь.

Решение:

1. Обозначим длину одного катета через x см. Тогда длина второго катета равна (6 - x) см.

2. Площадь прямоугольного треугольника равна половине произведения катетов:
S = ½ · x · (6 - x) = ½(6x - x²) = -½x² + 3x.

3. Выделим квадрат двучлена в выражении для площади:
S = -½(x² - 6x) = -½(x² - 6x + 9 - 9) = -½((x - 3)² - 9) = -½(x - 3)² + 4,5.

4. Поскольку -½(x - 3)² ≤ 0 при любом x, наибольшее значение выражение принимает, когда -½(x - 3)² = 0, то есть при x = 3.

5. Если x = 3, то второй катет тоже равен 6 - 3 = 3 см. Треугольник является равнобедренным.

Ответ: наибольшей площади (4,5 см²) треугольник достигает, когда оба катета равны 3 см.

🏗 Практика: задача из реальной жизни

🚀 Физика и спорт: Стрела выпущена вертикально вверх из лука. Высота h (в метрах), на которой находится стрела через время t (в секундах), приближённо описывается формулой:

h(t) = -5t² + 50t + 20

Вопрос: Какой наибольшей высоты достигнет стрела и через какое время это произойдёт?

Показать пошаговое решение

Решение: Нам нужно найти наибольшее значение квадратного трёхчлена h(t) = -5t² + 50t + 20. Для этого выделим квадрат двучлена.

1. Вынесем -5 за скобки в первых двух слагаемых:
h(t) = -5(t² - 10t) + 20.

2. Добавим и вычтем 25 (так как (-10/2)² = 25) внутри скобок:
h(t) = -5(t² - 10t + 25 - 25) + 20.

3. Свернём полный квадрат и раскроем внешние скобки:
h(t) = -5((t - 5)² - 25) + 20 = -5(t - 5)² + 125 + 20 = -5(t - 5)² + 145.

4. Так как -5(t - 5)² ≤ 0 при любом t, максимальное значение высоты равно 145 и достигается оно при t = 5.

Проверка: h(5) = -5(25) + 50(5) + 20 = -125 + 250 + 20 = 145. Всё верно! ✅

Ответ: стрела достигнет наибольшей высоты 145 метров через 5 секунд после выстрела.

📝 Итоги урока

Главное запомнить:

  • Квадратный трёхчлен имеет вид ax² + bx + c, где a ≠ 0.
  • Корни трёхчлена — это корни уравнения ax² + bx + c = 0. Их количество определяет дискриминант D.
  • Приём выделения квадрата двучлена позволяет переписать трёхчлен в виде a(x - m)² + n, что удобно для поиска наибольшего или наименьшего значения.
  • При преобразованиях нельзя сокращать слагаемые, можно сокращать только множители!

💡 Методическая подсказка для учителя

При объяснении выделения квадрата двучлена используйте визуальную аналогию с «достраиванием» квадрата из геометрических фигур (алгебраические плитки). Обратите внимание учеников на типичную ошибку: при вынесении отрицательного коэффициента за скобки знаки внутри скобок меняются, и вычитаемое число (например, -25) при раскрытии скобок даст плюс, что часто вызывает путаницу. Требуйте обязательной проверки ответа подстановкой в исходное выражение.
