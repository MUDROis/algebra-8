🧠 Изучение нового материала

👋 Привет! Мы научились решать дробные рациональные уравнения. Но зачем это нужно? Оказывается, с их помощью можно решать реальные задачи из физики, экономики и повседневной жизни: о движении, совместной работе или смесях!

Главный секрет успеха:
Текстовая задача → Математическая модель (уравнение) → Решение → Проверка на физический смысл!

🛠 Универсальный алгоритм решения

Шаг 1. Обозначь искомую величину (или удобную для счёта) через x.

Шаг 2. Вырази все остальные величины задачи через x (лучше всего составлять таблицу: «Было / Стало» или «Скорость / Время / Расстояние»).

Шаг 3. Составь уравнение, используя главное условие задачи (например, равенство времени или разность количеств).

Шаг 4. Найди ОДЗ и реши полученное дробное рациональное уравнение.

Шаг 5. Критически важный шаг: Отбрось корни, которые не входят в ОДЗ или не имеют физического смысла (например, отрицательное время, скорость меньше скорости течения, отрицательная масса).

📖 Разбор примера из учебника (Задача о сплаве)

«Сплав меди и цинка, содержащий 10 кг цинка, дополнили 20 кг цинка. В результате содержание меди в сплаве уменьшилось на 25%. Какова была первоначальная масса сплава?»

Решение:
1. Пусть x (кг) — первоначальная масса сплава. Тогда меди в нём было (x - 10) кг.
2. Первоначальное содержание меди: (x - 10) / x
3. Новая масса сплава: (x + 20) кг. Масса меди не изменилась: (x - 10) кг.
4. Новое содержание меди: (x - 10) / (x + 20)
5. Условие: содержание уменьшилось на 25% (то есть на 1/4). Составляем уравнение:
(x - 10) / x - (x - 10) / (x + 20) = 1/4

6. ОДЗ: x ≠ 0, x ≠ -20. Физический смысл: x > 10 (так как цинка уже 10 кг).
7. Умножим на 4x(x + 20):
4(x + 20)(x - 10) - 4x(x - 10) = x(x + 20)
4(x² + 10x - 200) - (4x² - 40x) = x² + 20x
4x² + 40x - 800 - 4x² + 40x = x² + 20x
80x - 800 = x² + 20x
x² - 60x + 800 = 0

8. По теореме Виета: x₁ = 20, x₂ = 40.
9. Проверка смысла: Оба корня больше 10. Проверим подстановкой:
• Если x = 20: было 10/20 = 50% меди. Стало 10/40 = 25% меди. Разница 25%. ✅
• Если x = 40: было 30/40 = 75% меди. Стало 30/60 = 50% меди. Разница 25%. ✅
Ответ: 20 кг или 40 кг.

🛠 Закрепление

Реши задачи, а затем нажми на них, чтобы проверить себя. Помни: сначала определяй, что ты обозначаешь за x!

🟢 База №654. Задача о билетах в театр

«Андрей купил билеты в театр «Надежда» на 240 р. Если бы он потратил эти деньги на билеты в театр «Удача», то смог бы купить на 4 билета больше, так как они были на 5 р. дешевле. Сколько стоил билет в театр «Надежда»?»

Решение:

1. Пусть x (р.) — цена билета в «Надежду». Тогда цена билета в «Удачу»: (x - 5) р.

2. Количество билетов в «Надежду»: 240/x. В «Удачу»: 240/(x - 5).

3. Уравнение (разность количеств равна 4):
240/(x - 5) - 240/x = 4

4. ОДЗ: x ≠ 0, x ≠ 5. Физический смысл: x > 5.

5. Разделим обе части на 4 для упрощения:
60/(x - 5) - 60/x = 1

6. Умножим на x(x - 5):
60x - 60(x - 5) = x(x - 5)
60x - 60x + 300 = x² - 5x
x² - 5x - 300 = 0

7. По теореме Виета: x₁ = 20, x₂ = -15.

8. Проверка смысла: x = -15 не подходит (цена не может быть отрицательной). x = 20 подходит.

Проверка: 240/20 = 12 билетов. Цена «Удачи» = 15 р. 240/15 = 16 билетов. 16 - 12 = 4. Всё верно! ✅

Ответ: 20 рублей.

🔵 Средний №658. Задача о движении по реке и озеру

«Турист прошел на лодке против течения реки 6 км и по озеру 15 км, затратив на путь по озеру на 1 ч больше, чем на путь по реке. Скорость течения реки равна 2 км/ч. Найдите скорость лодки при движении по озеру.»

Решение:

1. Пусть x (км/ч) — скорость лодки по озеру (в стоячей воде). Тогда скорость против течения: (x - 2) км/ч.

2. Время по озеру: 15/x ч. Время против течения: 6/(x - 2) ч.

3. Уравнение (время по озеру на 1 ч больше):
15/x - 6/(x - 2) = 1

4. ОДЗ: x ≠ 0, x ≠ 2. Физический смысл: x > 2.

5. Умножим на x(x - 2):
15(x - 2) - 6x = x(x - 2)
15x - 30 - 6x = x² - 2x
9x - 30 = x² - 2x
x² - 11x + 30 = 0

6. По теореме Виета: x₁ = 5, x₂ = 6.

7. Проверка смысла: Оба корня больше 2. Проверим оба:
• Если x = 5: по озеру 15/5 = 3 ч. Против течения 6/(5-2) = 2 ч. 3 - 2 = 1 ч. ✅
• Если x = 6: по озеру 15/6 = 2.5 ч. Против течения 6/(6-2) = 1.5 ч. 2.5 - 1.5 = 1 ч. ✅

Ответ: 5 км/ч или 6 км/ч. (Задача имеет два допустимых решения!)

🟣 Продвинутый №663. Задача о совместной работе

«При совместной работе двух кранов разгрузку баржи закончили за 6 ч. Сколько времени потребовалось бы каждому крану отдельно для разгрузки баржи, если известно, что первому крану для этого требуется на 5 ч больше, чем второму?»

Решение:

1. Пусть x (ч) — время работы второго крана. Тогда время первого крана: (x + 5) ч.

2. Производительность (часть работы в час): второго — 1/x, первого — 1/(x + 5).

3. Совместная производительность: 1/6. Уравнение:
1/x + 1/(x + 5) = 1/6

4. ОДЗ: x ≠ 0, x ≠ -5. Физический смысл: x > 0.

5. Умножим на 6x(x + 5):
6(x + 5) + 6x = x(x + 5)
6x + 30 + 6x = x² + 5x
12x + 30 = x² + 5x
x² - 7x - 30 = 0

6. По теореме Виета: x₁ = 10, x₂ = -3.

7. Проверка смысла: x = -3 не подходит (время не может быть отрицательным). x = 10 подходит.

8. Если второй кран работает 10 ч, то первый: 10 + 5 = 15 ч.

Проверка: 1/10 + 1/15 = 3/30 + 2/30 = 5/30 = 1/6. Всё верно! ✅

Ответ: 15 часов и 10 часов.

🏗 Практика: задача из реальной жизни (STEAM)

🚀 IT и 3D-печать: Два 3D-принтера разной мощности печатают партию деталей. Работая вместе, они справляются с партией за 2 часа. Если бы работал только первый принтер, ему понадобилось бы на 3 часа больше времени, чем второму. За какое время изготовит партию каждый принтер по отдельности?

(Подсказка: это вариация задачи №664. Работай с производительностью, а не со временем!)

Показать пошаговое решение

Решение:

1. Пусть x (ч) — время, за которое второй принтер печатает всю партию. Тогда первый печатает её за (x + 3) ч.

2. Производительность второго: 1/x (части партии в час). Производительность первого: 1/(x + 3).

3. Вместе за час они печатают 1/2 всей партии. Составляем уравнение:
1/x + 1/(x + 3) = 1/2

4. ОДЗ: x ≠ 0, x ≠ -3. Физический смысл: x > 0.

5. Умножим обе части на 2x(x + 3):
2(x + 3) + 2x = x(x + 3)
2x + 6 + 2x = x² + 3x
x² - x - 6 = 0

6. По теореме Виета: x₁ = 3, x₂ = -2.

7. Проверка смысла: x = -2 не подходит (время не может быть отрицательным). Подходит x = 3.

8. Второй принтер печатает партию за 3 ч, а первый — за 3 + 3 = 6 ч.

Проверка: 1/3 + 1/6 = 2/6 + 1/6 = 3/6 = 1/2. Вместе — ровно за 2 часа. Всё верно! ✅

Ответ: первый принтер — за 6 часов, второй — за 3 часа.

📝 Итоги урока

Главное запомнить:

  • При решении задач всегда начинай с обозначения переменной и составления таблицы величин.
  • Дробные уравнения возникают, когда мы связываем величины через формулы (например, t = S/v).
  • ОДЗ + Физический смысл — это фильтр, который отсеивает математически верные, но жизненно невозможные ответы (отрицательное время, скорость меньше течения).
  • Иногда задача имеет два допустимых ответа (как в задаче о туристе). Не спеши отбрасывать второй корень без проверки!

💡 Методическая подсказка для учителя

Самая частая ошибка учеников на этом этапе — составление уравнения «наугад» без таблицы. Требуйте от учеников рисовать мини-таблицу (Величина | Было | Стало) перед записью уравнения. Также обращайте внимание на единицы измерения: если время дано в минутах, а скорость в км/ч, необходимо привести всё к согласованным единицам (минуты — в часы). Обсуждение задачи с двумя корнями (№658) — отличный момент для развития критического мышления.
