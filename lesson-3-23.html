🧠 Блок 1. Изучение

🪝 Разминка: уравнение с секретом

Реши простое приведённое квадратное уравнение x² − 7x + 10 = 0 — и ты увидишь нечто любопытное. Используй формулу корней из урока 21.

Реши уравнение и посмотри на корни
Шаг 1: Коэффициенты: a = 1, b = −7, c = 10. Дискриминант: D = (−7)² − 4·1·10 = 49 − 40 = 9. D > 0 — два корня.
Шаг 2: √9 = 3. По формуле x = (−b ± √D)/(2a) = (7 ± 3)/2: x₁ = (7 − 3)/2 = 2, x₂ = (7 + 3)/2 = 5.
Проверка: 2² − 7·2 + 10 = 4 − 14 + 10 = 0 ✅; 5² − 7·5 + 10 = 25 − 35 + 10 = 0 ✅
Ответ: x₁ = 2; x₂ = 5 ✅

А теперь — главное наблюдение. Сложи корни: 2 + 5 = 7. Перемножь их: 2 · 5 = 10. Сравни с коэффициентами уравнения x² − 7x + 10 = 0. Сумма корней 7 — это второй коэффициент с противоположным знаком (−(−7) = 7), а произведение 10 — это свободный член! Случайность? Нет — это теорема Виета, и мы её сейчас докажем.

📜 Формулировка теоремы Виета

Уравнение x² + px + q = 0 (старший коэффициент равен 1) называется приведённым квадратным уравнением. Для него и формулируется теорема.

ТЕОРЕМА. Сумма корней приведённого квадратного уравнения равна второму коэффициенту, взятому с противоположным знаком, а произведение корней равно свободному члену.
x₁ + x₂ = −p,    x₁ · x₂ = q

🔬 Доказательство теоремы

Рассмотрим приведённое квадратное уравнение x² + px + q = 0. Его дискриминант D = p² − 4q. Пусть D > 0 — тогда уравнение имеет два корня, которые находятся по формуле корней (урок 21):

x₁ = −p − √D2 ,    x₂ = −p + √D2
Шаг 1. Сумма корней. Сложим x₁ и x₂:
x₁ + x₂ = −p − √D2 + −p + √D2 = (−p − √D) + (−p + √D)2 = −2p2 = −p.
Слагаемые −√D и +√D взаимно уничтожились, осталось −2p/2 = −p.
Шаг 2. Произведение корней. Применим формулу разности квадратов (a − b)(a + b) = a² − b² к числителям:
x₁ · x₂ = −p − √D2 · −p + √D2 = (−p)² − (√D)²4 = p² − D4.
Вспомним, что D = p² − 4q, поэтому p² − D = p² − (p² − 4q) = 4q. Тогда p² − D4 = 4q4 = q.
Вывод: x₁ + x₂ = −p и x₁ · x₂ = q. Теорема доказана. ○
А что если D = 0? В этом случае уравнение имеет один корень (точнее — два равных корня). Если условиться считать, что при D = 0 корни x₁ и x₂ совпадают и вычисляются по той же формуле x = (−p ± √D)/2 (где √D = 0), то теорема Виета остаётся верной и в этом случае. Например, для x² − 6x + 9 = 0: единственный корень x = 3, и формально x₁ + x₂ = 3 + 3 = 6 = −(−6), x₁ · x₂ = 3 · 3 = 9.

🌍 Обобщение на произвольное квадратное уравнение

А что если уравнение не приведённое, то есть a ≠ 1? Пусть ax² + bx + c = 0 имеет корни x₁ и x₂. Разделим обе части на a (a ≠ 0) — получим равносильное приведённое уравнение:

x² + ba x + ca = 0

Здесь p = b/a и q = c/a. Применяя теорему Виета к этому приведённому уравнению, получаем важнейшую формулу:

x₁ + x₂ = −ba ,    x₁ · x₂ = ca

Это и есть теорема Виета для произвольного квадратного уравнения ax² + bx + c = 0: сумма корней равна −b/a, а произведение равно c/a.

🔄 Теорема, обратная теореме Виета

Теорема Виета говорит: «если x₁ и x₂ — корни, то их сумма и произведение равны таким-то числам». А обратная теорема идёт в другую сторону: «если у двух чисел такие сумма и произведение, то они — корни уравнения». Это чрезвычайно полезно для проверки найденных корней и для их подбора.

ТЕОРЕМА (обратная). Если числа m и n таковы, что их сумма равна −p, а произведение равно q, то эти числа являются корнями уравнения x² + px + q = 0.
Доказательство. По условию m + n = −p и mn = q. Подставим p = −(m + n) и q = mn в уравнение x² + px + q = 0:
x² − (m + n)x + mn = 0.
Проверим, что m — корень: подставим x = m: m² − (m + n)m + mn = m² − m² − mn + mn = 0 ✅.
Аналогично для x = n: n² − (m + n)n + mn = n² − mn − n² + mn = 0 ✅.
Значит, m и n — корни уравнения. Теорема доказана. ○

📐 Примеры из учебника

Пример 1. Найдём сумму и произведение корней уравнения 3x² − 5x + 2 = 0.

Решение. Сначала убедимся, что корни есть. Дискриминант D = (−5)² − 4·3·2 = 25 − 24 = 1 > 0 — корни существуют. Применим теорему Виета для общего уравнения ax² + bx + c = 0, где a = 3, b = −5, c = 2:
x₁ + x₂ = −b/a = −(−5)/3 = 5/3;   x₁ · x₂ = c/a = 2/3.
(Проверка через формулу корней: x = (5 ± 1)/6 → x₁ = 4/6 = 2/3, x₂ = 6/6 = 1; сумма 2/3 + 1 = 5/3 ✅, произведение 2/3 · 1 = 2/3 ✅.)

Пример 2. Решим уравнение x² + 3x − 40 = 0 и выполним проверку по теореме, обратной теореме Виета.

Решение. D = 3² − 4·1·(−40) = 9 + 160 = 169, √169 = 13. x = (−3 ± 13)/2 → x₁ = −8, x₂ = 5.
Проверка по обратной теореме. В уравнении x² + 3x − 40 = 0: p = 3, q = −40. Должно быть: x₁ + x₂ = −p = −3 и x₁ · x₂ = q = −40.
Сумма: −8 + 5 = −3 ✅. Произведение: −8 · 5 = −40 ✅. Корни найдены правильно.

Пример 3. Найдём подбором корни уравнения x² − x − 12 = 0.

Решение. Сначала проверим, что корни есть: D = (−1)² − 4·1·(−12) = 1 + 48 = 49 > 0 ✅.
По теореме Виета: x₁ + x₂ = −(−1) = 1, x₁ · x₂ = −12.
Если корни целые, то они — делители числа −12: ±1, ±2, ±3, ±4, ±6, ±12. Подберём пару, чьё произведение равно −12, а сумма равна 1. Подходит пара −3 и 4: (−3)·4 = −12 ✅ и (−3) + 4 = 1 ✅. По обратной теореме Виета эти числа — корни уравнения x² − x − 12 = 0.

🧑‍🏫 Франсуа Виет (1540—1603)

Франсуа Виет (1540—1603) — выдающийся французский математик, по профессии юрист. Ввёл систему алгебраических символов, разработал основы элементарной алгебры. Был одним из первых, кто стал обозначать числа буквами, что существенно развило теорию уравнений.

Современники называли его «отцом алгебры». По легенде, во время войны Франции с Испанией Виет расшифровал секретный шифр испанского короля, состоявший из 500 знаков, — и тем самым помог французам читать перехваченные депеши. Испанский король жаловался Папе Римскому, что «французский математик расшифровал его секрет с помощью дьявольской магии».

Теорема, которую мы изучаем, была сформулирована Виетом в 1591 году в трактате «Введение в аналитическое искусство».

📚 Ключевые термины

Термин Определение простым языком
Приведённое квадратное уравнение Уравнение вида x² + px + q = 0, где старший коэффициент равен 1. Любое квадратное уравнение ax² + bx + c = 0 можно сделать приведённым, разделив на a.
Теорема Виета (прямая) Сумма корней приведённого уравнения x² + px + q = 0 равна −p, а их произведение равно q. Для общего уравнения: сумма = −b/a, произведение = c/a.
Теорема, обратная теореме Виета Если сумма двух чисел равна −p, а их произведение равно q, то эти числа — корни уравнения x² + px + q = 0. Используется для проверки и подбора корней.
Подбор корней Способ нахождения целых корней: выписываем делители свободного члена q и выбираем те, чья сумма равна −p. По обратной теореме Виета они и есть корни.
Проверка по обратной теореме Найдя корни, проверяем: их сумма должна быть −b/a, произведение — c/a. Если сходится — корни верные (в уравнении, составленном правильно).
Признак знаков корней Если произведение корней < 0 — знаки разные. Если > 0 — знаки одинаковые, а по знаку суммы определяем, какие именно (положительные или отрицательные).

⚠️ Главные правила

Правило 1: Теорема Виета только для уравнений, имеющих корни.
Прежде чем применять теорему, убедись, что D ≥ 0. Если D < 0 — корней нет, и говорить об их сумме и произведении бессмысленно. Алгоритм: найти D → если D ≥ 0 → применить теорему.
Правило 2: Для общего уравнения — дели на a.
В уравнении ax² + bx + c = 0: сумма корней = −b/a, произведение = c/a. Частая ошибка — написать −b вместо −b/a или c вместо c/a. Для приведённого уравнения (a = 1) формула упрощается до x₁ + x₂ = −p, x₁·x₂ = q.
Правило 3: Подбор корней — через делители q.
Чтобы подобрать целые корни уравнения x² + px + q = 0: 1) выпиши все делители числа q (положительные и отрицательные); 2) выбери пару (m, n) с произведением mn = q; 3) проверь, что m + n = −p; 4) по обратной теореме Виета m и n — корни.
Правило 4: Проверка — обязательна.
Решив уравнение по формуле корней, всегда проверяй ответ по теореме Виета: сложи и перемножь найденные корни, сравни с −b/a и c/a. Это занимает 10 секунд и ловит ошибки в вычислениях дискриминанта и корня.
Правило 5: Знаки корней — по знакам p и q.
В уравнении x² + px + q = 0: если q < 0 — корни разных знаков. Если q > 0 и p < 0 — оба корня положительные. Если q > 0 и p > 0 — оба корня отрицательные.

🚦 Признак знаков корней

По теореме Виета можно, не решая уравнения, определить знаки его корней — если они существуют. Смотрим на знаки произведения q и суммы −p.

Произведение корней (q или c/a) Сумма корней (−p или −b/a) Знаки корней Пояснение
q < 0 — разные знаки Произведение отрицательно, значит один корень > 0, другой < 0. Знак суммы подскажет, у какого модуль больше.
q > 0 −p > 0 оба положительные Произведение и сумма положительны — оба корня > 0.
q > 0 −p < 0 оба отрицательные Произведение > 0, сумма < 0 — оба корня < 0.
q = 0 — один корень = 0 Свободный член равен 0 → один из корней 0, второй равен −p.

🎯 Устная проверка: сумма и произведение

Не решая уравнение, назови сумму и произведение его корней. Помни: сначала — теорема Виета, формула — потом!

а) (№ 578а) x² − 37x + 27 = 0    б) (№ 578б) y² + 41y − 371 = 0    в) (№ 578в) x² − 210x = 0

г) (№ 578г) y² − 19 = 0    д) (№ 578д) 2x² − 9x − 10 = 0    е) (№ 578е) 5x² + 12x + 7 = 0

Показать ответы
а) a = 1: сумма = 37, произведение = 27.
б) a = 1: сумма = −41, произведение = −371.
в) a = 1, q = 0: сумма = 210, произведение = 0.
г) a = 1: сумма = 0, произведение = −19.
д) a = 2: сумма = −(−9)/2 = 4,5, произведение = −10/2 = −5.
е) a = 5: сумма = −12/5, произведение = 7/5.
⚠️ Ловушки теоремы Виета. 1) Применяют к уравнению без корней (D < 0) — сначала проверь D. 2) В общем уравнении забывают делить на a: пишут сумму −b вместо −b/a. 3) Путают знаки: сумма = −p (с минусом!), а произведение = q (без минуса). 4) При подборе корней забывают отрицательные делители: для q = −12 делители ±1, ±2, ±3, ±4, ±6, ±12. 5) Обратная теорема проверяет только правильность вычисления корней, но не правильность составления уравнения.

🟢 Базовый уровень

Задание 1 (№ 578а,б)

Найдите сумму и произведение корней уравнения:
а) x² − 37x + 27 = 0;   б) y² + 41y − 371 = 0.

Показать решение
а) Уравнение приведённое (a = 1), p = −37, q = 27. По теореме Виета: x₁ + x₂ = −p = 37, x₁ · x₂ = q = 27.
б) Уравнение приведённое, p = 41, q = −371. По теореме Виета: y₁ + y₂ = −p = −41, y₁ · y₂ = q = −371.
Замечание: D = 37² − 4·27 = 1369 − 108 = 1261 > 0 ✅ и D = 41² + 4·371 = 1681 + 1484 = 3165 > 0 ✅ — корни существуют, теорема применима.

Задание 2 (№ 578д,е)

Найдите сумму и произведение корней уравнения:
д) 2x² − 9x − 10 = 0;   е) 5x² + 12x + 7 = 0.

Показать решение

е) a = 5, b = 12, c = 7. D = 144 − 140 = 4 > 0. x₁ + x₂ = −12/5 = −2,4, x₁ · x₂ = 7/5 = 1,4.

Задание 3 (№ 579а)

Решите уравнение x² − 2x − 9 = 0 и выполните проверку по теореме, обратной теореме Виета.

Показать подробное решение
Шаг 1: D = (−2)² − 4·1·(−9) = 4 + 36 = 40. √40 = 2√10.
Шаг 2: x = (2 ± 2√10)/2 = 1 ± √10. То есть x₁ = 1 + √10 ≈ 4,162, x₂ = 1 − √10 ≈ −2,162.
Шаг 3 (проверка по обратной теореме): в уравнении p = −2, q = −9. Должно быть x₁ + x₂ = 2 и x₁ · x₂ = −9.
Сумма: (1 + √10) + (1 − √10) = 2 ✅.
Произведение: (1 + √10)(1 − √10) = 1 − 10 = −9 ✅ (разность квадратов!).
Ответ: x₁ = 1 + √10, x₂ = 1 − √10 ✅

Задание 4 (№ 580а)

Найдите корни уравнения x² − 15x − 16 = 0 и выполните проверку по теореме, обратной теореме Виета.

Показать подробное решение
Шаг 1: D = (−15)² − 4·1·(−16) = 225 + 64 = 289. √289 = 17.
Шаг 2: x = (15 ± 17)/2 → x₁ = (15 − 17)/2 = −1, x₂ = (15 + 17)/2 = 16.
Шаг 3 (проверка): p = −15, q = −16. Должно быть: сумма = 15, произведение = −16.
Сумма: −1 + 16 = 15 ✅. Произведение: −1 · 16 = −16 ✅.
Ответ: x₁ = −1, x₂ = 16 ✅

Задание 5 (№ 580в)

Найдите корни уравнения 12x² − 4x − 1 = 0 и выполните проверку по теореме, обратной теореме Виета.

Показать подробное решение
Шаг 1: a = 12, b = −4, c = −1. D = (−4)² − 4·12·(−1) = 16 + 48 = 64. √64 = 8.
Шаг 2: x = (4 ± 8)/(2·12) = (4 ± 8)/24 → x₁ = (4 − 8)/24 = −4/24 = −1/6, x₂ = (4 + 8)/24 = 12/24 = 1/2.
Шаг 3 (проверка): сумма должна быть −b/a = 4/12 = 1/3, произведение c/a = −1/12.
Сумма: −1/6 + 1/2 = −1/6 + 3/6 = 2/6 = 1/3 ✅. Произведение: (−1/6)·(1/2) = −1/12 ✅.
Ответ: x₁ = −1/6, x₂ = 1/2 ✅

Показать подбор корней

Задание 8 (№ 583)

В уравнении x² + px − 35 = 0 один из корней равен 7. Найдите другой корень и коэффициент p.

Показать подробное решение
Шаг 1: По теореме Виета: x₁ · x₂ = q = −35. Подставим x₁ = 7: 7 · x₂ = −35 → x₂ = −5.
Шаг 2: Также по теореме: x₁ + x₂ = −p. Подставим оба корня: 7 + (−5) = 2 = −p → p = −2.
Проверка: уравнение x² − 2x − 35 = 0. D = 4 + 140 = 144, √144 = 12, x = (2 ± 12)/2 → x₁ = −5, x₂ = 7 ✅.
Ответ: x₂ = −5, p = −2 ✅
🟣 Продвинутый уровень

Задание 9 (№ 584)

Один из корней уравнения x² − 13x + q = 0 равен 12,5. Найдите другой корень и коэффициент q.

Показать подробное решение
Шаг 1: По теореме Виета: x₁ + x₂ = 13 (так как p = −13). Подставим x₁ = 12,5 = 25/2: 25/2 + x₂ = 13 → x₂ = 13 − 25/2 = 26/2 − 25/2 = 1/2 = 0,5.
Шаг 2: Произведение: x₁ · x₂ = q. q = (25/2) · (1/2) = 25/4 = 6,25.
Проверка: уравнение x² − 13x + 25/4 = 0 → 4x² − 52x + 25 = 0. D = 2704 − 400 = 2304 = 48². x = (52 ± 48)/8 → x₁ = 100/8 = 12,5 ✅, x₂ = 4/8 = 0,5 ✅.
Ответ: x₂ = 0,5; q = 6,25 ✅
🟣 Продвинутый уровень

Задание 10 (№ 585)

Один из корней уравнения 5x² + bx + 24 = 0 равен 8. Найдите другой корень и коэффициент b.

Показать подробное решение
Шаг 1: В общем уравнении ax² + bx + c = 0: x₁ · x₂ = c/a = 24/5. Подставим x₁ = 8: 8 · x₂ = 24/5 → x₂ = 24/5 ÷ 8 = 24/40 = 3/5 = 0,6.
Шаг 2: Сумма: x₁ + x₂ = −b/a → 8 + 3/5 = 43/5 = −b/5 → b = −43.
Проверка: уравнение 5x² − 43x + 24 = 0. D = 1849 − 480 = 1369 = 37². x = (43 ± 37)/10 → x₁ = 80/10 = 8 ✅, x₂ = 6/10 = 0,6 ✅.
Ответ: x₂ = 0,6; b = −43 ✅
🟣 Продвинутый уровень

Задание 11 (№ 587)

Разность корней квадратного уравнения x² − 12x + q = 0 равна 2. Найдите q.

Показать подробное решение
Шаг 1: По теореме Виета: x₁ + x₂ = 12, x₁ · x₂ = q. Также из условия: x₁ − x₂ = 2 (считаем, что x₁ > x₂).
Шаг 2: Сложим и вычтем: (x₁ + x₂) + (x₁ − x₂) = 12 + 2 → 2x₁ = 14 → x₁ = 7. Тогда x₂ = 12 − 7 = 5.
Шаг 3: q = x₁ · x₂ = 7 · 5 = 35.
Проверка: уравнение x² − 12x + 35 = 0. D = 144 − 140 = 4, √4 = 2. x = (12 ± 2)/2 → x₁ = 7, x₂ = 5. Разность 7 − 5 = 2 ✅.
Ответ: q = 35 ✅
🟣 Продвинутый уровень

Задание 12 (№ 589)

Разность квадратов корней уравнения x² + 2x + q = 0 равна 12. Найдите q.

Показать подробное решение
Шаг 1: По теореме Виета: x₁ + x₂ = −2, x₁ · x₂ = q.
Шаг 2: Разложим разность квадратов: x₁² − x₂² = (x₁ − x₂)(x₁ + x₂) = (x₁ − x₂)·(−2) = 12 → x₁ − x₂ = −6.
Шаг 3: Система: x₁ + x₂ = −2 и x₁ − x₂ = −6. Сложим: 2x₁ = −8 → x₁ = −4. Тогда x₂ = −2 − (−4) = 2.
Шаг 4: q = x₁ · x₂ = (−4) · 2 = −8.
Проверка: уравнение x² + 2x − 8 = 0. D = 4 + 32 = 36, √36 = 6. x = (−2 ± 6)/2 → x₁ = −4, x₂ = 2. Разность квадратов: (−4)² − 2² = 16 − 4 = 12 ✅.
Ответ: q = −8 ✅
🟣 Продвинутый уровень

Задание 13 (№ 590)

Известно, что сумма квадратов корней уравнения x² − 3x + a = 0 равна 65. Найдите a.

Показать подробное решение
Шаг 1: По теореме Виета: x₁ + x₂ = 3, x₁ · x₂ = a.
Шаг 2: Сумму квадратов выразим через сумму и произведение: x₁² + x₂² = (x₁ + x₂)² − 2x₁x₂ = 9 − 2a.
Шаг 3: По условию: 9 − 2a = 65 → 2a = 9 − 65 = −56 → a = −28.
Проверка: уравнение x² − 3x − 28 = 0. D = 9 + 112 = 121 = 11². x = (3 ± 11)/2 → x₁ = 7, x₂ = −4. Сумма квадратов: 49 + 16 = 65 ✅.
Ответ: a = −28 ✅

🏗 Блок 3. Практическое применение

🚀 Задача для криптоаналитика

В разведке перехватили шифр: противник использует два «ключевых числа» a и b таких, что их сумма равна 15, а произведение равно 36. Помоги криптоаналитику восстановить числа — и он построит уравнение, корнями которого они являются.

Показать решение криптоаналитика
Шаг 1: По теореме, обратной теореме Виета, числа m и n с суммой −p и произведением q являются корнями уравнения x² + px + q = 0.
Шаг 2: Сумма a + b = 15 = −p → p = −15. Произведение a · b = 36 = q.
Шаг 3: Уравнение: x² − 15x + 36 = 0. Его корни — искомые числа.
Шаг 4: Подбором: делители 36 — это 1, 2, 3, 4, 6, 9, 12, 18, 36. Пара (3, 12): 3 + 12 = 15 ✅, 3 · 12 = 36 ✅. По обратной теореме Виета: 3 и 12 — корни.
Ответ: ключевые числа 3 и 12 ✅

💼 Задача для разработчика онлайн-тестов

Разработчик составляет тест по математике: ему нужно квадратное уравнение с целыми корнями 6 и 8. Составь это уравнение, используя теорему, обратную теореме Виета. В ответ введи коэффициенты p и q.

Показать решение разработчика
Шаг 1: Корни x₁ = 6, x₂ = 8. По теореме Виета для уравнения x² + px + q = 0: p = −(x₁ + x₂) = −(6 + 8) = −14, q = x₁ · x₂ = 48.
Шаг 2: Уравнение: x² − 14x + 48 = 0.
Проверка: D = 196 − 192 = 4, √4 = 2. x = (14 ± 2)/2 → x₁ = 6, x₂ = 8 ✅.
Ответ: x² − 14x + 48 = 0 (можно умножить на любой множитель: 2x² − 28x + 96 = 0 и т. п.) ✅

🎨 Бонус: составь своё уравнение

Придумай два целых числа, найди их сумму S и произведение P. Тогда уравнение x² − S·x + P = 0 имеет эти числа корнями. Так, для чисел 5 и 9: S = 14, P = 45 → уравнение x² − 14x + 45 = 0. Проверь: 5 + 9 = 14 ✅, 5 · 9 = 45 ✅.

🌟 Главное, что нужно запомнить

  • Теорема Виета (прямая): для приведённого уравнения x² + px + q = 0 с корнями x₁ и x₂ верно: x₁ + x₂ = −p, x₁ · x₂ = q.
  • Для общего уравнения: ax² + bx + c = 0 → x₁ + x₂ = −b/a, x₁ · x₂ = c/a. Делим коэффициенты на a!
  • Обратная теорема: если m + n = −p и mn = q, то m и n — корни уравнения x² + px + q = 0. Основа для подбора и проверки.
  • Подбор целых корней: выписываем делители q, выбираем пару с суммой −p. По обратной теореме — это корни.
  • Признак знаков: q < 0 → корни разных знаков; q > 0 и −p > 0 → оба положительные; q > 0 и −p < 0 → оба отрицательные.
  • Перед применением теоремы — проверь D: если D < 0, корней нет, теорема неприменима.
  • Формулы для симметричных выражений: x₁² + x₂² = (x₁+x₂)² − 2x₁x₂; x₁³ + x₂³ = (x₁+x₂)((x₁+x₂)² − 3x₁x₂); x₁² − x₂² = (x₁−x₂)(x₁+x₂).
  • 💡 Лайфхак: если корни «красивые» (целые) — сначала попробуй подобрать по теореме Виета, и только потом считай по формуле корней. Это экономит время на контрольной.

💡 Методическая подсказка (для учителя / родителя)

🎯 Типичные ошибки:

  • Применяют теорему к уравнению без корней: для x² + 7x + 13 = 0 (D = 49 − 52 = −3 < 0) пишут «сумма = −7, произведение = 13», хотя корней нет. Сначала D — потом теорема.
  • Забывают делить на a: в 3x² − 5x + 2 = 0 пишут сумму 5 вместо 5/3. Формула −b/a — обязательна.
  • Путают знаки в теореме: пишут x₁ + x₂ = p (без минуса). Запоминайте как мнемонику: «сумма = −p» (минус от "переходит в сумму"), «произведение = q» (свободный член как есть).
  • В № 587–588 путают разность и сумму: используют x₁ + x₂ там, где дана разность x₁ − x₂, и получают неверный знак q. Полезно вводить вспомогательную переменную d = x₁ − x₂.
  • В № 593 не видят формулы: не вспоминают, что x₁² + x₂² = (x₁+x₂)² − 2x₁x₂ — это тождество, связывающее квадраты с суммой и произведением.
  • При подборе корней забывают отрицательные делители: для q = 12 рассматривают только 1, 2, 3, 4, 6, 12 — но не −1, −2, …. Для x² + 7x + 12 = 0 корни −3 и −4.

🪜 Подмостки для слабых учеников:

  • Карточка-шаблон: «Уравнение …, a = …, b = …, c = …»; «D = b² − 4ac = …»; «если D ≥ 0: сумма = −b/a = …, произведение = c/a = …».
  • Начинайте с приведённых уравнений (a = 1): x² − 5x + 6 = 0, x² + 7x + 12 = 0 — корни целые, легко подбираются.
  • Таблицу «Признак знаков корней» распечатайте как памятку: по ней можно за 5 секунд ответить, какие знаки у корней, не решая уравнение.
  • Решайте № 583–586 в парах: один называет теорему Виета, другой подставляет известный корень. Это закрепляет связку «один корень известен → найди второй через произведение».

🚀 Вызов для сильных учеников:

  • № 591: попросите учеников доказать критерий знаков корней через теорему Виета: «произведение < 0 ⟺ корни разных знаков».
  • № 593: свяжите с тождествами x₁² + x₂² = (x₁+x₂)² − 2x₁x₂ и x₁³ + x₂³ = (x₁+x₂)³ − 3x₁x₂(x₁+x₂). Пусть выведут второе из первого.
  • № 594: обсудите, почему нельзя сокращать обе части уравнения (3x + 1)² = 3x + 1 на (3x + 1) — теряется корень x = −1/3. Надёжнее перенести всё в одну сторону и разложить на множители.
  • Покажите связь с квадратным трёхчленом (§ 8, п. 24, который следует дальше): теорема Виета понадобится для разложения ax² + bx + c = a(x − x₁)(x − x₂).
