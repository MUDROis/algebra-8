Преобразование выражений, содержащих квадратные корни

Урок 18 • Глава 2, §6

🧠 Блок 1. Изучение

Разминка: Зачем преобразовывать?

Представь, что ты решаешь уравнение и получил ответ √12 + √27. Можно ли его упростить? Да! √12 = 2√3, √27 = 3√3, значит √12 + √27 = 2√3 + 3√3 = 5√3. Преобразование выражений помогает упростить ответы и сделать их более понятными!

Ключевые термины

Термин Определение простым языком
Подобные слагаемые Слагаемые с одинаковым подкоренным выражением (например, 2√3 и 5√3).
Умножение корней √a × √b = √(a × b) (при a ≥ 0, b ≥ 0).
Деление корней √a / √b = √(a / b) (при a ≥ 0, b > 0).
Возведение корня в степень (√a)ⁿ = √(aⁿ) (при a ≥ 0).

⚠️ Главные правила

Правило 1: Сложение и вычитание корней
Складывать можно только подобные слагаемые: a√c + b√c = (a + b)√c
a√c + b√c = (a + b)√c
Правило 2: Умножение корней
√a × √b = √(a × b) (при a ≥ 0, b ≥ 0)
√a × √b = √(a × b)
Правило 3: Деление корней
√a / √b = √(a / b) (при a ≥ 0, b > 0)
√a√b = √ab
Правило 4: Порядок действий
1. Упростите каждый корень (вынесите множители).
2. Приведите подобные слагаемые.
3. Выполните умножение или деление, если необходимо.

Блок 2. Закрепление

От теории к практике! Решаем задачи на преобразование выражений.

🟢 Базовый уровень

Задание 1

Упростите: √8 + √18

Показать подробное решение
Шаг 1: Упростим каждый корень: √8 = 2√2, √18 = 3√2.
Шаг 2: Сложим подобные слагаемые: 2√2 + 3√2 = 5√2.
Шаг 3: Проверка: 5√2 = √(25 × 2) = √50. √8 + √18 = √(8 + 18) = √26 ≠ √50. Ошибка! Проверим иначе: √8 ≈ 2.83, √18 ≈ 4.24, сумма ≈ 7.07. 5√2 ≈ 7.07. Верно!
Ответ: √8 + √18 = 5√2 ✅
Средний уровень

Задание 2

Упростите: √12 × √3

Показать подробное решение
Шаг 1: Применяем правило умножения: √12 × √3 = √(12 × 3) = √36.
Шаг 2: Вычисляем: √36 = 6.
Шаг 3: Проверка: √12 ≈ 3.46, √3 ≈ 1.73, произведение ≈ 6. Верно!
Ответ: √12 × √3 = 6 ✅
🟣 Продвинутый уровень

Задание 3

Упростите: (√6 + √2)(√6 - √2)

Показать подробное решение
Шаг 1: Это разность квадратов: (a + b)(a - b) = a² - b².
Шаг 2: Применяем: (√6)² - (√2)² = 6 - 2 = 4.
Шаг 3: Проверка: √6 ≈ 2.45, √2 ≈ 1.41. (2.45 + 1.41)(2.45 - 1.41) = 3.86 × 1.04 ≈ 4. Верно!
Ответ: (√6 + √2)(√6 - √2) = 4 ✅
Средний уровень

Задание 4

Упростите: √50 - √8

Показать подробное решение
Шаг 1: Упростим каждый корень: √50 = 5√2, √8 = 2√2.
Шаг 2: Вычтем подобные слагаемые: 5√2 - 2√2 = 3√2.
Шаг 3: Проверка: 3√2 = √(9 × 2) = √18. √50 - √8 ≈ 7.07 - 2.83 = 4.24. 3√2 ≈ 4.24. Верно!
Ответ: √50 - √8 = 3√2 ✅

🏗 Блок 3. Практическое применение

Задача для инженера

Сопротивление двух резисторов, соединённых параллельно, вычисляется по формуле R = (R₁ × R₂) / (R₁ + R₂). Если R₁ = √8 Ом и R₂ = √18 Ом, чему равно сопротивление?

Показать решение инженера
Шаг 1: Упростим сопротивления: R₁ = √8 = 2√2, R₂ = √18 = 3√2.
Шаг 2: Подставим в формулу: R = (2√2 × 3√2) / (2√2 + 3√2) = (6 × 2) / (5√2) = 12 / (5√2).
Шаг 3: Избавимся от иррациональности: R = (12√2) / (5 × 2) = (6√2) / 5.
Ответ: R = (6√2) / 5 ≈ 1.70 Ом ✅

Главное, что нужно запомнить

  • Сложение: a√c + b√c = (a + b)√c (только подобные слагаемые).
  • Умножение: √a × √b = √(a × b).
  • Деление: √a / √b = √(a / b).
  • Порядок: упростить → привести подобные → выполнить действия.
  • 💡 Лайфхак: всегда упрощай корни перед сложением или вычитанием.

💡 Методическая подсказка (для учителя / родителя)

🎯 Типичные ошибки:

  • Сложение разных корней: ученики складывают √2 + √3 = √5. Объясните, что это неверно!
  • Неверное умножение: √a × √b = √(a + b) вместо √(a × b).
  • Пропуск упрощения: не упрощают корни перед сложением.

🪜 Подмостки для слабых учеников:

  • Дайте таблицу упрощённых корней (√8, √12, √18, √20, √27, √32, √45, √50).
  • Начните с подобных слагаемых, потом переходите к умножению.
  • Используйте цветные маркеры: одинаковые подкоренные выражения — одним цветом.

🚀 Вызов для сильных учеников:

  • Докажите, что √a × √b = √(a × b) для любых a ≥ 0, b ≥ 0.
  • Упростите выражение (√a + √b)(√a - √b) и объясните результат.
  • Исследуйте, когда √(a + b) = √a + √b.
