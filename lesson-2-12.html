📈 Уравнение x² = a

Глава 2, § 12

🧠 Блок 1. Изучение нового

🪝 Разминка: парабола — старый знакомый

Ты уже знаешь график функции y = x² — это парабола, ветви которой направлены вверх. Сегодня мы используем этот график, чтобы понять, сколько корней имеет уравнение x² = a в зависимости от значения a. 🎯

📌 Ключевые свойства графика y = x²

СвойствоФормулировкаСледствие
1. Проходит через начало координат При x = 0 получаем y = 0 Точка (0; 0) лежит на графике
2. Все точки выше оси x При x ≠ 0 получаем y > 0 Парабола лежит в верхней полуплоскости
3. Симметрия относительно оси y Противоположным значениям x соответствует одно и то же y (−3)² = 3² = 9

📘 Три случая решения уравнения x² = a

Случай 1: a < 0 → корней нет

Не существует числа, квадрат которого отрицателен.
Пример: x² = −25 — нет решений ❌

Случай 2: a = 0 → один корень

Единственное число, квадрат которого равен нулю, — это ноль.
Пример: x² = 0 → x = 0 ✅

Случай 3: a > 0 → два корня

Прямая y = a пересекает параболу в двух симметричных точках:
x₁ = √a и x₂ = −√a
Пример: x² = 6,25 → x = ±2,5 ✅

Итог: при a > 0 уравнение x² = a имеет два корня: x = √a и x = −√a.
При a = 0 — один корень: x = 0.
При a < 0 — корней нет.

📘 Пример 1. Решение уравнений

а) x² = 6,25
x = ±√6,25 = ±2,5 ✅
Проверка: 2,5² = 6,25 и (−2,5)² = 6,25 ✅
б) x² = 9/4
x = ±√(9/4) = ±3/2 = ±1,5 ✅
Проверка: (3/2)² = 9/4 ✅
в) x² = 2
x = ±√2
Это иррациональные числа: √2 ≈ 1,4, −√2 ≈ −1,4 ✅

📘 Пример 2. Свойство арифметического корня

Для любого a ≥ 0 верно: (√a)² = a

Примеры:
(√7)² = 7 ✅
(√25)² = 25 ✅
(√0)² = 0 ✅

⚠️ Но √(−4) не существует!

🛠 Блок 2. Закрепление

Задачи из учебника. Выбери уровень и вперёд! 🚀

🟢 Базовый Задание 1 (№ 312 + № 313 из учебника)

Определите, имеет ли уравнение корни, и решите его:

а) x² = 81    б) x² = 18    в) x² = 0    г) x² = −25    д) x² = 36    е) x² = 0,49
Показать решение
а) x² = 81
a = 81 > 0 → два корня:
x = ±√81 = ±9 ✅
Проверка: 9² = 81, (−9)² = 81 ✅
б) x² = 18
a = 18 > 0 → два корня:
x = ±√18 = ±3√2 (иррациональные) ✅
Приближённо: x ≈ ±4,24
в) x² = 0
a = 0 → один корень:
x = 0 ✅
г) x² = −25
a = −25 < 0 → корней нет ❌
(квадрат числа не может быть отрицательным)
д) x² = 36
x = ±√36 = ±6 ✅
е) x² = 0,49
x = ±√0,49 = ±0,7 ✅
Проверка: 0,7² = 0,49 ✅

Ответы: ±9; ±3√2; 0; нет корней; ±6; ±0,7. Всё верно! ✅

🔵 Средний Задание 2 (№ 317 из учебника)

Решите уравнение:

а) (x − 3)² = 25    б) (x + 4)² = 9    в) (x − 6)² = 7    г) (x + 2)² = 6
Показать решение
а) (x − 3)² = 25
x − 3 = ±5
x₁ = 3 + 5 = 8
x₂ = 3 − 5 = −2
Проверка: (8−3)² = 25 ✅, (−2−3)² = 25 ✅
б) (x + 4)² = 9
x + 4 = ±3
x₁ = −4 + 3 = −1
x₂ = −4 − 3 = −7
Проверка: (−1+4)² = 9 ✅, (−7+4)² = 9 ✅
в) (x − 6)² = 7
x − 6 = ±√7
x₁ = 6 + √7 ≈ 6 + 2,65 ≈ 8,65
x₂ = 6 − √7 ≈ 6 − 2,65 ≈ 3,35
Проверка: (√7)² = 7 ✅
г) (x + 2)² = 6
x + 2 = ±√6
x₁ = −2 + √6 ≈ −2 + 2,45 ≈ 0,45
x₂ = −2 − √6 ≈ −2 − 2,45 ≈ −4,45
Проверка: (√6)² = 6 ✅

Ответы: а) 8 и −2; б) −1 и −7; в) 6 ± √7; г) −2 ± √6. Отлично! ✅

🟣 Продвинутый Задание 3 (№ 323 + № 324 из учебника)

Вычислите:

а) 0,49 + 2(√0,4)²    б) (3√11)² − √6400    в) (2√6)² + (−3√2)²    г) (2 − √5)² + 4√5
Показать решение
а) 0,49 + 2(√0,4)²
(√0,4)² = 0,4
0,49 + 2 · 0,4 = 0,49 + 0,8 = 1,29 ✅
б) (3√11)² − √6400
(3√11)² = 9 · 11 = 99
√6400 = 80
99 − 80 = 19 ✅
в) (2√6)² + (−3√2)²
(2√6)² = 4 · 6 = 24
(−3√2)² = 9 · 2 = 18
24 + 18 = 42 ✅
г) (2 − √5)² + 4√5
Раскрываем по формуле (a−b)² = a² − 2ab + b²:
(2 − √5)² = 4 − 4√5 + 5 = 9 − 4√5
9 − 4√5 + 4√5 = 9 ✅

Ответы: 1,29; 19; 42; 9. Блестяще! 🏆

🏗 Блок 3. Практическое применение

👷 Задача для архитектора: расчёт балки

Архитектор проектирует квадратное окно площадью 2,56 м². Нужно найти длину стороны окна и длину диагонали (для установки перемычки). Также нужно проверить, поместится ли окно в проём высотой 2 м.

Показать решение архитектора
Шаг 1. Сторона квадрата:
a² = 2,56 → a = √2,56 = 1,6 м
Проверка: 1,6² = 2,56 ✅
Шаг 2. Диагональ квадрата (теорема Пифагора):
d² = a² + a² = 2a² = 2 · 2,56 = 5,12
d = √5,12 ≈ 2,26 м
Шаг 3. Проверка высоты проёма:
Сторона окна = 1,6 м
Высота проёма = 2 м
1,6 < 2 → окно помещается ✅
Но диагональ 2,26 м > 2 м — при наклоне окно не пройдёт! ⚠️

Ответ: сторона = 1,6 м, диагональ ≈ 2,26 м. Окно помещается в проём только вертикально. 🏗️

🌍 Где ещё используется уравнение x² = a?
• Физика: расчёт скорости при свободном падении v² = 2gh → v = √(2gh)
• Электротехника: мощность и напряжение P = U²/R → U = √(PR)
• Астрономия: орбитальные скорости планет

🌟 Главное, что нужно запомнить

  • ✅ Уравнение x² = a при a > 0 имеет два корня: x = √a и x = −√a.
  • ✅ При a = 0 — один корень: x = 0.
  • ✅ При a < 0 — корней нет.
  • ✅ График y = x² — парабола, симметричная относительно оси y, вершина в начале координат.
  • ✅ (√a)² = a при a ≥ 0.
  • ✅ Если a — не полный квадрат, корни иррациональны (например, √2, √3, √7).
  • 💡 Лайфхак: для уравнения вида (f(x))² = a сначала находим f(x) = ±√a, затем решаем два простых уравнения.

💡 Методическая подсказка (для учителя / родителя)

Типичные ошибки:

  • Забывают второй (отрицательный) корень: пишут только x = √a, забывая x = −√a.
  • Путают √(x²) и x: на самом деле √(x²) = |x|.
  • Неправильно возводят произведение в квадрат: (3√5)² = 9 · 5 = 45, а не 3√25.
  • При решении (x−a)² = b забывают раскрыть скобки с двумя знаками ±.

🪜 Подмостки для слабых учеников:

  • Дайте таблицу квадратов 1² … 20² для быстрого поиска.
  • Начните с числовых примеров: x² = 4, x² = 9, x² = 16.
  • Нарисуйте параболу и прямую y = a — визуализация помогает понять количество корней.
  • Используйте алгоритм: «Определи знак a → запиши формулу → проверь».

🚀 Вызов для сильных учеников:

  • № 316 из учебника: уравнения вида x³ − 11x = 0 (разложение на множители).
  • № 324 из учебника: упрощение выражений вида (5+√3)² + (5−√3)².
  • № 328 из учебника: постройте графики y = √(−x) и y = √(10x).
  • Докажите, что √2 иррационально (связь с § 10).
