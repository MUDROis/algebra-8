🧠 Блок 1. Изучение

Разминка: Что такое двойной радикал?

Двойной радикал — это выражение, содержащее корень из суммы или разности корней. Например, √(5 + 2√6). На первый взгляд кажется, что его нельзя упростить. Но если заметить, что 5 + 2√6 = (√3 + √2)², то √(5 + 2√6) = √3 + √2. Волшебство? Нет, математика!

Ключевые термины

Термин Определение простым языком
Двойной радикал Выражение вида √(a ± 2√b), которое можно представить как √x ± √y.
Выделение полного квадрата Преобразование подкоренного выражения к виду (√x ± √y)².
Формула вложенного корня √(a + 2√b) = √x + √y, где x + y = a и xy = b.

⚠️ Главные правила

Правило 1: Основная формула
Если a + 2√b = (√x + √y)², то √(a + 2√b) = √x + √y, где x + y = a и xy = b.
√(a + 2√b) = √x + √y, где x + y = a, xy = b
Правило 2: Алгоритм преобразования
1. Представь подкоренное выражение в виде (√x + √y)² = x + y + 2√(xy).
2. Найди x и y из системы: x + y = a, xy = b.
3. Извлеки корень: √(a + 2√b) = √x + √y.
Правило 3: Пример
√(5 + 2√6): x + y = 5, xy = 6. Решаем систему: x = 3, y = 2. Значит √(5 + 2√6) = √3 + √2.
Правило 4: Проверка
Всегда проверяй: возведи результат в квадрат и сравни с исходным подкоренным выражением.

Блок 2. Закрепление

От теории к практике! Решаем задачи на преобразование двойных радикалов.

🟢 Базовый уровень

Задание 1

Упростите: √(7 + 4√3)

Показать подробное решение
Шаг 1: Представим подкоренное выражение в виде (√x + √y)² = x + y + 2√(xy).
Шаг 2: Имеем: x + y = 7, 2√(xy) = 4√3, значит √(xy) = 2√3, xy = 12.
Шаг 3: Решаем систему: x + y = 7, xy = 12. Получаем x = 4, y = 3.
Шаг 4: Значит √(7 + 4√3) = √4 + √3 = 2 + √3.
Ответ: √(7 + 4√3) = 2 + √3 ✅
Средний уровень

Задание 2

Упростите: √(11 + 2√18)

Показать подробное решение
Шаг 1: Представим подкоренное выражение в виде (√x + √y)² = x + y + 2√(xy).
Шаг 2: Имеем: x + y = 11, 2√(xy) = 2√18, значит √(xy) = √18, xy = 18.
Шаг 3: Решаем систему: x + y = 11, xy = 18. Получаем x = 9, y = 2.
Шаг 4: Значит √(11 + 2√18) = √9 + √2 = 3 + √2.
Ответ: √(11 + 2√18) = 3 + √2 ✅
🟣 Продвинутый уровень

Задание 3

Упростите: √(8 - 2√15)

Показать подробное решение
Шаг 1: Представим подкоренное выражение в виде (√x - √y)² = x + y - 2√(xy).
Шаг 2: Имеем: x + y = 8, 2√(xy) = 2√15, значит √(xy) = √15, xy = 15.
Шаг 3: Решаем систему: x + y = 8, xy = 15. Получаем x = 5, y = 3.
Шаг 4: Значит √(8 - 2√15) = √5 - √3.
Ответ: √(8 - 2√15) = √5 - √3 ✅
Средний уровень

Задание 4

Упростите: √(9 + 4√5)

Показать подробное решение
Шаг 1: Представим подкоренное выражение в виде (√x + √y)² = x + y + 2√(xy).
Шаг 2: Имеем: x + y = 9, 2√(xy) = 4√5, значит √(xy) = 2√5, xy = 20.
Шаг 3: Решаем систему: x + y = 9, xy = 20. Получаем x = 5, y = 4.
Шаг 4: Значит √(9 + 4√5) = √5 + √4 = √5 + 2.
Ответ: √(9 + 4√5) = 2 + √5 ✅

🏗 Блок 3. Практическое применение

Задача для математика

Докажите, что √(2 + √3) можно представить в виде (√6 + √2)/2.

Показать решение математика
Шаг 1: Умножим подкоренное выражение на 2: 2(2 + √3) = 4 + 2√3.
Шаг 2: Представим 4 + 2√3 в виде (√x + √y)² = x + y + 2√(xy).
Шаг 3: Имеем: x + y = 4, xy = 3. Решаем систему: x = 3, y = 1.
Шаг 4: Значит 4 + 2√3 = (√3 + 1)², и √(4 + 2√3) = √3 + 1.
Шаг 5: Возвращаемся к исходному: √(2 + √3) = (√3 + 1)/√2 = (√6 + √2)/2.
Ответ: √(2 + √3) = (√6 + √2)/2 ✅

Главное, что нужно запомнить

  • Формула: √(a + 2√b) = √x + √y, где x + y = a, xy = b.
  • Алгоритм: представить в виде (√x ± √y)² → найти x и y → извлечь корень.
  • Проверка: возвести результат в квадрат и сравнить с исходным выражением.
  • Применение: упрощение выражений, решение уравнений, тригонометрия.
  • 💡 Лайфхак: если подкоренное выражение имеет вид a ± 2√b, попробуй найти два числа, сумма которых равна a, а произведение — b.

💡 Методическая подсказка (для учителя / родителя)

🎯 Типичные ошибки:

  • Неверное представление: ученики пытаются представить √(a + √b) вместо √(a + 2√b). Объясните, что коэффициент 2 обязателен.
  • Ошибки в системе: неправильно решают систему x + y = a, xy = b. Требуйте проверки.
  • Пропуск проверки: не проверяют результат возведением в квадрат.

🪜 Подмостки для слабых учеников:

  • Дайте готовые пары (x, y) для типовых случаев: (3,2), (4,3), (5,2), (5,3).
  • Начните с простых примеров с малыми числами.
  • Используйте цветные маркеры: x и y — разными цветами.

🚀 Вызов для сильных учеников:

  • Докажите, что √(a + 2√b) = √x + √y, где x и y — корни уравнения t² - at + b = 0.
  • Упростите √(1 + √(1 + √(1 + ...))) (бесконечный вложенный корень).
  • Исследуйте, когда √(a + 2√b) можно представить в виде √x + √y с целыми x и y.
