🧠 Блок 1. Изучение

🪝 Разминка: Обратное действие

Представь, что ты умножил число на 3 и получил 15. Как вернуться обратно? Правильно — разделить на 3! В алгебре деление — это действие, обратное умножению. Но есть хитрость: чтобы разделить на дробь, нужно умножить на обратную дробь! Это как «перевернуть» дробь вверх ногами. 🔄

📚 Ключевые термины

Термин Определение простым языком
Деление дробей Действие, при котором первую дробь умножают на дробь, обратную второй.
Обратная дробь Дробь, у которой числитель и знаменатель поменялись местами (например, 35 и 53).
Взаимно обратные дроби Две дроби, произведение которых равно 1 (например, 27 и 72).
Деление на многочлен Многочлен представляют как дробь со знаменателем 1, затем применяют правило деления.
Сокращение После деления всегда проверяй, можно ли сократить результат!
ОДЗ Область допустимых значений: делитель ≠ 0, знаменатели ≠ 0.

⚠️ Главные правила

Правило 1: Деление дробей
Чтобы разделить одну дробь на другую, нужно первую дробь умножить на дробь, обратную второй.
ab : cd = ab · dc = a · db · c
Правило 2: Деление на многочлен
При делении дроби на многочлен этот многочлен записывают в виде дроби со знаменателем 1, а затем применяют правило деления дробей.
ab : c = ab : c1 = ab · 1c = ab · c
Правило 3: Взаимно обратные дроби
Произведение взаимно обратных дробей равно 1. Это помогает проверять деление!
ab · ba = 1

🟢 Базовый уровень

Задание 1 (№134а из учебника)

Выполните деление:

5m6n : 15m8n
Показать подробное решение
Шаг 1: Применяем правило деления дробей: первую дробь умножаем на дробь, обратную второй.
Обратная к 15m8n — это 8n15m.
Шаг 2: Записываем умножение:
5m6n · 8n15m
Шаг 3: Умножаем числители и знаменатели:
Числитель: 5m · 8n = 40mn
Знаменатель: 6n · 15m = 90mn
Шаг 4: Записываем дробь:
40mn90mn
Шаг 5: Сокращаем дробь. Общий множитель: 10mn.
40mn : 10mn = 4
90mn : 10mn = 9
Ответ: 49.
Проверка: Подставим m=3, n=2. Исходная: (15/12) : (45/16) = 1.25 : 2.8125 = 0.444... Ответ: 4/9 ≈ 0.444... Всё верно! ✅
🔵 Средний уровень

Задание 2 (№140б из учебника)

Выполните деление:

5a : 6aba² - b²
Показать подробное решение
Шаг 1: Применяем правило деления. Обратная дробь:
Обратная к 6aba² - b² — это a² - b²6ab.
Шаг 2: Записываем умножение:
5a · a² - b²6ab
Шаг 3: Раскладываем a² - b² как разность квадратов:
a² - b² = (a - b)(a + b)
Шаг 4: Умножаем:
Числитель: 5 · (a - b)(a + b)
Знаменатель: a · 6ab = 6a²b
Шаг 5: Записываем результат:
5(a - b)(a + b)6a²b
Шаг 6: Проверяем сокращение. Общих множителей нет.
Ответ: 5(a - b)(a + b)6a²b (при a ≠ 0, b ≠ 0, a ≠ ±b).
Проверка: Подставим a=2, b=1. Исходная: 5/2 : 12/3 = 2.5 : 4 = 0.625. Ответ: 5·1·3/(6·4·1) = 15/24 = 0.625. Всё верно! ✅
🟣 Продвинутый уровень

Задание 3 (№143а из учебника)

Выполните деление:

3x6y : 5x + 10yy²
Показать подробное решение
Шаг 1: Применяем правило деления. Обратная дробь:
Обратная к 5x + 10yy² — это y²5x + 10y.
Шаг 2: Записываем умножение:
3x6y · y²5x + 10y
Шаг 3: Упрощаем первую дробь:
3x6y = x2y (сократили на 3)
Шаг 4: Раскладываем знаменатель второй дроби:
5x + 10y = 5(x + 2y)
Шаг 5: Умножаем:
x2y · y²5(x + 2y) = x · y²2y · 5(x + 2y)
Шаг 6: Сокращаем y:
y² : y = y
Получаем: xy10(x + 2y)
Ответ: xy10(x + 2y) (при y ≠ 0, x ≠ -2y).
Проверка: Подставим x=2, y=1. Исходная: 6/6 : 20/1 = 1 : 20 = 0.05. Ответ: 2·1/(10·4) = 2/40 = 0.05. Всё верно! ✅

Блок 3. Практическое применение

🚴 Задача для велосипедиста

Велосипедист проехал первые 30 км со скоростью v км/ч, а остальные 17 км — со скоростью на 2 км/ч больше. Время вычисляется по формуле t = s/v. Найди общее время пути t в виде одной дроби и вычисли при v = 15 км/ч.

Показать решение инженера
Шаг 1: Время на первом участке: t₁ = 30/v.
Время на втором участке: t₂ = 17/(v + 2).
Шаг 2: Общее время: t = t₁ + t₂ = 30/v + 17/(v + 2).
Шаг 3: Приводим к общему знаменателю v(v + 2):
30(v + 2)v(v + 2) + 17vv(v + 2)
Шаг 4: Складываем числители:
30(v + 2) + 17v = 30v + 60 + 17v = 47v + 60
Шаг 5: Записываем результат:
t = (47v + 60) / (v(v + 2))
Шаг 6: Подставляем v = 15:
t = (47·15 + 60) / (15·17) = (705 + 60) / 255 = 765 / 255 = 3 часа.
Ответ: t = (47v + 60) / (v(v + 2)) часов. При v = 15: 3 часа.
Проверка: t₁ = 30/15 = 2 ч, t₂ = 17/17 = 1 ч. Всего: 2 + 1 = 3 ч. Всё верно! ‍♂️

🌟 Главное, что нужно запомнить

  • Правило деления: первая дробь × обратная второй дроби.
  • Обратная дробь: числитель и знаменатель меняются местами.
  • Деление на многочлен: представь многочлен как дробь со знаменателем 1.
  • Сокращение: всегда сокращай результат после деления!
  • ⚠️ ОДЗ: делитель ≠ 0, все знаменатели ≠ 0.
  • 💡 Лайфхак: произведение взаимно обратных дробей = 1 (проверка).

💡 Методическая подсказка (для учителя / родителя)

🎯 Типичные ошибки:

  • Забывают «перевернуть»: ученики иногда просто делят числитель на числитель и знаменатель на знаменатель. Напоминайте: умножаем на ОБРАТНУЮ!
  • Путают умножение и деление: при делении на дробь нужно умножать, а не делить. Это частая ошибка.
  • Забытое ОДЗ: при делении на выражение с переменной забывают указать ограничения (делитель ≠ 0).

🪜 Подмостки для слабых учеников:

  • Разрешите сначала записать «переворот» второй дроби отдельно, затем умножать. Это снижает когнитивную нагрузку.
  • Используйте цветные маркеры: первая дробь — синим, обратная второй — красным. Стрелка «переворота» — жёлтым.

🚀 Вызов для сильных учеников:

  • Задача №147 из учебника (задача на движение с течением реки) — требует составления уравнения и проверки ОДЗ.
  • Попросите их доказать, что деление на дробь эквивалентно умножению на обратную через определение деления.
