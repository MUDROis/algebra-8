🧠 Блок 1. Изучение

🪝 Разминка: полное квадратное уравнение — новый противник

На уроке 20 ты расправился с неполными квадратными уравнениями. Но в жизни чаще встречаются полные: все три коэффициента отличны от нуля. Например, площадь прямоугольной площадки со сторонами x и (x + 3) метра описывается уравнением x² + 3x − 154 = 0 — и ни один коэффициент не равен нулю. Как такое решить? Учебник (п. 21) показывает путь: решить уравнение 7x² − 6x − 1 = 0 методом выделения квадрата двучлена.

Как решает учебник: выделение квадрата двучлена
Разделим обе части на 7: x² − (6/7)x − (1/7) = 0 — приведённое квадратное уравнение.
Представим разность x² − (6/7)x в виде x² − 2·(3/7)x, прибавим к ней (3/7)² и тут же вычтем его: x² − 2·(3/7)x + (3/7)² − (3/7)² − 1/7 = 0.
Первые три слагаемых — квадрат двучлена: (x − 3/7)² = (3/7)² + 1/7 = 9/49 + 7/49 = 16/49.
Отсюда x − 3/7 = ±4/7, то есть x = 3/7 + 4/7 = 1 или x = 3/7 − 4/7 = −1/7. Уравнение имеет два корня: −1/7 и 1.

Способ рабочий, но громоздкий: каждый раз делить, подбирать дроби, возводить их в квадрат… Поэтому поступают по-инженерному: решают уравнение ax² + bx + c = 0 в общем виде один раз и получают готовую формулу корней. Подставляй коэффициенты — получай ответ. Проверим её на нашем уравнении: a = 7, b = −6, c = −1. Считаем дискриминант: D = (−6)² − 4·7·(−1) = 36 + 28 = 64, √64 = 8, и корни x = (6 ± 8)/14: это −1/7 и 1 — те же самые, но без выделения квадрата! Сегодня научимся делать это с любым квадратным уравнением.

📚 Ключевые термины

Термин Определение простым языком
Дискриминант Число D = b² − 4ac, которое вычисляют по коэффициентам квадратного уравнения. «Discriminare» по-латыни — «различать»: по знаку D различают, сколько корней у уравнения.
Формула корней квадратного уравнения Формула x = (−b ± √D)/(2a), где D = b² − 4ac. В учебнике она обозначена (I). Работает для любого квадратного уравнения, если D ≥ 0.
Полное квадратное уравнение Уравнение ax² + bx + c = 0, у которого все коэффициенты a, b, c отличны от нуля. Именно для него формула корней главная.
Выделение квадрата двучлена Приём: из трёхчлена получают квадрат суммы или разности «плюс остаток». Так выводится формула корней, но считать им каждый раз неудобно.
Формула (II) с D₁ Удобная формула для уравнений с чётным вторым коэффициентом b = 2k: x = (−k ± √D₁)/a, где D₁ = k² − ac.
Приближённые корни Если √D не извлекается точно, корни вычисляют с калькулятором и округляют до нужной точности (например, до 0,01).

⚠️ Главные правила

Правило 1: Дискриминант (учебник, п. 21).
Для квадратного уравнения ax² + bx + c = 0 (a ≠ 0) число D = b² − 4ac называют дискриминантом квадратного уравнения. Знак D определяется числителем, ведь 4a² > 0 всегда — а значит, именно D решает судьбу корней.
D = b² − 4ac
Правило 2: Формула корней (формула I).
Если D ≥ 0, корни уравнения ax² + bx + c = 0 находят по формуле:
x = −b ± √D2a,   где D = b² − 4ac
Откуда берётся формула. Разделим ax² + bx + c = 0 на a: получим x² + (b/a)x + (c/a) = 0. Выделим квадрат двучлена: прибавим и вычтем (b/(2a))². Получим (x + b/(2a))² = (b² − 4ac)/(4a²), то есть (x + b/(2a))² = D/(4a²). Слева — квадрат числа, справа — дробь со знаменателем 4a² > 0. Дальше всё решает знак D.
Правило 3: Три случая дискриминанта.
• D > 0 — уравнение имеет два корня: x₁ = (−b − √D)/(2a) и x₂ = (−b + √D)/(2a);
• D = 0 — уравнение имеет один корень: x = −b/(2a);
• D < 0 — уравнение не имеет корней: дробь D/(4a²) отрицательна, а квадрат двучлена слева отрицательным быть не может.
Правило 4: Алгоритм (синяя рамка учебника).
При решении квадратного уравнения по формуле (I) целесообразно поступать так:
1) вычислить дискриминант и сравнить его с нулём;
2) если дискриминант положителен или равен нулю — воспользоваться формулой корней; если дискриминант отрицателен — записать, что корней нет.
Правило 5: При D = 0 формула (I) тоже работает.
Подставим D = 0 в формулу: x = (−b ± √0)/(2a) = −b/(2a). Получился тот самый единственный корень. Поэтому достаточно запомнить одну формулу — с «±».
Правило 6: Чётный второй коэффициент — формула (II).
Если уравнение имеет вид ax² + 2kx + c = 0 (второй коэффициент чётный: b = 2k), то при D₁ ≥ 0 его корни находят по формуле x = (−k ± √D₁)/a, где D₁ = k² − ac. Если D₁ < 0 — корней нет. Числа получаются меньше, считать легче.
Правило 7: Сначала — стандартный вид!
Формула работает только для уравнения ax² + bx + c = 0. Если слагаемые перепутаны (1 − 18p + 81p² = 0) или уравнение не доведено до нуля (5x² = 9x + 2), сначала приведи его к стандартному виду и выпиши коэффициенты: a — при x², b — при x, c — свободный член.

🎯 Устная проверка (№ 531 из учебника)

Вычислите дискриминант квадратного уравнения и укажите число его корней. Рассуждай так: подставь a, b и c в формулу D = b² − 4ac, аккуратно следи за знаками и сравни результат с нулём.

Показать ответы устного задания
а) 2x² + 3x + 1 = 0 — D = 3² − 4·2·1 = 9 − 8 = 1 > 0: два корня (это −1/2 и −1).
б) 2x² + x + 2 = 0 — D = 1² − 4·2·2 = 1 − 16 = −15 < 0: корней нет.
в) 9x² + 6x + 1 = 0 — D = 6² − 4·9·1 = 36 − 36 = 0: один корень (это −1/3).
г) x² + 5x − 6 = 0 — D = 5² − 4·1·(−6) = 25 + 24 = 49 > 0: два корня (это −6 и 1).

📐 Работаем с формулой: примеры из учебника

Пример 1 (из учебника). Решим уравнение 12x² + 7x + 1 = 0.
Найдём дискриминант: D = 7² − 4·12·1 = 49 − 48 = 1, D > 0 — два корня. Применим формулу корней: √1 = 1, значит, x = (−7 ± 1)/24. Отсюда x₁ = (−7 − 1)/24 = −8/24 = −1/3 и x₂ = (−7 + 1)/24 = −6/24 = −1/4. Ответ: −1/3; −1/4.

Пример 2 (из учебника). Решим уравнение x² − 12x + 36 = 0.
Имеем D = (−12)² − 4·1·36 = 144 − 144 = 0 — один корень. По формуле: x = (12 − √0)/2 = 12/2 = 6. Ответ: 6.

Пример 3 (из учебника). Решим уравнение 7x² − 25x + 23 = 0.
Имеем D = (−25)² − 4·7·23 = 625 − 644 = −19, D < 0. Ответ: корней нет.

Пример 4 (из учебника, формула II). Решим уравнение 9x² − 14x + 5 = 0.
Второй коэффициент чётный: −14 = 2k, то есть k = −7. Считаем D₁ = k² − ac = (−7)² − 9·5 = 49 − 45 = 4 ≥ 0. По формуле (II): x = (−k ± √D₁)/a = (7 ± 2)/9, откуда x₁ = 5/9 и x₂ = 1. Ответ: 5/9; 1.

Правило 8: Проверка. Найденные корни подставляй в ИСХОДНОЕ уравнение — каждый по очереди. Для Примера 1: 12·(−1/3)² + 7·(−1/3) + 1 = 4/3 − 7/3 + 1 = 0 ✅ и 12·(−1/4)² + 7·(−1/4) + 1 = 3/4 − 7/4 + 1 = 0 ✅.
⚠️ Ловушки формулы. 1) Знак «−b»: если b = −25, в числителе стоит −(−25) = +25 — знак меняется. 2) b² всегда неотрицательно: (−25)² = 625, а не −625. 3) Дели на 2a ВЕСЬ числитель: дробь (−b ± √D)/(2a), а не только −b. 4) Если c < 0, то −4ac = плюс — самая частая ошибка в дискриминанте.

Геометрический смысл: корни уравнения ax² + bx + c = 0 — это абсциссы точек пересечения параболы y = ax² + bx + c с осью x. Дискриминант «различает», сколько таких точек: две, одна или ни одной.

От теории к практике! Решаем задачи из учебника (§ 7, п. 21). Порядок один: стандартный вид → коэффициенты a, b, c → дискриминант D → формула корней → проверка.

🟢 Базовый уровень

Задание 1 (№ 532 а)

Решите уравнение: 3x² − 7x + 4 = 0

Показать подробное решение
Шаг 1: Коэффициенты: a = 3, b = −7, c = 4. Все отличны от нуля — полное квадратное уравнение.
Шаг 2: Дискриминант: D = (−7)² − 4·3·4 = 49 − 48 = 1. D > 0 — уравнение имеет два корня.
Шаг 3: √1 = 1. По формуле x = (−b ± √D)/(2a) = (7 ± 1)/6: x₁ = (7 − 1)/6 = 6/6 = 1, x₂ = (7 + 1)/6 = 8/6 = 4/3 = 1⅔.
Проверка: 3·1² − 7·1 + 4 = 0 ✅; 3·(4/3)² − 7·(4/3) + 4 = 16/3 − 28/3 + 12/3 = 0 ✅
Ответ: x₁ = 1; x₂ = 4/3 ✅

Задание 2 (№ 532 б)

Решите уравнение: 5x² − 8x + 3 = 0

Показать подробное решение
Шаг 1: Коэффициенты: a = 5, b = −8, c = 3.
Шаг 2: D = (−8)² − 4·5·3 = 64 − 60 = 4 > 0 — два корня, √4 = 2.
Шаг 3: x = (8 ± 2)/10: x₁ = (8 − 2)/10 = 6/10 = 0,6, x₂ = (8 + 2)/10 = 10/10 = 1.
Проверка: 5·(0,6)² − 8·0,6 + 3 = 1,8 − 4,8 + 3 = 0 ✅; 5·1 − 8 + 3 = 0 ✅
Ответ: x₁ = 0,6; x₂ = 1 ✅

Задание 3 (№ 532 г)

Решите уравнение: 2y² − 9y + 10 = 0

Показать подробное решение
Шаг 1: Коэффициенты: a = 2, b = −9, c = 10 (переменная y — это не важно, формула та же).
Шаг 2: D = (−9)² − 4·2·10 = 81 − 80 = 1 > 0 — два корня, √1 = 1.
Шаг 3: y = (9 ± 1)/4: y₁ = (9 − 1)/4 = 8/4 = 2, y₂ = (9 + 1)/4 = 10/4 = 2,5.

Задание 4 (№ 533 г)

Решите уравнение: 1 − 18p + 81p² = 0

Показать подробное решение
Шаг 1: Приведём к стандартному виду: 81p² − 18p + 1 = 0. Теперь коэффициенты: a = 81, b = −18, c = 1. (Осторожно: a — это коэффициент при p², то есть 81, а не 1!)
Шаг 2: D = (−18)² − 4·81·1 = 324 − 324 = 0 — один корень.
Шаг 3: p = −b/(2a) = 18/162 = 1/9. (По формуле (II): b = 2k = −18, k = −9, D₁ = 81 − 81 = 0, p = 9/81 = 1/9 — тот же ответ.)
Проверка: 1 − 18·(1/9) + 81·(1/81) = 1 − 2 + 1 = 0 ✅
Ответ: p = 1/9 ✅

Задание 5 (№ 532 ж)

Решите уравнение: y² − 10y − 24 = 0

Показать подробное решение
Шаг 1: Коэффициенты: a = 1, b = −10, c = −24.
Шаг 2: D = (−10)² − 4·1·(−24) = 100 + 96 = 196 > 0 — два корня. Не забудь: c = −24, поэтому −4ac = +96!
Шаг 3: √196 = 14. y = (10 ± 14)/2: y₁ = (10 − 14)/2 = −4/2 = −2, y₂ = (10 + 14)/2 = 24/2 = 12.
Проверка: (−2)² − 10·(−2) − 24 = 4 + 20 − 24 = 0 ✅; 12² − 10·12 − 24 = 144 − 120 − 24 = 0 ✅
Ответ: y₁ = −2; y₂ = 12 ✅

Задание 6 (№ 533 б)

Решите уравнение: −y² + 3y + 5 = 0

Показать подробное решение
Шаг 1: Умножим обе части на −1 (знак у всех слагаемых сменится, а корни не изменятся): y² − 3y − 5 = 0. Так удобнее: a = 1, b = −3, c = −5.
Шаг 2: D = (−3)² − 4·1·(−5) = 9 + 20 = 29 > 0 — два корня.
Шаг 3: Число 29 не извлекается как точный квадрат: √29 ≈ 5,385 (проверь калькулятором). y = (3 ± √29)/2: y₁ = (3 − 5,385)/2 ≈ −1,19, y₂ = (3 + 5,385)/2 ≈ 4,19.
Проверка: −(4,1926)² + 3·4,1926 + 5 ≈ −17,578 + 12,578 + 5 ≈ 0 ✅ (для y₁ ≈ −1,19 — так же)
Ответ: y₁ = (3 − √29)/2 ≈ −1,19; y₂ = (3 + √29)/2 ≈ 4,19 ✅

Задание 7 (№ 537 а, формула II)

Решите уравнение, используя формулу (II): 3x² − 14x + 16 = 0

Показать подробное решение
Шаг 1: Второй коэффициент чётный: −14 = 2k, значит k = −7. Уравнение имеет вид ax² + 2kx + c = 0.
Шаг 2: D₁ = k² − ac = (−7)² − 3·16 = 49 − 48 = 1 ≥ 0 — корни есть.
Шаг 3: x = (−k ± √D₁)/a = (7 ± 1)/3: x₁ = (7 − 1)/3 = 6/3 = 2, x₂ = (7 + 1)/3 = 8/3 = 2⅔.
Проверка: 3·2² − 14·2 + 16 = 12 − 28 + 16 = 0 ✅; 3·(8/3)² − 14·(8/3) + 16 = 64/3 − 112/3 + 48/3 = 0 ✅
Ответ: x₁ = 2; x₂ = 8/3 ✅

Задание 8 (№ 540 а)

Решите уравнение: 5x² = 9x + 2

Показать подробное решение
Шаг 1: Приведём к стандартному виду — перенесём 9x + 2 влево: 5x² − 9x − 2 = 0. Коэффициенты: a = 5, b = −9, c = −2.
Шаг 2: D = (−9)² − 4·5·(−2) = 81 + 40 = 121 > 0 — два корня, √121 = 11.
Шаг 3: x = (9 ± 11)/10: x₁ = (9 − 11)/10 = −2/10 = −0,2, x₂ = (9 + 11)/10 = 20/10 = 2.

Ответ: x₁ = −0,2; x₂ = 2 ✅

⚽ Задача для спортивного инженера

Футболист пробивает штрафной, и высота полёта мяча меняется по закону h(t) = 20t − 5t², где t — время в секундах, h — высота в метрах (g ≈ 10 м/с²). В какие моменты времени мяч окажется на высоте 15 м?

Показать решение инженера
Шаг 1: Подставим h = 15 в закон полёта: 20t − 5t² = 15. Перенесём всё влево: −5t² + 20t − 15 = 0.
Шаг 2: Умножим обе части на −1 и разделим на 5: t² − 4t + 3 = 0. Коэффициенты: a = 1, b = −4, c = 3.
Шаг 3: D = (−4)² − 4·1·3 = 16 − 12 = 4 > 0 — два корня. √4 = 2, t = (4 ± 2)/2: t₁ = (4 − 2)/2 = 1, t₂ = (4 + 2)/2 = 3.
Шаг 4: Оба корня имеют смысл! Мяч пролетает отметку 15 м дважды: на подъёме (через 1 с) и на спуске (через 3 с).
Проверка: h(1) = 20·1 − 5·1² = 15 м ✅; h(3) = 20·3 − 5·3² = 60 − 45 = 15 м ✅
Ответ: через 1 с (вверх) и через 3 с (вниз) ✅

🖥 Задача для IT-дизайнера

Дизайнер интерфейсов готовит баннер для сайта: его ширина на 3 см больше высоты, а площадь равна 40 см². Найдите размеры баннера.

Показать решение дизайнера
Шаг 1: Пусть высота равна x см, тогда ширина равна (x + 3) см. Площадь: x·(x + 3) = 40.
Шаг 2: Раскроем скобки и перенесём всё влево: x² + 3x − 40 = 0. Коэффициенты: a = 1, b = 3, c = −40.
Шаг 3: D = 3² − 4·1·(−40) = 9 + 160 = 169 > 0 — два корня. √169 = 13, x = (−3 ± 13)/2: x₁ = (−3 − 13)/2 = −8, x₂ = (−3 + 13)/2 = 5.
Шаг 4: Корень x = −8 не подходит по смыслу задачи: высота не может быть отрицательной. Значит, высота 5 см, а ширина 5 + 3 = 8 см.
Проверка: 5 · 8 = 40 см² ✅; ширина 8 на 3 больше высоты 5 ✅
Ответ: высота — 5 см, ширина — 8 см ✅

🌟 Главное, что нужно запомнить

  • Дискриминант: D = b² − 4ac для уравнения ax² + bx + c = 0 (a ≠ 0). «Различитель»: по знаку D различают число корней.
  • Формула корней (I): x = (−b ± √D)/(2a) при D ≥ 0. Она работает для любого квадратного уравнения — и полного, и неполного.
  • Три случая: D > 0 — два корня; D = 0 — один корень x = −b/(2a); D < 0 — корней нет.
  • Алгоритм: стандартный вид → a, b, c → D = b² − 4ac → сравнить с нулём → формула или «корней нет».
  • Чётный b = 2k: формула (II): D₁ = k² − ac, x = (−k ± √D₁)/a — числа мельче, считать проще.
  • Неточный корень: если √D не извлекается, вычисляй приближённо с калькулятором и округляй до нужной точности.
  • Проверка: подставь каждый корень в исходное уравнение — должно получиться верное равенство.
  • 💡 Лайфхак: b² не зависит от знака b: (−25)² = 625. А вот при c < 0 слагаемое −4ac становится положительным — не потеряй эти плюсы в дискриминанте.

💡 Методическая подсказка (для учителя / родителя)

🎯 Типичные ошибки:

  • Знак «−b»: при b = −7 ученики пишут в числителе −7 вместо −(−7) = 7. Отрабатывайте подстановку с отрицательными b отдельно.
  • Ошибка в −4ac: при c < 0 произведение −4ac положительно, а при b < 0 квадрат (−b)² положителен. Потеря этих плюсов — причина № 1 «пропавших» корней.
  • Деление только числителя: запись x = −b ± √D/2a без скобок ведёт к ошибке. Требуйте дробную черту под всем числителем.
  • «Корни» из отрицательного числа: при D < 0 пишут ±√(−19). Напомните: квадрат числа не бывает отрицательным.
  • Пропуск стандартного вида: в уравнении 1 − 18p + 81p² = 0 берут a = 1, b = −18, c = 81, хотя a = 81 — коэффициент при p².
  • Раннее округление: при неточном √D округляйте только окончательный ответ, иначе погрешность растёт.

🪜 Подмостки для слабых учеников:

  • Алгоритм-памятка из четырёх шагов: стандартный вид → выпиши a, b, c → вычисли D = b² − 4ac → сравни с нулём и примени формулу.
  • Карточка-шпаргалка с формулой (I) на парте; b подчёркивайте голубым, 4ac — красным, как в схеме урока.
  • Начинайте с уравнений, где D — точный квадрат (№ 532), и лишь затем переходите к №№ 533, 545 с иррациональными корнями.
  • Повторите таблицу квадратов до 20² = 400 — это ускоряет вычисление D в разы.

🚀 Вызов для сильных учеников:

  • Задача-исследование № 552: сравните корни уравнений ax² + bx + c = 0 и cx² + bx + a = 0. Например, x² − 5x + 6 = 0 имеет корни 2 и 3, а 6x² − 5x + 1 = 0 — корни 1/2 и 1/3. Гипотеза: корни «перевёрнутого» уравнения обратны исходным. Проверьте на 2x² − 13x + 6 = 0 и 6x² − 13x + 2 = 0 и докажите её.
  • № 553: существует ли значение a, при котором уравнение x² − ax + a − 4 = 0 не имеет корней или имеет один корень? Ответ: нет — D = a² − 4a + 16 = (a − 2)² + 12 > 0 при любом a, поэтому корней всегда два.
  • № 547: решите уравнение x² = 0,5x + 3 сначала графически, затем по формуле (ответ: 2 и −1,5; D = 12,25 — точный квадрат 3,5²). Сравните оба способа.
  • № 536 б: при каких значениях x трёхчлены 3x² − 4x + 3 и x² + x + 1 принимают равные значения? (Ответ: x = 1/2 и x = 2.)
