🧠 Изучение нового материала

👋 Привет! Сегодня применим наш алгоритм описания свойств к двум важнейшим функциям — обратной пропорциональности $y = \dfrac{k}{x}$ и квадратному корню $y = \sqrt{x}$.

📈 Функция $y = \dfrac{k}{x}$ ($k \ne 0$)

Свойства функции $y = \dfrac{k}{x}$:
1. Функция определена при любых значениях аргумента, кроме нуля: $D(y) = (-\infty;\ 0) \cup (0;\ +\infty)$.
2. Значением функции может быть любое число, кроме нуля: $E(y) = (-\infty;\ 0) \cup (0;\ +\infty)$.
3. Функция нулей не имеет — дробь $\dfrac{k}{x}$ при $k \ne 0$ ни при каком $x$ не обращается в нуль.
4. При $k > 0$ функция принимает отрицательные значения на $(-\infty;\ 0)$ и положительные на $(0;\ +\infty)$; при $k < 0$ — наоборот.
5. При $k > 0$ функция убывает на каждом из промежутков $(-\infty;\ 0)$ и $(0;\ +\infty)$; при $k < 0$ — возрастает на каждом из них.
Обоснование знака: при $k > 0$ дробь $\dfrac{k}{x}$ отрицательна при $x < 0$ (минус на плюс) и положительна при $x > 0$ (плюс на плюс). При $k < 0$ — наоборот.

⚠️ Очень важное замечание! Хотя функция $y = \dfrac{k}{x}$ убывает (или возрастает) на каждом из промежутков $(-\infty;\ 0)$ и $(0;\ +\infty)$ по отдельности, она не является ни убывающей, ни возрастающей на всей области определения. Например, при $k = 1$: $f(-1) = -1$, а $f(1) = 1$ — при переходе через нуль значения «перепрыгивают». Функция не является монотонной на всей области определения!

📈 Функция $y = \sqrt{x}$

Свойства функции $y = \sqrt{x}$:
1. Функция определена при любых неотрицательных значениях аргумента: $D(y) = [0;\ +\infty)$.
2. Функция принимает только неотрицательные значения, причём любое неотрицательное число может являться её значением: $E(y) = [0;\ +\infty)$.
3. Функция обращается в нуль при $x = 0$.
4. Функция является возрастающей.
Доказательство возрастания. Пусть $x_1$ и $x_2$ — произвольные значения аргумента, причём $x_2 > x_1 \ge 0$. Рассмотрим разность:
$\sqrt{x_2} - \sqrt{x_1} = \dfrac{(\sqrt{x_2} - \sqrt{x_1})(\sqrt{x_2} + \sqrt{x_1})}{\sqrt{x_2} + \sqrt{x_1}} = \dfrac{x_2 - x_1}{\sqrt{x_2} + \sqrt{x_1}}$.
Так как $x_2 - x_1 > 0$ и $\sqrt{x_2} + \sqrt{x_1} > 0$, разность положительна: $\sqrt{x_2} > \sqrt{x_1}$. Значит, функция возрастает. ∎

🛠 Закрепление

Реши задачи, а затем нажми на них, чтобы проверить себя. Помни: у $y = k/x$ области определения и значений «выколоты» нулём, а у $y = \sqrt{x}$ всё начинается с нуля!

🟢 База №1127. Какие из прямых y = 25, y = 0,09, y = −10 пересекают график функции y = √x? Укажи абсциссы точек пересечения

Решение:

1. Так как $\sqrt{x} \ge 0$, горизонтальная прямая $y = a$ пересекает график, только если $a \ge 0$.

2. $y = 25$: $\sqrt{x} = 25 \Rightarrow x = 625$ — пересекает.

3. $y = 0{,}09$: $\sqrt{x} = 0{,}09 \Rightarrow x = 0{,}0081$ — пересекает.

4. $y = -10$: $\sqrt{x} = -10$ не имеет решений — не пересекает. ✅

🟢 База №1130(а). Дана функция f(x) = √x. Укажи x, при которых f(x) = 10

Решение:

$\sqrt{x} = 10 \Rightarrow x = 100$. ✅

🔵 Средний №1130(б). Укажи x, при которых 3 < f(x) < 5 для f(x) = √x

Решение:

$3 < \sqrt{x} < 5$ — возведём все части в квадрат (все части неотрицательны, знаки сохраняются):
$9 < x < 25$. ✅

🔵 Средний №1133. Функция y = 16/x. При каких x: а) y = 8; y = −8; б) y < 4; в) y > 2?

Решение:

а) $\dfrac{16}{x} = 8 \Rightarrow x = 2$; $\dfrac{16}{x} = -8 \Rightarrow x = -2$.

б) $\dfrac{16}{x} < 4$: при $x > 0$: $16 < 4x \Rightarrow x > 4$; при $x < 0$: $\dfrac{16}{x} < 0 < 4$ — выполняется всегда. Итого: $x < 0$ или $x > 4$.

в) $\dfrac{16}{x} > 2$: при $x > 0$: $16 > 2x \Rightarrow x < 8$; при $x < 0$: $\dfrac{16}{x} < 0$ — не может быть больше 2. Итого: $0 < x < 8$.

🟣 Продвинутый №1134. Является ли возрастающей или убывающей функция: а) y = 5x + 6; б) y = 1/x; в) y = 1/(x + 5)?

Решение:

а) $y = 5x + 6$: коэффициент $k = 5 > 0$ — возрастающая (на всей прямой).

б) $y = \dfrac{1}{x}$: это $y = \dfrac{k}{x}$ при $k = 1 > 0$ — убывает на каждом из промежутков $(-\infty;\ 0)$ и $(0;\ +\infty)$ (но не на всей области определения!).

в) $y = \dfrac{1}{x+5}$: сдвиг гиперболы влево на 5. Область определения: $x \ne -5$. На каждом из промежутков $(-\infty;\ -5)$ и $(-5;\ +\infty)$ функция убывает (как и при $k = 1 > 0$). ✅

🏗 Практика: задача из реальной жизни (STEAM)

🚀 Физика и электротехника: По закону Ома для участка цепи сила тока зависит от сопротивления проводника: $I = \dfrac{U}{R}$, где $U$ — напряжение (В), $R$ — сопротивление (Ом).

Вопрос: Пусть $U = 220$ В. а) Найди силу тока при $R = 10$ Ом и $R = 100$ Ом; б) при каком сопротивлении ток будет равен 5 А? в) Используя свойства функции $I(R)$, ответь: как изменится ток при увеличении сопротивления?

Показать пошаговое решение

Решение:

а) $I = \dfrac{220}{10} = 22$ А; $I = \dfrac{220}{100} = 2{,}2$ А.

б) $\dfrac{220}{R} = 5 \Rightarrow R = 44$ Ом.

в) $I(R) = \dfrac{220}{R}$ — обратная пропорциональность с $k = 220 > 0$. При $R > 0$ функция убывает: с увеличением сопротивления сила тока уменьшается.

💡 Проверка: при $R = 10$ Ом ток 22 А, при $R = 100$ Ом — 2,2 А: действительно меньше. Область определения: $R > 0$; множество значений: $I > 0$. ✅

📝 Итоги урока

Главное запомнить:

  • $y = \dfrac{k}{x}$: $D(y) = E(y) = (-\infty;\ 0) \cup (0;\ +\infty)$; нулей нет.
  • При $k > 0$ гипербола убывает на каждом промежутке; при $k < 0$ — возрастает на каждом промежутке. Но на всей области определения функция не монотонна!
  • $y = \sqrt{x}$: $D(y) = E(y) = [0;\ +\infty)$; нуль при $x = 0$; функция возрастает.
  • Доказательство возрастания $\sqrt{x}$ — через умножение на сопряжённое выражение.
  • Обратная пропорциональность описывает множество реальных зависимостей: $I = U/R$, $t = s/v$, $p = m/V$.

💡 Методическая подсказка для учителя

Ключевой момент урока — «ловушка» монотонности: функция $y = k/x$ убывает (или возрастает) на каждом из промежутков по отдельности, но не является монотонной на всей области определения. Это тонкое различие вызывает много ошибок; обязательно разберите пример $f(-1) = -1$, $f(1) = 1$ при $k = 1$ — определение монотонности на промежутке требует, чтобы оба значения лежали в одном промежутке. Для доказательства возрастания $\sqrt{x}$ покажите приём умножения на сопряжённое выражение — он пригодится в дальнейшем (иррациональные неравенства).
