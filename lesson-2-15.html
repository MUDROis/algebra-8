✖️➗ Квадратный корень из произведения и дроби

Глава 2, § 15

🧠 Блок 1. Изучение нового

🪝 Разминка: два волшебных свойства

Сравни: √(81·4) и √81 · √4.
√(81·4) = √324 = 18
√81 · √4 = 9 · 2 = 18
Результаты совпадают! Это не случайность — это теорема, которая превращает сложные корни в простые. Сегодня мы докажем её и научимся применять! 🔑

📘 Теорема 1. Корень из произведения

ТЕОРЕМА 1

Если a ≥ 0 и b ≥ 0, то

√(a·b) = √a · √b

Словами: корень из произведения неотрицательных множителей равен произведению корней из этих множителей.

Доказательство. Нужно проверить два условия:
① √a · √b ≥ 0 — верно, так как оба корня неотрицательны.
② (√a · √b)² = (√a)² · (√b)² = a · b — верно.
По определению арифметического квадратного корня, теорема доказана. ✅
💡 Теорема распространяется на любое число множителей:
√(a·b·c) = √a · √b · √c (при a ≥ 0, b ≥ 0, c ≥ 0)

📘 Теорема 2. Корень из дроби

ТЕОРЕМА 2

Если a ≥ 0 и b > 0, то

√(a/b) = √a / √b

Словами: корень из дроби, числитель которой неотрицателен, а знаменатель положителен, равен корню из числителя, делённому на корень из знаменателя.

📘 Примеры из учебника

Пример 1. √(64 · 0,04)
= √64 · √0,04 = 8 · 0,2 = 1,6 ✅
Пример 2. √(32 · 98)
Разкладываем на полные квадраты:
32 = 16 · 2, 98 = 49 · 2
√(32·98) = √(16·2·49·2) = √(16·49·4) = 4 · 7 · 2 = 56 ✅
Пример 3. √(36/169)
= √36 / √169 = 6/13 ✅
Пример 4. √20 · √5
= √(20·5) = √100 = 10 ✅
Пример 5. √80 / √5
= √(80/5) = √16 = 4 ✅
Пример 6. √11025
Разкладываем: 11025 = 9 · 25 · 49
√11025 = √9 · √25 · √49 = 3 · 5 · 7 = 105 ✅
⚠️ Обрати внимание: теоремы работают только для неотрицательных множителей!
√(−4 · 9) ≠ √(−4) · √9 — так делать нельзя!
Правильно: √(−4 · 9) не существует, так как −36 < 0.

🟢 Базовый Задание 1 (№ 362 из учебника)

Найдите значение выражения:

а) √(100·49)    б) √(81·400)    в) √(64·121)    г) √(144·0,25)    д) √(0,01·169)    е) √(2,25·0,04)
Показать решение
а) √(100·49) = √100 · √49 = 10 · 7 = 70 ✅
Проверка: 70² = 4900 = 100·49 ✅
б) √(81·400) = √81 · √400 = 9 · 20 = 180 ✅
Проверка: 180² = 32400 = 81·400 ✅
в) √(64·121) = √64 · √121 = 8 · 11 = 88 ✅
Проверка: 88² = 7744 = 64·121 ✅
г) √(144·0,25) = √144 · √0,25 = 12 · 0,5 = 6 ✅
Проверка: 6² = 36 = 144·0,25 ✅
д) √(0,01·169) = √0,01 · √169 = 0,1 · 13 = 1,3 ✅
Проверка: 1,3² = 1,69 = 0,01·169 ✅
е) √(2,25·0,04) = √2,25 · √0,04 = 1,5 · 0,2 = 0,3 ✅
Проверка: 0,3² = 0,09 = 2,25·0,04 ✅

Ответы: 70; 180; 88; 6; 1,3; 0,3. Всё верно! ✅

🔵 Средний Задание 2 (№ 367 из учебника)

Вычислите значение корня (нужно разложить на множители):

а) √(810·40)    б) √(10·250)    в) √(72·32)    г) √(8·98)
Показать решение
а) √(810·40)
Раскладываем: 810 = 81·10, 40 = 4·10
√(81·10·4·10) = √(81·4·100) = 9·2·10 = 180 ✅
Проверка: 180² = 32400 = 810·40 ✅
б) √(10·250)
= √2500 = 50 ✅
Проверка: 50² = 2500 = 10·250 ✅
в) √(72·32)
Раскладываем: 72 = 36·2, 32 = 16·2
√(36·2·16·2) = √(36·16·4) = 6·4·2 = 48 ✅
Проверка: 48² = 2304 = 72·32 ✅
г) √(8·98)
Раскладываем: 8 = 4·2, 98 = 49·2
√(4·2·49·2) = √(4·49·4) = 2·7·2 = 28 ✅
Проверка: 28² = 784 = 8·98 ✅

Ответы: 180; 50; 48; 28. Отлично! ✅

🟣 Продвинутый Задание 3 (№ 369 + № 368 из учебника)

Вычислите:

а) √(13² − 12²)    б) √(8² + 6²)    в) √(75·48)
Показать решение
а) √(13² − 12²)
Используем формулу разности квадратов:
13² − 12² = (13−12)(13+12) = 1·25 = 25
√25 = 5 ✅
Проверка: 169 − 144 = 25, √25 = 5 ✅
б) √(8² + 6²)
= √(64 + 36) = √100 = 10 ✅
Проверка: 10² = 100 = 64+36 ✅
в) √(75·48)
Раскладываем: 75 = 25·3, 48 = 16·3
√(25·3·16·3) = √(25·16·9) = 5·4·3 = 60 ✅
Проверка: 60² = 3600 = 75·48 ✅

Ответы: 5; 10; 60. Блестяще! 🏆

🏗 Блок 3. Практическое применение

👷 Задача для архитектора: диагональ окна

Архитектор проектирует прямоугольное окно со сторонами 6 м и 8 м. Для установки диагональной перемычки нужно найти длину диагонали. Также нужно проверить, поместится ли окно в проём шириной 11 м при наклоне.

Показать решение архитектора
Шаг 1. По теореме Пифагора диагональ прямоугольника:
d = √(a² + b²)
Шаг 2. Подставляем a = 6, b = 8:
d = √(6² + 8²) = √(36 + 64) = √100
Шаг 3. Вычисляем:
d = √100 = 10 м
Шаг 4. Проверка ширины проёма:
Диагональ = 10 м
Ширина проёма = 11 м
10 < 11 → окно поместится при наклоне ✅
Шаг 5. Проверка:
6² + 8² = 36 + 64 = 100
√100 = 10 ✅
10² = 100 ✅

Ответ: диагональ окна = 10 м. Окно поместится в проём шириной 11 м. 🏗️

🌍 Где ещё нужны корни из произведений?
• Строительство: диагонали, площади, объёмы d = √(a²+b²)
• Физика: кинетическая энергия E = mv²/2 → v = √(2E/m)
• Электротехника: импеданс Z = √(R² + X²)
• География: расстояние между точками на плоскости d = √((x₂−x₁)² + (y₂−y₁)²)

🌟 Главное, что нужно запомнить

  • ✅ Теорема 1: √(a·b) = √a · √b при a ≥ 0, b ≥ 0.
  • ✅ Теорема 2: √(a/b) = √a / √b при a ≥ 0, b > 0.
  • ✅ Теоремы работают в обе стороны:
    √a · √b = √(a·b) и √a / √b = √(a/b).
  • ✅ Для упрощения раскладываем подкоренное выражение на полные квадраты: √72 = √(36·2) = 6√2.
  • ✅ Теорема о корне из произведения распространяется на любое число множителей.
  • ✅ Для разности квадратов: √(a²−b²) = √((a−b)(a+b)).
  • 💡 Лайфхак: если под корнем большое число — разложи его на простые множители и вынеси полные квадраты!

💡 Методическая подсказка (для учителя / родителя)

Типичные ошибки:

  • Применяют теорему к отрицательным множителям: √(−4·9) ≠ √(−4)·√9.
  • Путают √(a+b) и √a + √b — это разные вещи! Теорема работает только для произведения.
  • Забывают, что знаменатель должен быть строго положительным (b > 0, а не b ≥ 0).
  • При разложении на множители пропускают полные квадраты.

🪜 Подмостки для слабых учеников:

  • Дайте таблицу квадратов 1² … 20² для быстрого поиска.
  • Начните с полных квадратов: √(4·9), √(16·25), √(36·49).
  • Используйте алгоритм: «Разложи → Найди полные квадраты → Вынеси».
  • Разрешите калькулятор для проверки, но требуйте ручное разложение.
