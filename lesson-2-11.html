🌿 Квадратные корни. Арифметический квадратный корень

Глава 2, § 11

🧠 Блок 1. Изучение нового

🪝 Разминка: задача о площади квадрата

Площадь квадрата равна 64 см². Чему равна его сторона?

Обозначим сторону x см. Тогда площадь: x² = 64.
Корни уравнения: x = 8 и x = −8.
Но длина не может быть отрицательной! Значит, сторона = 8 см.

Вот так мы пришли к понятию арифметического квадратного корня — это неотрицательный корень. 🌱

📌 Ключевые понятия

ПонятиеОпределениеПример
Квадратный корень из a Число, квадрат которого равен a Корни из 64: это 8 и −8
Арифметический квадратный корень Неотрицательное число, квадрат которого равен a √64 = 8
Радикал Знак √ (от лат. radix — корень) В выражении √25 знак радикала — это √
Подкоренное выражение Выражение, стоящее под знаком радикала В √(x+3) подкоренное выражение — x + 3
Определение: √a = b означает, что выполняются два условия:
① b ≥ 0 (число неотрицательное)
② b² = a (квадрат равен подкоренному выражению)
⚠️ Важно: при a < 0 выражение √a не имеет смысла, потому что не существует числа, квадрат которого отрицателен. Например, √(−4) — не существует!

📘 Пример 1. Нахождение арифметических квадратных корней

√4 = 2, так как 2 ≥ 0 и 2² = 4 ✅
√1,21 = 1,1, так как 1,1 ≥ 0 и 1,1² = 1,21 ✅
√0 = 0, так как 0 ≥ 0 и 0² = 0 ✅

📘 Пример 2. Решение уравнения с квадратным корнем

Решим уравнение: √(5x − 1) = 7

Шаг 1. Из определения арифметического квадратного корня следует, что подкоренное выражение равно квадрату правой части:
5x − 1 = 7²
5x − 1 = 49
Шаг 2. Решаем линейное уравнение:
5x = 50
x = 10
Шаг 3. Проверка:
√(5·10 − 1) = √49 = 7 ✅
Ответ: x = 10

📘 Пример 3. Когда выражение не имеет смысла

Выясним, при каких выражениях корень не существует:

√100 = 10 — имеет смысл ✅
√(−100) — не имеет смысла ❌ (подкоренное выражение отрицательное)
−√100 = −10 — имеет смысл ✅ (минус перед корнем, а не под ним)
√(−10)² = √100 = 10 — имеет смысл ✅ (сначала возводим в квадрат)
√((−25)·(−4)) = √100 = 10 — имеет смысл ✅
√(−25·4) = √(−100) — не имеет смысла ❌

🔵 Средний Задание 2 (№ 294 из учебника)

Найдите значение выражения:

а) √x + √9 при x = 25 и при x = 0,36
б) √(4 − 2a) при a = 2 и при a = −22,5
Показать решение
а) √x + √9
При x = 25: √25 + √9 = 5 + 3 = 8 ✅
При x = 0,36: √0,36 + √9 = 0,6 + 3 = 3,6 ✅
б) √(4 − 2a)
При a = 2: √(4 − 4) = √0 = 0 ✅
При a = −22,5: √(4 − 2·(−22,5)) = √(4 + 45) = √49 = 7 ✅

Ответы: а) 8 и 3,6; б) 0 и 7. Отлично! ✅

🟣 Продвинутый Задание 3 (№ 307 из учебника)

Решите уравнение:

а) √(3x − 1) = 1    б) √(6x + 4) = 2    в) √(12 − x) = 6    г) √(8x − 1) = 1
Показать решение
а) √(3x − 1) = 1
Возводим обе части в квадрат: 3x − 1 = 1
3x = 2 → x = 2/3
Проверка: √(3·(2/3) − 1) = √(2 − 1) = √1 = 1 ✅
б) √(6x + 4) = 2
6x + 4 = 4
6x = 0 → x = 0
Проверка: √(0 + 4) = √4 = 2 ✅
в) √(12 − x) = 6
12 − x = 36
−x = 24 → x = −24
Проверка: √(12 − (−24)) = √36 = 6 ✅
г) √(8x − 1) = 1
8x − 1 = 1
8x = 2 → x = 0,25
Проверка: √(8·0,25 − 1) = √(2 − 1) = √1 = 1 ✅

Ответы: а) x = 2/3; б) x = 0; в) x = −24; г) x = 0,25. Ты справился! 🎉

🏗 Блок 3. Практическое применение

👷 Задача для ландшафтного дизайнера

Дизайнер планирует выложить квадратную площадку из тротуарной плитки. Площадь площадки — 12,25 м². Найдите длину стороны площадки и определите, сколько погонных метров бордюра нужно закупить для ограждения.

Показать решение дизайнера
Шаг 1. Сторона квадрата равна арифметическому квадратному корню из площади:
a = √S = √12,25
Шаг 2. Находим корень:
√12,25 = 3,5, так как 3,5² = 12,25 ✅
Шаг 3. Сторона площадки: a = 3,5 м
Шаг 4. Периметр (длина бордюра):
P = 4a = 4 · 3,5 = 14 м
Шаг 5. Проверка:
3,5² = 12,25 ✅
4 · 3,5 = 14 ✅

Ответ: сторона площадки 3,5 м, бордюра нужно 14 м. Дизайнер доволен! 🌳

🌍 Где ещё нужны квадратные корни?
• Строительство: расчёт диагоналей, проверка прямых углов
• Физика: скорость, ускорение, время падения t = √(2h/g)
• География: расчёт расстояния до горизонта d ≈ √(2Rh)
• IT: алгоритмы машинного обучения, обработка изображений

🌟 Главное, что нужно запомнить

  • ✅ Квадратный корень из числа a — это число, квадрат которого равен a.
  • ✅ Арифметический квадратный корень — это неотрицательное число, квадрат которого равен a. Обозначается √a.
  • ✅ Два условия: √a = b означает b ≥ 0 и b² = a.
  • ✅ При a < 0 выражение √a не имеет смысла.
  • ✅ Для решения уравнения √(f(x)) = c (где c ≥ 0) возводим обе части в квадрат: f(x) = c².
  • ✅ Минус перед корнем допустим: −√9 = −3. Минус под корнем — нет: √(−9) не существует.
  • 💡 Лайфхак: после возведения в квадрат всегда делай подстановку ответа в исходное уравнение!

💡 Методическая подсказка (для учителя / родителя)

Типичные ошибки:

  • Путают квадратный корень и арифметический квадратный корень: уравнение x² = 25 имеет два корня (±5), а √25 = 5 — только один.
  • Забывают, что подкоренное выражение должно быть ≥ 0.
  • При решении уравнений возводят в квадрат, но не проверяют, что правая часть была неотрицательной.
  • Путают √(a + b) и √a + √b — это разные вещи!

🪜 Подмостки для слабых учеников:

  • Дайте таблицу квадратов (1² … 20²) — пусть ищут корни по ней.
  • Начните с числовых примеров: √16, √25, √0,49, потом переходите к буквенным.
  • Используйте цветные маркеры: один цвет для подкоренного выражения, другой — для результата.

🚀 Вызов для сильных учеников:

  • № 298 из учебника: определите, какие из данных корней являются рациональными, а какие — иррациональными.
  • № 308 из учебника: уравнения вида √(12 + x) − 7 = 3.
  • № 299 из учебника: приведите контрпример для утверждения об иррациональности.
  • Попросите доказать: √2 — иррациональное число (связь с уроком § 10).
