Для тех, кто хочет знать больше: Свойства числовых неравенств

Урок 35 • Глава IV, §11

📖 Материал по учебнику «Алгебра 8 класс» (§ 11, п. 35). Навигация — внизу страницы, полный список уроков — на главной странице курса.

🧠 Изучение нового материала

👋 Привет! На прошлом уроке мы познакомились с самим понятием числового неравенства. Сегодня мы изучим инструментарий, который позволит нам работать с неравенствами так же уверенно, как мы работаем с уравнениями. Это набор свойств, которые позволяют преобразовывать неравенства, сохраняя их истинность.

Теорема 1 (перестановка сторон):
Если a > b, то b < a.
Если a < b, то b > a.
Доказательство: Если разность a − b — положительное число, то разность b − a = −(a − b) — отрицательное. И наоборот.
Теорема 2 (транзитивность):
Если a < b и b < c, то a < c.
Доказательство: Прибавим к разности a − c выражение (b − b) = 0 и сгруппируем:
a − c = a − c + b − b = (a − b) + (b − c).
По условию оба слагаемых отрицательны. Сумма отрицательных чисел отрицательна, значит a − c < 0, то есть a < c.

Рис. 1. Геометрическая интерпретация транзитивности: если a левее b, а b левее c, то a автоматически левее c.

Теорема 3 (прибавление числа):
Если a < b и c — любое число, то a + c < b + c.
Доказательство: (a + c) − (b + c) = a + c − b − c = a − b.
По условию a − b — отрицательное число. Значит, и разность (a + c) − (b + c) отрицательна, то есть a + c < b + c.

💡 Следствие: к обеим частям верного неравенства можно прибавить одно и то же число — неравенство останется верным.

Теорема 4 (умножение/деление):
• Если a < b и c > 0, то ac < bc.
• Если a < b и c < 0, то ac > bc (знак неравенства переворачивается).
Доказательство: ac − bc = c(a − b).
Так как a < b, разность (a − b) отрицательна.
• Если c > 0, то c(a − b) < 0 (плюс × минус = минус), значит ac < bc.
• Если c < 0, то c(a − b) > 0 (минус × минус = плюс!), значит ac > bc.
⚠️ ЗАПОМНИ! Это главное отличие неравенств от уравнений:
При умножении/делении обеих частей на отрицательное число знак неравенства МЕНЯЕТСЯ на противоположный!

🛠 Закрепление

Реши задачи, а затем нажми на них, чтобы проверить себя. Помни: всегда указывай, какое свойство применяешь!

🟢 База №862. Известно, что a < b. Сравните: а) a − 3 и b; б) a + 4 и b − 1.

Решение:

а) По условию a < b.
Применим Теорему 4 (умножение на положительное число 1): a · 1 < b · 1, то есть a < b.
Теперь применим Теорему 3 (вычитание 3 — это прибавление −3):
a + (−3) < b + (−3) ⟹ a − 3 < b − 3.
Так как a − 3 < b − 3 и b − 3 < b (по Теореме 3 с прибавлением −3 к b), то по Теореме 2 (транзитивность):
a − 3 < b. ✅

б) По условию a < b.
Прибавим 4 к обеим частям (Теорема 3): a + 4 < b + 4.
Теперь нужно сравнить b + 4 и b − 1. Составим разность:
(b + 4) − (b − 1) = b + 4 − b + 1 = 5 > 0.
Значит, b − 1 < b + 4.
Но нам нужно сравнить a + 4 с b − 1. Из того, что a + 4 < b + 4, а b − 1 < b + 4, прямой вывод о a + 4 и b − 1 сделать нельзя.
Составим разность (a + 4) − (b − 1) = a − b + 5.
Так как a < b, то a − b < 0, но знак суммы (a − b) + 5 зависит от того, насколько a меньше b.
Вывод: однозначного сравнения сделать нельзя (например, при a=1, b=2: a+4=5, b−1=1, значит a+4>b−1; при a=1, b=10: a+4=5, b−1=9, значит a+4<b−1). ⚠️

🔵 Средний №864(а, в). Используя свойства неравенств, запишите верное неравенство, которое получится, если к обеим частям неравенства 18 > −7 прибавить число −5; обе части неравенства −9 < 21 умножить на −1.

Решение:

а) Дано: 18 > −7. Прибавляем −5 к обеим частям.
По Теореме 3:
18 + (−5) > −7 + (−5)
13 > −12 ✅

в) Дано: −9 < 21. Умножаем обе части на −1.
По Теореме 4 (умножение на отрицательное число): знак неравенства меняется на противоположный!
−9 · (−1) > 21 · (−1)
9 > −21 ✅

Проверка на числовой прямой: −9 находится левее 21 (верно, −9 < 21). Но при умножении на −1 точки «зеркально отражаются» относительно нуля, и 9 оказывается правее −21. Именно поэтому знак переворачивается!

🟣 Продвинутый №871. Известно, что 3 < a < 4. Оцените значение выражения: а) 5a; б) −a; в) a + 2; г) 5 − a; д) 0,2a + 3.

Решение: Будем последовательно применять свойства к двойному неравенству 3 < a < 4.

а) 5a:
Умножим все части на 5 (5 > 0, знак сохраняется — Теорема 4):
3 · 5 < 5a < 4 · 5
15 < 5a < 20 ✅

б) −a:
Умножим все части на −1 (знак переворачивается — Теорема 4):
3 · (−1) > −a > 4 · (−1)
−3 > −a > −4 ⟹ −4 < −a < −3 ✅

в) a + 2:
Прибавим 2 ко всем частям (Теорема 3):
3 + 2 < a + 2 < 4 + 2
5 < a + 2 < 6 ✅

г) 5 − a:
Сначала умножим 3 < a < 4 на −1 (знак переворачивается):
−3 > −a > −4 ⟹ −4 < −a < −3.
Теперь прибавим 5 ко всем частям:
−4 + 5 < 5 − a < −3 + 5
1 < 5 − a < 2 ✅

д) 0,2a + 3:
Умножим 3 < a < 4 на 0,2 (0,2 > 0, знак сохраняется):
0,6 < 0,2a < 0,8.
Прибавим 3 ко всем частям:
3,6 < 0,2a + 3 < 3,8.
3,6 < 0,2a + 3 < 3,8 ✅

🏗 Практика: задача из реальной жизни

🚀 Инженерия и точные измерения: На производстве изготовлен правильный треугольник (равносторонний) со стороной a мм. Контроль качества показал, что размер стороны укладывается в диапазон 54,2 < a < 54,3 мм.
Вопрос: В каких границах лежит периметр P этого треугольника?

Показать пошаговое решение

Решение:

1. Периметр равностороннего треугольника вычисляется по формуле: P = 3a.

2. По условию известно: 54,2 < a < 54,3.

3. Применим Теорему 4 (умножение на положительное число 3 — знак сохраняется):
54,2 · 3 < 3a < 54,3 · 3

4. Выполним умножение:
54,2 · 3 = 162,6
54,3 · 3 = 162,9

5. Запишем результат в виде двойного неравенства:
162,6 < P < 162,9

Вывод для инженера: Периметр треугольника гарантированно находится в интервале от 162,6 мм до 162,9 мм. Этот допуск (0,3 мм) достаточен для большинства производственных задач и позволяет оценить, подойдёт ли деталь для конкретного узла.

💡 Обратите внимание: именно так работают допуски в машиностроении! Зная диапазон одной детали, инженеры оценивают границы сложных сборок, используя свойства неравенств.

📝 Итоги урока

Главное запомнить:

  • Теорема 1: a > b ⟺ b < a (перестановка сторон).
  • Теорема 2 (транзитивность): если a < b и b < c, то a < c.
  • Теорема 3: к обеим частям неравенства можно прибавить одно и то же число — знак сохраняется.
  • Теорема 4: при умножении/делении на положительное число знак сохраняется; при умножении/делении на отрицательное — переворачивается! ⚠️
  • Следствие: если a, b > 0 и a < b, то 1/a > 1/b (знак переворачивается).
  • Все свойства доказываются через определение неравенства — через знак разности.

💡 Методическая подсказка для учителя

Главная «ловушка» этого урока — Теорема 4. Ученики очень часто забывают переворачивать знак неравенства при умножении на отрицательное число, потому что в уравнениях такой необходимости нет. Рекомендуется дать запоминающуюся визуальную аналогию: «Знак неравенства — это стрелка, указывающая на большее число. Когда мы умножаем на минус, все числа на числовой прямой зеркально отражаются, и стрелка начинает указывать в противоположную сторону.» Задача №871 отлично закрепляет навык работы с двойными неравенствами — именно этот формат используется в ОГЭ и ЕГЭ при оценке значений выражений.
