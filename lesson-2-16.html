Квадратный корень из степени

Урок 16 • Глава 2, §5

📖 Материал по учебнику «Алгебра 8 класс». Навигация — внизу страницы, полный список уроков — на главной странице курса.

🧠 Блок 1. Изучение

Разминка: Что такое степень?

Степень — это краткая запись умножения числа на само себя. Например, 2³ = 2 × 2 × 2 = 8. А что будет, если извлечь квадратный корень из степени? Например, √(2⁴) = √16 = 4. Интересно, что 4 = 2². То есть √(2⁴) = 2². Здесь показатель степени разделился пополам!

Ключевые термины

Термин Определение простым языком
Степень Выражение aⁿ, где a — основание, n — показатель. Показатель может быть любым целым числом.
Квадратный корень из степени √(aⁿ), где n — чётное число. Результат зависит от знака основания.
Модуль числа Расстояние от числа до нуля на числовой прямой. |a| = a, если a ≥ 0, и |a| = -a, если a < 0.
Чётный показатель Показатель степени, который делится на 2 без остатка (2, 4, 6, 8...).

⚠️ Главные правила

Правило 1: Основная формула
При чётном показателе n: √(aⁿ) = |a|^(n/2)
√(aⁿ) = |a|n/2, где n — чётное число
Правило 2: Почему модуль?
При чётном показателе aⁿ всегда неотрицательно (aⁿ ≥ 0). Поэтому √(aⁿ) тоже неотрицательно. Чтобы результат всегда был положительным, берём модуль основания.
Правило 3: Примеры
• √(3⁴) = √(81) = 9 = 3² = |3|²
• √((-3)⁴) = √(81) = 9 = |-3|² = 3²
• √(2⁶) = √(64) = 8 = 2³ = |2|³
Правило 4: Важное отличие
• √(aⁿ) — подкоренное выражение aⁿ всегда ≥ 0, поэтому a может быть любым числом.
• (√a)ⁿ — подкоренное выражение a должно быть ≥ 0, поэтому a ≥ 0.

Блок 2. Закрепление

От теории к практике! Решаем задачи на квадратный корень из степени.

🟢 Базовый уровень

Задание 1

Вычислите: √(5⁴)

Показать подробное решение
Шаг 1: Показатель n = 4 — чётное. Применяем формулу: √(5⁴) = |5|^(4/2) = |5|² = 5².
Шаг 2: Вычисляем: 5² = 25.
Шаг 3: Проверка: √(5⁴) = √(625) = 25. Верно!
Ответ: √(5⁴) = 25 ✅
Средний уровень

Задание 2

Вычислите: √((-4)⁶)

Показать подробное решение
Шаг 1: Показатель n = 6 — чётное. Применяем формулу: √((-4)⁶) = |-4|^(6/2) = |-4|³ = 4³.
Шаг 2: Вычисляем: 4³ = 64.
Шаг 3: Проверка: √((-4)⁶) = √(4096) = 64. Верно!
Ответ: √((-4)⁶) = 64 ✅
🟣 Продвинутый уровень

Задание 3

Упростите выражение: √(x⁸), где x — любое число.

Показать подробное решение
Шаг 1: Показатель n = 8 — чётное. Применяем формулу: √(x⁸) = |x|^(8/2) = |x|⁴.
Шаг 2: Поскольку |x|⁴ = x⁴ (чётная степень убирает знак), получаем: √(x⁸) = x⁴.
Ответ: √(x⁸) = x⁴ ✅
Средний уровень

Задание 4

Вычислите: √(2¹⁰)

Показать подробное решение
Шаг 1: Показатель n = 10 — чётное. Применяем формулу: √(2¹⁰) = |2|^(10/2) = 2⁵.
Шаг 2: Вычисляем: 2⁵ = 32.
Шаг 3: Проверка: √(2¹⁰) = √(1024) = 32. Верно!
Ответ: √(2¹⁰) = 32 ✅

🏗 Блок 3. Практическое применение

Задача для физика

Энергия тела вычисляется по формуле E = mc², где m — масса, c — скорость света. Если c = 3 × 10⁸ м/с, чему равно c²?

Показать решение физика
Шаг 1: c² = (3 × 10⁸)² = 9 × 10¹⁶ м²/с².
Шаг 2: Теперь найдём √(c²) = √(9 × 10¹⁶) = 3 × 10⁸ = c.
Ответ: √(c²) = c. Это показывает, что квадратный корень из квадрата числа равен самому числу (если оно положительное). ✅

Главное, что нужно запомнить

  • Формула: √(aⁿ) = |a|^(n/2), где n — чётное число.
  • Модуль: берём модуль основания, чтобы результат всегда был неотрицательным.
  • Отличие от (√a)ⁿ: в √(aⁿ) основание может быть отрицательным, в (√a)ⁿ — только неотрицательным.
  • Проверка: всегда проверяй вычислением степени и корня.
  • 💡 Лайфхак: показатель степени при извлечении квадратного корня делится пополам.

💡 Методическая подсказка (для учителя / родителя)

🎯 Типичные ошибки:

  • Пропуск модуля: ученики пишут √(aⁿ) = a^(n/2) без модуля. Объясните, что результат всегда неотрицательный.
  • Путаница с (√a)ⁿ: подменяют одну формулу другой. Подчёркивайте разницу в области определения.
  • Неверная проверка: проверяют только арифметически, не подставляя исходное выражение.

🪜 Подмостки для слабых учеников:

  • Дайте таблицу степеней для чисел 2, 3, 4, 5 (до 6-й степени).
  • Начните с конкретных чисел, потом переходите к переменным.
  • Используйте цветные маркеры: основание — одним цветом, показатель — другим.

🚀 Вызов для сильных учеников:

  • Докажите, что √(a²ⁿ) = |a|ⁿ для любого целого n.
  • Исследуйте, что происходит при нечётном показателе (√(a³)).
  • Сравните √(aⁿ) и (√a)ⁿ для разных значений a и n.
