Алгебраический способ решения систем уравнений

Урок 31 • Глава 3, §10

📖 Материал по учебнику «Алгебра 8 класс» (§ 10, п. 31). Навигация — внизу страницы, полный список уроков — на главной странице курса.

🧠 Изучение нового материала

👋 Привет! Графический способ удобен для оценки количества решений, но он часто даёт лишь приближённые ответы. Для получения точных координат мы используем алгебраический способ. Он включает два основных метода: метод подстановки и метод сложения.

🛠 Метод подстановки (для систем с уравнением 1-й и 2-й степени)

Алгоритм:
1️⃣ Вырази одну переменную через другую из уравнения первой степени.
2️⃣ Подставь полученное выражение в уравнение второй степени.
3️⃣ Реши полученное уравнение с одной переменной.
4️⃣ Найди соответствующие значения второй переменной, подставив найденные корни в выражение из шага 1.

Пример 1 (из учебника): Реши систему $\begin{cases} x^2 - 3xy - 2y = 2 \\ x + 2y = 1 \end{cases}$

1. Из второго уравнения выразим $x$: $x = 1 - 2y$.
2. Подставим это в первое уравнение:
$(1 - 2y)^2 - 3(1 - 2y)y - 2y = 2$
3. Раскроем скобки и упростим:
$1 - 4y + 4y^2 - 3y + 6y^2 - 2y = 2$
$10y^2 - 9y - 1 = 0$
4. Решим квадратное уравнение (D = 81 - 4·10·(-1) = 121):
$y_1 = 1$, $y_2 = -0.1$
5. Найдём $x$ по формуле $x = 1 - 2y$:
Если $y_1 = 1$, то $x_1 = 1 - 2(1) = -1$.
Если $y_2 = -0.1$, то $x_2 = 1 - 2(-0.1) = 1.2$.
Ответ: $(-1; 1)$ и $(1.2; -0.1)$. ✅

🛠 Метод сложения (для систем с двумя уравнениями 2-й степени)

Идея: Умножить уравнения на такие числа, чтобы коэффициенты при одной из переменных (обычно $x^2$ или $y^2$) стали противоположными. Затем почленно сложить уравнения, чтобы исключить эту переменную.

Пример 3 (из учебника): Реши систему $\begin{cases} x^2 - 2y^2 + x = -6 \\ x^2 - 3y^2 = -11 \end{cases}$

1. Умножим первое уравнение на 3, а второе на $-2$, чтобы уравнять коэффициенты при $y^2$ до $-6$ и $+6$:
$\begin{cases} 3x^2 - 6y^2 + 3x = -18 \\ -2x^2 + 6y^2 = 22 \end{cases}$
2. Почленно сложим левые и правые части:
$(3x^2 - 2x^2) + (-6y^2 + 6y^2) + 3x = -18 + 22$
$x^2 + 3x = 4 \Rightarrow x^2 + 3x - 4 = 0$
3. Решим уравнение (по теореме Виета): $x_1 = -4$, $x_2 = 1$.
4. Подставим $x$ во второе исходное уравнение ($3y^2 = x^2 + 11$):
• Если $x = -4$: $3y^2 = 16 + 11 = 27 \Rightarrow y^2 = 9 \Rightarrow y = \pm 3$.
• Если $x = 1$: $3y^2 = 1 + 11 = 12 \Rightarrow y^2 = 4 \Rightarrow y = \pm 2$.
Ответ: $(-4; 3)$, $(-4; -3)$, $(1; 2)$, $(1; -2)$. ✅

🛠 Закрепление

Реши задачи, а затем нажми на них, чтобы проверить себя. Помни: при методе подстановки удобнее выражать ту переменную, коэффициент при которой равен 1 или -1.

🟢 База №702(а). Реши систему методом подстановки: $\begin{cases} y^2 - x = -1 \\ x = y + 3 \end{cases}$

Решение:

1. Переменная $x$ уже выражена: $x = y + 3$.

2. Подставим в первое уравнение:
$y^2 - (y + 3) = -1$
$y^2 - y - 3 + 1 = 0$
$y^2 - y - 2 = 0$

3. По теореме Виета: $y_1 = 2$, $y_2 = -1$.

4. Найдём $x$:
Если $y = 2$, то $x = 2 + 3 = 5$.
Если $y = -1$, то $x = -1 + 3 = 2$.

Проверка: Для $(5; 2)$: $2^2 - 5 = 4 - 5 = -1$. Верно! ✅

Ответ: $(5; 2)$ и $(2; -1)$.

🔵 Средний №704(а). Реши систему: $\begin{cases} x - y = 3 \\ xy = -2 \end{cases}$

Решение:

1. Выразим $x$ из первого уравнения: $x = y + 3$.

2. Подставим во второе уравнение:
$(y + 3)y = -2$
$y^2 + 3y + 2 = 0$

3. По теореме Виета: $y_1 = -1$, $y_2 = -2$.

4. Найдём $x$:
Если $y = -1$, то $x = -1 + 3 = 2$.
Если $y = -2$, то $x = -2 + 3 = 1$.

Проверка: Для $(1; -2)$: $1 \cdot (-2) = -2$. Верно! ✅

Ответ: $(2; -1)$ и $(1; -2)$.

🟣 Продвинутый №707(а). Реши систему методом сложения: $\begin{cases} 2x + y^2 = 9 \\ x - y^2 = 3 \end{cases}$

Решение:

1. Заметим, что коэффициенты при $y^2$ уже противоположные ($+1$ и $-1$). Почленно сложим уравнения:
$(2x + x) + (y^2 - y^2) = 9 + 3$
$3x = 12 \Rightarrow x = 4$.

2. Подставим $x = 4$ во второе уравнение:
$4 - y^2 = 3$
$y^2 = 1 \Rightarrow y = \pm 1$.

3. Получаем две пары решений.
Проверка: Для $(4; -1)$: $2(4) + (-1)^2 = 8 + 1 = 9$. Верно! ✅

Ответ: $(4; 1)$ и $(4; -1)$.

🏗 Практика: задача из реальной жизни (STEAM)

🚀 Авиамоделирование и безопасность: Два дрона движутся в одной вертикальной плоскости. Траектория первого описывается параболой $y = x^2 - 4$, а второго — прямой линией $x + y = 2$ (координаты в метрах).
Вопрос: Существуют ли точки пересечения их траекторий (риск столкновения)? Если да, найди их точные координаты алгебраическим методом.

Показать пошаговое решение и график

Решение:

1. Составим систему уравнений:
$\begin{cases} y = x^2 - 4 \\ x + y = 2 \end{cases}$

2. Выразим $y$ из второго уравнения: $y = 2 - x$.

3. Подставим в первое уравнение:
$2 - x = x^2 - 4$
$x^2 + x - 6 = 0$

4. Решим квадратное уравнение (по теореме Виета):
$x_1 = -3$, $x_2 = 2$.

5. Найдём соответствующие $y$ по формуле $y = 2 - x$:
Если $x = -3$, то $y = 2 - (-3) = 5$.
Если $x = 2$, то $y = 2 - 2 = 0$.

Вывод: Траектории пересекаются в двух точках: $(-3; 5)$ и $(2; 0)$. Операторам дронов необходимо скорректировать курс! ⚠️

📝 Итоги урока

Главное запомнить:

  • Метод подстановки идеален, когда одна из переменных легко выражается из линейного уравнения.
  • Метод сложения эффективен, когда можно подобрать множители для уничтожения одной из переменных (особенно $x^2$ или $y^2$).
  • Система, содержащая уравнение второй степени, может иметь 0, 1, 2, 3 или 4 решения (как в Примере 3).
  • Всегда проверяй найденные пары чисел подстановкой в исходную систему, чтобы избежать ошибок при раскрытии скобок.

💡 Методическая подсказка для учителя

Типичная ошибка учеников при методе подстановки: подставив выражение для $x$ в первое уравнение, они пытаются найти $y$, а затем забывают найти обратное значение $x$, записывая в ответ только одну координату. Акцентируйте внимание на шаге 4 алгоритма. При методе сложения обратите внимание на случай, когда после сложения получается уравнение вида $y^2 = -5$ (решений нет) или $y^2 = 9$ (даёт сразу два значения $y$ для одного $x$, что увеличивает количество пар решений, как в Примере 3).
