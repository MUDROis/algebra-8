Для тех, кто хочет знать больше: Свойства линейной функции

Урок 44 • Глава V, §14

📖 Материал по учебнику «Алгебра 8 класс» (§ 14, п. 44). Навигация — внизу страницы, полный список уроков — на главной странице курса.

🧠 Изучение нового материала

👋 Привет! На прошлом уроке мы научились описывать свойства функции по графику. Сегодня применим этот алгоритм к линейной функции $y = kx + b$ ($k \ne 0$) — одной из самых важных моделей реальных процессов. Все свойства можно вывести строго, решая уравнения и неравенства.

Свойства функции $y = kx + b$ (при $k \ne 0$):
1. Функция определена при любых значениях $x$: $D(f) = \mathbb{R}$.
2. Значением функции может быть любое число: $E(f) = \mathbb{R}$.
3. Функция обращается в нуль при $x = -\dfrac{b}{k}$ (решение уравнения $kx + b = 0$).
4. При $k > 0$ функция принимает отрицательные значения при $x < -\dfrac{b}{k}$ и положительные при $x > -\dfrac{b}{k}$; при $k < 0$ — наоборот.
5. При $k > 0$ функция возрастает, при $k < 0$ — убывает.

Докажем свойство 5 — монотонность. Пусть $x_1$ и $x_2$ — произвольные значения аргумента, причём $x_2 > x_1$. Обозначим соответствующие значения функции: $y_1 = kx_1 + b$ и $y_2 = kx_2 + b$. Рассмотрим разность:

$y_2 - y_1 = (kx_2 + b) - (kx_1 + b) = kx_2 - kx_1 = k(x_2 - x_1)$.

Множитель $x_2 - x_1$ положителен, так как $x_2 > x_1$. Поэтому знак произведения $k(x_2 - x_1)$ определяется знаком коэффициента $k$:

• Если $k > 0$, то $k(x_2 - x_1) > 0$, значит, $y_2 > y_1$ — функция возрастает.
• Если $k < 0$, то $k(x_2 - x_1) < 0$, значит, $y_2 < y_1$ — функция убывает.

Рис. 1. Графики линейной функции: при k>0 функция возрастает, при k<0 — убывает (обе проходят через точку (x₀; 0)).

🛠 Закрепление

Реши задачи, а затем нажми на них, чтобы проверить себя. Помни: знак функции определяют, решая неравенство $kx + b > 0$ (или $< 0$)!

🟢 База №1114(а). Построй график функции y = 1,5x − 3 и перечисли её свойства

Решение:

1. Нуль функции: $1{,}5x - 3 = 0 \Rightarrow x = 2$.

2. При $k = 1{,}5 > 0$ функция возрастает.

3. Знак: $y < 0$ при $x < 2$; $y > 0$ при $x > 2$.

4. $D(f) = \mathbb{R}$, $E(f) = \mathbb{R}$.

5. График — прямая через точки $(2;\ 0)$ и $(0;\ -3)$. ✅

🟢 База №1117. Какие из линейных функций являются возрастающими, а какие — убывающими: y = 8x − 5, y = −3x + 11, y = −49x − 100, y = x + 1, y = 1 − x?

Решение: смотрим на знак коэффициента $k$:

• Возрастающие ($k > 0$): $y = 8x - 5$, $y = x + 1$.

• Убывающие ($k < 0$): $y = -3x + 11$, $y = -49x - 100$, $y = 1 - x$ (здесь $k = -1$). ✅

🔵 Средний №1116. При каких x функция обращается в нуль, положительна, отрицательна: а) f(x) = −0,7x + 350; б) f(x) = 30x + 10?

Решение:

а) Нуль: $-0{,}7x + 350 = 0 \Rightarrow x = 500$. При $k = -0{,}7 < 0$:
$f(x) > 0$ при $x < 500$; $f(x) < 0$ при $x > 500$.

б) Нуль: $30x + 10 = 0 \Rightarrow x = -\dfrac{1}{3}$. При $k = 30 > 0$:
$f(x) < 0$ при $x < -\dfrac{1}{3}$; $f(x) > 0$ при $x > -\dfrac{1}{3}$.

🔵 Средний №1118. Функция f(x) = 13x − 78. При каких x: а) f(x) = 0; б) f(x) > 0; в) f(x) < 0? Является ли функция возрастающей?

Решение:

а) $13x - 78 = 0 \Rightarrow x = 6$.

б) $13x - 78 > 0 \Rightarrow x > 6$.

в) $13x - 78 < 0 \Rightarrow x < 6$.

При $k = 13 > 0$ функция возрастает. ✅

🟣 Продвинутый №1120. Функция f(x) = −1,5x + 6. При каких x выполняется условие 0 < f(x) < 3?

Решение (алгебраически):

1. Решим двойное неравенство: $0 < -1{,}5x + 6 < 3$.

2. Вычтем 6 из всех частей: $-6 < -1{,}5x < -3$.

3. Разделим на $-1{,}5$ (отрицательное число — знаки меняются):
$\dfrac{-6}{-1{,}5} > x > \dfrac{-3}{-1{,}5} \Rightarrow 4 > x > 2$.

Ответ: $2 < x < 4$. ✅

🏗 Практика: задача из реальной жизни (STEAM)

🚀 Экономика и тарифы: Вернёмся к задачке про тарифы (урок 34): стоимость тарифа «Старт» — $y_1 = 300 + 5x$, «Профи» — $y_2 = 450 + 2x$ (где $x$ — сверхлимитные гигабайты).

Вопрос: Используя свойства линейной функции, определи, при каком $x$ тарифы сравняются, и какой тариф выгоднее при $x > 50$; при $x < 50$.

Показать пошаговое решение

Решение:

1. Точка равенства: $300 + 5x = 450 + 2x \Rightarrow 3x = 150 \Rightarrow x = 50$.

2. Рассмотрим разность $y_1 - y_2 = (5x + 300) - (2x + 450) = 3x - 150$.

3. Это линейная функция от $x$ с коэффициентом $k = 3 > 0$ — она возрастает.

4. Значит: при $x < 50$ разность отрицательна ($y_1 < y_2$ — выгоднее «Старт»); при $x > 50$ разность положительна ($y_1 > y_2$ — выгоднее «Профи»).

💡 Вывод: свойства линейной функции позволяют ответить на вопрос «кто выгоднее» для всех значений сразу, без перебора! ✅

📝 Итоги урока

Главное запомнить:

  • Линейная функция $y = kx + b$ ($k \ne 0$): $D(f) = \mathbb{R}$, $E(f) = \mathbb{R}$.
  • Нуль функции: $x = -\dfrac{b}{k}$.
  • При $k > 0$: $y > 0$ при $x > -\dfrac{b}{k}$, $y < 0$ при $x < -\dfrac{b}{k}$; при $k < 0$ — наоборот.
  • При $k > 0$ функция возрастает, при $k < 0$ — убывает (доказательство через разность $y_2 - y_1 = k(x_2 - x_1)$).
  • Прямая пропорциональность $y = kx$ — частный случай ($b = 0$), её свойства те же.
  • Свойства линейной функции позволяют анализировать реальные зависимости «в общем виде».

💡 Методическая подсказка для учителя

Рекомендуется провести доказательство монотонности вместе с классом: оно короткое и демонстрирует стандартный приём (рассмотрение разности значений). Обратите внимание учеников на связь знака $k$ и наклона прямой («вверх»/«вниз»). Типичная ошибка при решении №1120 — забыть сменить знаки неравенства при делении на отрицательное число. Напомните про урок 35 (свойства числовых неравенств) и урок 39 (решение неравенств) — двойное неравенство решается преобразованием всех трёх частей сразу.
