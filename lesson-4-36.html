Для тех, кто хочет знать больше: Сложение и умножение числовых неравенств

Урок 36 • Глава IV, §11

📖 Материал по учебнику «Алгебра 8 класс» (§ 11, п. 36). Навигация — внизу страницы, полный список уроков — на главной странице курса.

🧠 Изучение нового материала

👋 Привет! На прошлом уроке мы изучили свойства отдельных неравенств. Сегодня мы сделаем мощный шаг вперёд — научимся складывать и умножать неравенства друг с другом! Это позволит нам оценивать значения сложных выражений, когда мы знаем только приблизительные границы входящих в них величин.

Теорема 5 (почленное сложение):
Если a < b и c < d, то a + c < b + d.
Доказательство: Прибавим к обеим частям неравенства a < b число c:
a + c < b + c.
Прибавим к обеим частям неравенства c < d число b:
b + c < b + d.
По Теореме 2 (транзитивность) из неравенств a + c < b + c и b + c < b + d следует:
a + c < b + d. ∎

💡 Правило: Верные неравенства одного знака можно почленно складывать — получится верное неравенство.

Теорема 6 (почленное умножение):
Если a < b и c < d, где a, b, c, d — положительные числа, то ac < bd.
Доказательство: Умножим обе части неравенства a < b на положительное число c:
ac < bc.
Умножим обе части неравенства c < d на положительное число b:
bc < bd.
По транзитивности: ac < bd. ∎

💡 Правило: Верные неравенства одного знака можно почленно умножать, если все части положительны.

⚠️ ВАЖНО! Если в неравенствах есть отрицательные числа, Теорема 6 может не работать!
Пример: −1 < 2 и −3 < 1 — верные неравенства.
Но (−1)·(−3) = 3, а 2·1 = 2, и 3 > 2 — неравенство перевернулось!
Следствие:
Если числа a и b положительны и a < b, то an < bn, где n — натуральное число.
Доказательство: Почленно перемножим n верных неравенств a < b, в которых a и b — положительные числа. Получим верное неравенство an < bn.

📖 Практическое применение: оценка значений выражений

Эти теоремы позволяют находить границы (оценки) для суммы, разности, произведения и частного, когда мы знаем только приблизительные значения величин.

Пример из учебника (стр. 196)

Дано: 15 < x < 16 и 2 < y < 3.

Требуется: Оценить сумму x + y, разность x − y, произведение xy и частное x/y.

1. Оценка суммы x + y:

Складываем неравенства почленно (Теорема 5):
15 < x < 16
+
2 < y < 3
─────────
17 < x + y < 19 ✅

2. Оценка разности x − y:

Представим разность как сумму: x − y = x + (−y).
Сначала оценим −y. Из 2 < y < 3 умножим на −1 (знак переворачивается):
−3 < −y < −2.
Теперь сложим:
15 < x < 16
+
−3 < −y < −2
─────────
12 < x − y < 14 ✅

3. Оценка произведения xy:

Так как x и y заключены между положительными числами, они сами положительны. Применяем Теорему 6:
15 < x < 16
×
2 < y < 3
─────────
15·2 < xy < 16·3
30 < xy < 48 ✅

4. Оценка частного x/y:

Представим частное как произведение: x/y = x · (1/y).
Сначала оценим 1/y. Из 2 < y < 3 по следствию (или Теореме 4):
1/3 < 1/y < 1/2.
Теперь перемножим (все числа положительны!):
15 < x < 16
×
1/3 < 1/y < 1/2
─────────
15·(1/3) < x/y < 16·(1/2)
5 < x/y < 8 ✅

🛠 Закрепление

Реши задачи, а затем нажми на них, чтобы проверить себя. Помни: при умножении все числа должны быть положительными!

🟢 База №881. Сложите почленно неравенства: а) 12 > −5 и 9 > 7; б) −2,5 < −0,7 и −6,5 < −1,3.

Решение:

а) Даны неравенства 12 > −5 и 9 > 7.
По Теореме 5 (почленное сложение):
12 + 9 > (−5) + 7
21 > 2 ✅

б) Даны неравенства −2,5 < −0,7 и −6,5 < −1,3.
По Теореме 5:
(−2,5) + (−6,5) < (−0,7) + (−1,3)
−9 < −2
−9 < −2 ✅

🔵 Средний №884. Пусть 3 < a < 4 и 4 < b < 5. Оцените: а) a + b; б) a − b; в) ab; г) a/b.

Решение:

а) a + b:
Складываем почленно:
3 < a < 4
+
4 < b < 5
─────────
7 < a + b < 9 ✅

б) a − b:
Из 4 < b < 5 умножаем на −1 (знак переворачивается): −5 < −b < −4.
Складываем:
3 < a < 4
+
−5 < −b < −4
─────────
−2 < a − b < 0 ✅

в) ab:
Все числа положительны, умножаем почленно:
3 < a < 4
×
4 < b < 5
─────────
12 < ab < 20 ✅

г) a/b:
Из 4 < b < 5: 1/5 < 1/b < 1/4.
Умножаем (все положительны):
3 < a < 4
×
1/5 < 1/b < 1/4
─────────
3·(1/5) < a/b < 4·(1/4)
3/5 < a/b < 1 или 0,6 < a/b < 1 ✅

🟣 Продвинутый №886. Пользуясь тем, что 1,4 < √2 < 1,5 и 1,7 < √3 < 1,8, оцените: а) √2 + √3; б) √3 − √2.

Решение:

а) √2 + √3:
Складываем почленно:
1,4 < √2 < 1,5
+
1,7 < √3 < 1,8
─────────
3,1 < √2 + √3 < 3,3 ✅

б) √3 − √2:
Представим как сумму: √3 + (−√2).
Из 1,4 < √2 < 1,5 умножаем на −1: −1,5 < −√2 < −1,4.
Складываем:
1,7 < √3 < 1,8
+
−1,5 < −√2 < −1,4
─────────
0,2 < √3 − √2 < 0,4 ✅

Проверка на калькуляторе: √3 − √2 ≈ 1,732 − 1,414 ≈ 0,318. Это число действительно лежит в интервале (0,2; 0,4). Всё верно!

🏗 Практика: задача из реальной жизни

🚀 Инженерия и допуски: На производстве изготовлены две детали. Длина первой детали a мм, длина второй — b мм. Контроль качества показал, что размеры укладываются в следующие диапазоны: 26 ≤ a ≤ 28 и 41 ≤ b ≤ 43.

Вопрос: В каких границах лежит периметр равнобедренного треугольника, основанием которого является первая деталь (a), а боковыми сторонами — две вторые детали (b)?

Показать пошаговое решение

Решение:

1. Периметр равнобедренного треугольника с основанием a и боковыми сторонами b вычисляется по формуле:
P = a + 2b

2. По условию известно:
26 ≤ a ≤ 28
41 ≤ b ≤ 43

3. Сначала оценим 2b. Умножим неравенство 41 ≤ b ≤ 43 на положительное число 2:
82 ≤ 2b ≤ 86

4. Теперь оценим сумму a + 2b. Сложим неравенства почленно (Теорема 5):
26 ≤ a ≤ 28
+
82 ≤ 2b ≤ 86
─────────
108 ≤ P ≤ 114

Вывод для инженера: Периметр треугольника гарантированно находится в диапазоне от 108 мм до 114 мм. Этот допуск (6 мм) позволяет оценить, подойдёт ли деталь для конкретного узла, не измеряя каждую деталь отдельно.

💡 Обратите внимание: Именно так работают допуски в машиностроении! Зная границы отдельных деталей, инженеры оценивают границы сложных сборок, используя теоремы о сложении и умножении неравенств. (Это задача №888 из учебника!)

📝 Итоги урока

Главное запомнить:

  • Теорема 5: Верные неравенства одного знака можно почленно складывать — получится верное неравенство.
  • Теорема 6: Верные неравенства одного знака можно почленно умножать, но только если все части положительны!
  • Следствие: Если a и b положительны и a < b, то an < bn для любого натурального n.
  • Для оценки разности представь её как сумму: x − y = x + (−y), оцени −y и сложи.
  • Для оценки частного представь его как произведение: x/y = x · (1/y), оцени 1/y и перемножь.
  • Эти теоремы — основа работы с допусками в инженерии, физике и экономике.

💡 Методическая подсказка для учителя

Главная «ловушка» этого урока — Теорема 6. Ученики часто забывают проверять, что все числа положительны, и пытаются умножать неравенства с отрицательными частями. Обязательно продемонстрируйте контрпример: (−1) < 2 и (−3) < 1 — верные неравенства, но их произведение даёт 3 > 2, то есть знак переворачивается. Рекомендуется требовать от учеников писать фразу «Все числа положительны, применяем Теорему 6» перед каждым умножением. Задачи №884 и №888 отлично показывают практическую ценность этих теорем для оценки реальных величин с допусками.
