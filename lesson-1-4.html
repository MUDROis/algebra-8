🔄 Сложение и вычитание дробей с разными знаменателями

Урок 4 • Глава 1, §4

📖 Материал по учебнику «Алгебра 8 класс». Навигация — внизу страницы, полный список уроков — на главной странице курса.

🧠 Блок 1. Изучение

🪝 Разминка: Яблоки и апельсины

Представь, что у тебя есть 3 яблока и 2 апельсина. Ты не можешь просто сказать «у меня 5 фруктов», потому что это разные вещи! Сначала нужно привести их к одному понятию — «фрукты». В алгебре то же самое: чтобы сложить дроби с разными знаменателями, сначала нужно привести их к общему знаменателю. Это как сказать «и яблоки, и апельсины — это фрукты»! 🍎🍊

📚 Ключевые термины

Термин Определение простым языком
Общий знаменатель Один знаменатель для всех дробей, к которому мы приводим каждую дробь.
Дополнительный множитель То, на что умножаем числитель и знаменатель дроби, чтобы получить общий знаменатель.
НОК (наименьшее общее кратное) Самое маленькое число, которое делится на все знаменатели без остатка.
Приведение к общему знаменателю Процесс: находим общий знаменатель → находим дополнительные множители → умножаем числители и знаменатели.
Разложение на множители Представление многочлена в виде произведения (вынос общего множителя, формулы сокращенного умножения, группировка).
Целое выражение как дробь Любое число или выражение можно записать как дробь со знаменателем 1 (например, a = a/1).

⚠️ Главные правила

Правило 1: Алгоритм сложения/вычитания дробей с разными знаменателями
1. Разложить знаменатели на множители (если нужно).
2. Найти общий знаменатель (НОК коэффициентов × все переменные с наибольшими показателями).
3. Найти дополнительные множители для каждой дроби.
4. Умножить числители на дополнительные множители.
5. Сложить/вычесть полученные числители.
6. Записать результат с общим знаменателем.
7. Сократить дробь (если возможно).
Правило 2: Как найти общий знаменатель?
Общий знаменатель = НОК коэффициентов × все переменные с наибольшими показателями степени.
Пример: для дробей x4ab и 56ab²
НОК(4, 6) = 12
Переменные: a (макс. степень 1), b (макс. степень 2)
Общий знаменатель: 12ab²
Правило 3: Целое выражение минус дробь
Если нужно вычесть дробь из целого выражения (например, a - 3a+1), представь целое выражение как дробь со знаменателем 1: a = a1.
a - 3a + 1 = a1 - 3a + 1 = a(a + 1) - 3a + 1 = a² + a - 3a + 1

🛠 Блок 2. Закрепление

От теории к практике! Решаем задачи из учебника, строго следуя алгоритму.

🟢 Базовый уровень

Задание 1 (по мотивам Примера 1 из учебника)

Сложите дроби:

x4ab + 56ab²
Показать подробное решение
Шаг 1: Знаменатели разные: 4ab и 6ab². Нужно найти общий знаменатель.
Шаг 2: Находим НОК коэффициентов: НОК(4, 6) = 12.
Переменные: a (макс. степень 1), b (макс. степень 2).
Общий знаменатель: 12ab².
Шаг 3: Находим дополнительные множители:
Для первой дроби: 12ab² : 4ab = 3b.
Для второй дроби: 12ab² : 6ab² = 2a.
Шаг 4: Умножаем числители на дополнительные множители:
Первая дробь: x · 3b = 3bx.
Вторая дробь: 5 · 2a = 10a.
Шаг 5: Складываем числители, знаменатель общий:
3bx + 10a12ab²
Шаг 6: Проверяем, можно ли сократить. Числитель 3bx + 10a на множители не раскладывается, общего с знаменателем нет.
Ответ: 3bx + 10a12ab².
Проверка: Пусть a=1, b=1, x=2. Исходная: 2/4 + 5/6 = 1/2 + 5/6 = 3/6 + 5/6 = 8/6 = 4/3. Ответ: (6 + 10)/12 = 16/12 = 4/3. Всё верно! ✅
🔵 Средний уровень

Задание 2 (по образцу Примера 2 из учебника)

Вычтите дроби, предварительно разложив знаменатели на множители:

a + 3a² - ab - b - 3ab + b²
Показать подробное решение
Шаг 1: Раскладываем знаменатели на множители:
a² - ab = a(a - b)
ab + b² = b(a + b)
Шаг 2: Находим общий знаменатель. Коэффициенты: 1. Переменные и скобки: a, b, (a - b), (a + b).
Общий знаменатель: ab(a - b)(a + b).
Шаг 3: Находим дополнительные множители:
Для первой дроби: ab(a - b)(a + b) : a(a - b) = b(a + b).
Для второй дроби: ab(a - b)(a + b) : b(a + b) = a(a - b).
Шаг 4: Умножаем числители на дополнительные множители:
Первая дробь: (a + 3) · b(a + b) = b(a + 3)(a + b).
Вторая дробь: (b - 3) · a(a - b) = a(b - 3)(a - b).
Шаг 5: Вычитаем числители (не забываем про скобки!):
b(a + 3)(a + b) - a(b - 3)(a - b)
Шаг 6: Раскрываем скобки:
Первая часть: b(a² + ab + 3a + 3b) = a²b + ab² + 3ab + 3b².
Вторая часть: a(ab - b² - 3a + 3b) = a²b - ab² - 3a² + 3ab.
Разность: (a²b + ab² + 3ab + 3b²) - (a²b - ab² - 3a² + 3ab) = a²b + ab² + 3ab + 3b² - a²b + ab² + 3a² - 3ab = 2ab² + 3b² + 3a².
Шаг 7: Записываем результат:
3a² + 2ab² + 3b²ab(a - b)(a + b)
Ответ: 3a² + 2ab² + 3b²ab(a - b)(a + b).
Проверка: Пусть a=2, b=1. Исходная: 5/2 - (-2)/3 = 5/2 + 2/3 = 15/6 + 4/6 = 19/6. Ответ: (12 + 4 + 3)/(2·1·1·3) = 19/6. Отлично, ты справился! ✅
🟣 Продвинутый уровень

Задание 3 (№89а из учебника)

Докажите, что при всех допустимых значениях y значение выражения не зависит от y:

5y + 32y + 2 - 7y + 43y + 3
Показать подробное решение
Шаг 1: Раскладываем знаменатели на множители:
2y + 2 = 2(y + 1)
3y + 3 = 3(y + 1)
Шаг 2: Находим общий знаменатель. НОК(2, 3) = 6. Переменные: (y + 1).
Общий знаменатель: 6(y + 1).
Шаг 3: Находим дополнительные множители:
Для первой дроби: 6(y + 1) : 2(y + 1) = 3.
Для второй дроби: 6(y + 1) : 3(y + 1) = 2.
Шаг 4: Умножаем числители на дополнительные множители:
Первая дробь: (5y + 3) · 3 = 15y + 9.
Вторая дробь: (7y + 4) · 2 = 14y + 8.
Шаг 5: Внимание: вычитаем! Вычитаем числители (не забываем про скобки!):
(15y + 9) - (14y + 8) = 15y + 9 - 14y - 8 = y + 1
Шаг 6: Записываем результат:
y + 16(y + 1)
Шаг 7: Сокращаем на (y + 1) (при условии y ≠ -1):
y + 16(y + 1) = 16
Ответ: 16.
Вывод: Переменная y исчезла! Значение выражения равно 1/6 при всех допустимых y (кроме y = -1). Доказано! ✅
Проверка: Пусть y = 0: 3/2 - 4/3 = 9/6 - 8/6 = 1/6. Пусть y = 1: 8/4 - 11/6 = 2 - 11/6 = 12/6 - 11/6 = 1/6. Всё сходится! 🎉

🏗 Блок 3. Практическое применение

👷 Задача для инженера-строителя

Ты проектируешь мост. Два участка дороги имеют разную длину, но ты хочешь выразить их общую длину в виде одной дроби. Первый участок: 3xx - 2 км, второй: 5x + 2 км. Найди общую длину моста в виде одной дроби.

Показать решение инженера
Шаг 1: Знаменатели разные: x - 2 и x + 2. Они не раскладываются дальше.
Шаг 2: Общий знаменатель: (x - 2)(x + 2).
Шаг 3: Дополнительные множители:
Для первой дроби: (x - 2)(x + 2) : (x - 2) = x + 2.
Для второй дроби: (x - 2)(x + 2) : (x + 2) = x - 2.
Шаг 4: Умножаем числители:
Первая дробь: 3x(x + 2) = 3x² + 6x.
Вторая дробь: 5(x - 2) = 5x - 10.
Шаг 5: Складываем числители:
(3x² + 6x) + (5x - 10) = 3x² + 11x - 10.
Шаг 6: Записываем результат:
3x² + 11x - 10(x - 2)(x + 2)
Ответ: Общая длина моста: 3x² + 11x - 10(x - 2)(x + 2) км. Отличная работа, инженер! 🌉

🌟 Главное, что нужно запомнить

  • Алгоритм: 1) Разложить знаменатели. 2) Найти общий знаменатель. 3) Найти дополнительные множители. 4) Умножить числители. 5) Сложить/вычесть. 6) Сократить.
  • Общий знаменатель: НОК коэффициентов × все переменные/скобки с наибольшими степенями.
  • Дополнительный множитель: Общий знаменатель делим на старый знаменатель дроби.
  • ⚠️ Ловушка минуса: При вычитании дробей обязательно бери весь числитель второй дроби в скобки!
  • Целое как дробь: a = a/1. Это помогает привести целое выражение к общему знаменателю с дробью.
  • 💡 Лайфхак: Если после всех действий y (или другая переменная) исчезла из ответа — значит, значение выражения не зависит от этой переменной!

💡 Методическая подсказка (для учителя / родителя)

🎯 Типичные ошибки:

  • Неправильный общий знаменатель: ученики часто забывают взять переменные с наибольшими степенями. Например, для 4ab и 6ab² пишут 12ab вместо 12ab².
  • Потеря минуса при вычитании: забывают менять знаки у всех слагаемых во втором числителе. Требуйте явно писать скобки!
  • Забытое сокращение: после сложения/вычитания не проверяют, можно ли сократить дробь.

🪜 Подмостки для слабых учеников:

  • Дайте алгоритм-памятку с пронумерованными шагами.
  • Разрешите использовать цветные маркеры: общий знаменатель — зелёным, дополнительные множители — синим.

🚀 Вызов для сильных учеников:

  • Задача №89б из учебника (более сложная, с «зеркальными» знаменателями).
  • Попросите их придумать своё выражение, которое не зависит от переменной.
