🧠 Блок 1. Изучение

🪝 Разминка: Средняя скорость

Представь, что ты едешь на велосипеде: первый километр — со скоростью 10 км/ч, второй — 20 км/ч. Какая средняя скорость? Не 15 км/ч! Если бы ты ехал 1 км за 6 минут и 1 км за 3 минуты, то 2 км за 9 минут = 13.3 км/ч. В алгебре мы научимся выводить точную формулу для таких случаев! 🚴

📚 Ключевые термины

Термин Определение простым языком
Рациональное выражение Любое выражение из дробей, многочленов и действий (+, −, ×, ).
Преобразование Упрощение выражения до вида одной рациональной дроби.
Порядок действий Сначала умножение/деление, потом сложение/вычитание. Скобки — в первую очередь!
Основное свойство дроби Можно умножать/делить числитель и знаменатель на одно и то же выражение.
Среднее гармоническое Особый вид среднего, используемый для скоростей на одинаковых участках пути.
Тождество Равенство, верное при всех допустимых значениях переменных.
ОДЗ Область допустимых значений: все знаменатели ≠ 0.

⚠️ Главные правила

Правило 1: Любое рациональное выражение → одна дробь
Сумму, разность, произведение и частное рациональных дробей всегда можно представить в виде одной рациональной дроби.
Правило 2: Умножение числителя и знаменателя на одно выражение
Если в числителе и знаменателе сложной дроби есть дроби, можно умножить числитель и знаменатель всей дроби на общий знаменатель внутренних дробей — это упростит выражение.
x/y − y/xx/y + y/x − 2 · xyxy = x² − y²x² + y² − 2xy = (x−y)(x+y)(x−y)² = x+yx−y
Правило 3: Формула средней скорости на равных участках
Если пройдено n участков одинаковой длины со скоростями v₁, v₂, ..., vₙ, то средняя скорость:
vср = n / (1/v₁ + 1/v₂ + ... + 1/vₙ)

Для двух участков: vср = 2v₁v₂ / (v₁ + v₂)

🛠 Блок 2. Закрепление

От теории к практике! Решаем задачи из учебника, соблюдая порядок действий.

🟢 Базовый уровень

Задание 1 (по мотивам Примера 1 из учебника)

Преобразуйте в рациональную дробь выражение:

(x + 1) − x² − 4x + 2 · 1x
Показать подробное решение
Шаг 1: Соблюдаем порядок действий: сначала умножение дробей (в правой части).
x² − 4x + 2 · 1x
Шаг 2: Раскладываем числитель как разность квадратов: x² − 4 = (x − 2)(x + 2).
(x − 2)(x + 2)x + 2 · 1x
Шаг 3: Сокращаем на (x + 2) (при x ≠ −2):
(x − 2)(x + 2)(x + 2) · x = x − 2x
Шаг 4: Теперь вычитаем из многочлена (x + 1) полученную дробь. Представляем (x + 1) как дробь со знаменателем x:
x + 1 = x(x + 1)/x = (x² + x)/x
Шаг 5: Выполняем вычитание:
x² + xx − x − 2x = x² + x − (x − 2)x = x² + x − x + 2x = x² + 2x
Ответ: x² + 2x (при x ≠ 0, x ≠ −2).
Проверка: Подставим x = 2. Исходная: 3 − (0/4)·(1/2) = 3 − 0 = 3. Ответ: (4+2)/2 = 3. Всё верно! ✅
🔵 Средний уровень

Задание 2 (по мотивам Примера 2 из учебника)

Представьте выражение в виде рациональной дроби:

(ba − b + aa + b) · aba² + b² + 1
Показать подробное решение
Шаг 1: Сначала выполняем действие в скобках — сложение дробей. Общий знаменатель: (a − b)(a + b) = a² − b².
Шаг 2: Приводим к общему знаменателю:
b(a + b) + a(a − b)(a − b)(a + b) = ab + b² + a² − aba² − b² = a² + b²a² − b²
Шаг 3: Умножаем полученную дробь на aba² + b²:
a² + b²a² − b² · aba² + b² = aba² − b²
Шаг 4: Прибавляем 1. Представляем 1 как дробь со знаменателем (a² − b²):
aba² − b² + a² − b²a² − b² = ab + a² − b²a² − b²
Ответ: a² + ab − b²a² − b² (при a ≠ ±b).
Проверка: Подставим a = 2, b = 1. Исходная: (1/1 + 2/3) · 2/5 + 1 = (5/3) · (2/5) + 1 = 2/3 + 1 = 5/3. Ответ: (4+2−1)/(4−1) = 5/3. Всё верно! ✅
🟣 Продвинутый уровень

Задание 3 (по мотивам №163а из учебника)

Докажите, что при всех допустимых значениях переменных значение выражения не зависит от a и b:

a + ba − b − a − ba + b − 4aba² − b²
Показать подробное решение
Шаг 1: Находим общий знаменатель. Заметим, что a² − b² = (a − b)(a + b). Значит, общий знаменатель — (a − b)(a + b).
Шаг 2: Приводим все дроби к общему знаменателю:
(a + b)²(a − b)(a + b) − (a − b)²(a − b)(a + b) − 4ab(a − b)(a + b)
Шаг 3: Раскрываем квадраты в числителях:
(a + b)² = a² + 2ab + b²
(a − b)² = a² − 2ab + b²
Шаг 4: Выполняем вычитание числителей (не забываем про скобки!):
(a² + 2ab + b²) − (a² − 2ab + b²) − 4ab
= a² + 2ab + b² − a² + 2ab − b² − 4ab
= (a² − a²) + (2ab + 2ab − 4ab) + (b² − b²)
= 0 + 0 + 0 = 0
Шаг 5: Записываем результат:
0a² − b² = 0
Ответ: 0 (при a ≠ ±b).
Вывод: Переменные a и b полностью исчезли! Значение выражения равно 0 при любых допустимых a и b. Доказано! ✅
Проверка: Подставим a = 3, b = 1. Исходная: 4/2 − 2/4 − 12/8 = 2 − 0.5 − 1.5 = 0. Всё верно!

🏗 Блок 3. Практическое применение

🚴 Задача про среднюю скорость

Велосипедист проехал 3 участка пути одинаковой длины (по 10 км каждый) со скоростями 15 км/ч, 20 км/ч и 30 км/ч. Найди среднюю скорость на всём пути. Почему она не равна среднему арифметическому (20 км/ч)?

Показать решение инженера
Шаг 1: Находим время на каждом участке:
t₁ = 10/15 = 2/3 ч
t₂ = 10/20 = 1/2 ч
t₃ = 10/30 = 1/3 ч
Шаг 2: Общее время:
t = 2/3 + 1/2 + 1/3 = 4/6 + 3/6 + 2/6 = 9/6 = 3/2 ч
Шаг 3: Общий путь: 3 · 10 = 30 км.
Шаг 4: Средняя скорость:
v = 30 / (3/2) = 30 · 2/3 = 20 км/ч
Шаг 5: Проверяем по формуле среднего гармонического:
v = 3 / (1/15 + 1/20 + 1/30) = 3 / (4/60 + 3/60 + 2/60) = 3 / (9/60) = 3 · 60/9 = 180/9 = 20 км/ч
Ответ: Средняя скорость = 20 км/ч.
Вывод: В данном случае среднее гармоническое совпало со средним арифметическим (это редкость!). Обычно средняя скорость меньше среднего арифметического, потому что на медленном участке тратится больше времени. ‍♂️

Главное, что нужно запомнить

  • Порядок действий: скобки → умножение/деление → сложение/вычитание.
  • Любое рациональное выражение можно представить в виде одной дроби.
  • Основное свойство дроби: умножение числителя и знаменателя на одно выражение упрощает сложные дроби.
  • Среднее гармоническое: используется для средних скоростей на равных участках.
  • ⚠️ ОДЗ: всегда указывай, при каких значениях переменных выражение имеет смысл.
  • 💡 Лайфхак: если после всех преобразований переменные исчезли — выражение не зависит от них (тождество).
  • 💡 Проверка: подставь конкретные числа в исходное и полученное выражения — должны совпасть!

💡 Методическая подсказка (для учителя / родителя)

Типичные ошибки:

  • Нарушение порядка действий: ученики сначала складывают, потом умножают. Требуйте явно расставлять приоритеты.
  • Потеря скобок при вычитании: A − (B − C) = A − B + C, а не A − B − C.
  • Забытое ОДЗ: после сокращения забывают указать ограничения (например, x ≠ −2).
  • Неправильное среднее арифметическое вместо гармонического: средняя скорость ≠ (v₁ + v₂)/2.

🪜 Подмостки для слабых учеников:

  • Разрешите расписывать каждый шаг отдельно, не пытаясь сделать всё в уме.
  • Используйте цветные маркеры: числители — синим, знаменатели — красным, общие множители — зелёным.
  • Дайте шаблон: «Сначала скобки, потом ×/÷, потом +/−, потом сократить».
