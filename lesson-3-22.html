🧠 Блок 1. Изучение

🪝 Разминка: уравнение-сюрприз

Прежде чем решать задачи, разомнёмся. Вот уравнение: x² + 4x − 192 = 0. Реши его по формуле корней из урока 21 — и узнаешь, в какой неожиданной задаче оно спрятано.

Реши уравнение и сверь ответ
Шаг 1: Коэффициенты: a = 1, b = 4, c = −192. Дискриминант: D = 4² − 4·1·(−192) = 16 + 768 = 784. D > 0 — два корня.
Шаг 2: √784 = 28. По формуле x = (−b ± √D)/(2a) = (−4 ± 28)/2: x₁ = (−4 − 28)/2 = −16, x₂ = (−4 + 28)/2 = 12.
Проверка: (−16)² + 4·(−16) − 192 = 256 − 64 − 192 = 0 ✅; 12² + 4·12 − 192 = 144 + 48 − 192 = 0 ✅
Ответ: x₁ = −16; x₂ = 12 ✅

Запомни это уравнение — через минуту ты встретишь его внутри геометрической задачи! Учебник (п. 22) начинается с важного заявления: многие задачи в математике, физике, технике решаются с помощью квадратных уравнений. План всегда один: перевести текст задачи на язык алгебры, решить уравнение и осмыслить результат. Такой перевод называют построением математической модели задачи.

📐 Разбор задач из учебника

Задача 1 (из учебника). Найдём катеты прямоугольного треугольника, если известно, что один из них на 4 см меньше другого, а гипотенуза равна 20 см.

Шаг 1. Вводим переменную. Пусть меньший катет равен x см. Тогда больший катет равен (x + 4) см. Обе неизвестные величины выражены через одну переменную x.
Шаг 2. Составляем уравнение — модель задачи. По теореме Пифагора квадрат гипотенузы равен сумме квадратов катетов, то есть x² + (x + 4)² = 20².
Упростим: x² + x² + 8x + 16 = 400, откуда 2x² + 8x − 384 = 0, а после деления на 2: x² + 4x − 192 = 0. Узнаёшь? Это уравнение из разминки!
Шаг 3. Решаем уравнение. D = 4² − 4·1·(−192) = 16 + 768 = 784, √784 = 28, x = (−4 ± 28)/2: x₁ = −16, x₂ = 12.
Шаг 4. Отбираем корни по смыслу задачи. По смыслу задачи значение x должно быть положительным числом: длина катета не может быть отрицательной. Этому условию удовлетворяет только второй корень, то есть число 12.
Ответ: 12 см, 16 см ✅ (проверка: 12² + 16² = 144 + 256 = 400 = 20² — теорема Пифагора сходится)

Задача 2 (из учебника). Тело брошено вертикально вверх с начальной скоростью 40 м/с. Через сколько секунд оно окажется на высоте 60 м?

Шаг 1. Физика подсказывает модель. Из курса физики известно, что если не учитывать сопротивление воздуха, то высота h (м), на которой брошенное вертикально вверх тело окажется через t (с), может быть найдена по формуле:
h = v0t − gt²2

где v₀ (м/с) — начальная скорость, а g — ускорение свободного падения, приближённо равное 10 м/с².

Шаг 2. Подставляем данные. Подставив значения h = 60 и v₀ = 40 в формулу, получим 60 = 40t − 5t². Отсюда 5t² − 40t + 60 = 0, то есть t² − 8t + 12 = 0.
Шаг 3. Решаем уравнение. D = (−8)² − 4·1·12 = 64 − 48 = 16, √16 = 4, t = (8 ± 4)/2: t₁ = 2, t₂ = 6.
Шаг 4. Осмысливаем оба корня. Условию задачи удовлетворяют оба найденных корня! На рисунке дан график зависимости h от t, где h = 40t − 5t². Из графика видно: тело в течение первых 4 с поднимается вверх до высоты 80 м, а затем начинает падать. На высоте 60 м от земли оно оказывается дважды: через 2 с после бросания (на подъёме) и через 6 с (на спуске).
Проверка: h(2) = 40·2 − 5·2² = 80 − 20 = 60 ✅; h(6) = 40·6 − 5·6² = 240 − 180 = 60 ✅
Ответ: на высоте 60 м тело окажется через 2 с и через 6 с ✅

📚 Ключевые термины

Термин Определение простым языком
Математическая модель Уравнение, которое описывает задачу на языке алгебры: «Пусть x — …, тогда …». Решив модель, возвращаемся к смыслу задачи.
Отбор корней по смыслу задачи Проверка каждого корня уравнения: может ли такая величина существовать? Длина, время и число предметов не бывают отрицательными. Лишние корни отбрасывают.
Теорема Пифагора В прямоугольном треугольнике квадрат гипотенузы равен сумме квадратов катетов: c² = a² + b². Самый частый источник квадратных уравнений в геометрии.
Закон движения Формула h = v₀t − gt²/2 — высота тела, брошенного вертикально вверх со скоростью v₀, через время t (g ≈ 10 м/с²).
Два подходящих корня Если оба корня имеют смысл (тело проходит высоту дважды: на подъёме и на спуске), в ответе пишут оба числа.
Задача «каждый с каждым» Если участников n и каждый встречается с каждым один раз, встреч будет n(n − 1)/2. Работает для партий, матчей и рукопожатий.

⚠️ Главные правила

Правило 1: Алгоритм решения задачи с помощью квадратного уравнения.
1) Прочитай условие, выдели данные и вопрос;
2) введи переменную («Пусть x — …») и вырази через неё остальные величины;
3) составь уравнение по условию (используй формулу: площадь, теорема Пифагора, закон движения);
4) приведи уравнение к виду ax² + bx + c = 0 и реши через дискриминант;
5) отбери корни по смыслу задачи, сделай проверку и запиши ответ на вопрос задачи.
Правило 2: Отбор корней — обязательный шаг.
В геометрических задачах длины положительны (x > 0), время неотрицательно (t ≥ 0), число людей, рядов и команд — натуральное. Корень, который «не существует в жизни», отбрасывают, даже если он красиво получился.
Правило 3: Оба корня могут подойти. Если по смыслу годятся оба корня, в ответе указывают оба значения (в задаче про высоту тело проходит отметку 60 м дважды: при t₁ = 2 и t₂ = 6).
Правило 4: Проверяют по условию, а не только в уравнении. Подставь найденные числа в исходную ситуацию: площадь сходится? сумма верна? треугольник с такими сторонами существует? Уравнение могло быть составлено неверно — проверка по условию это поймает.
Правило 5: Ответ — на вопрос задачи. Уравнение даёт обычно вспомогательную величину x. Если спрашивали длину изгороди — это периметр, сложи все стороны! Если спрашивали оба числа — назови оба. Не останавливайся на найденном x.

🧰 Типовые модели: из текста — в уравнение

Ситуация в задаче Уравнение-модель
Одно число на k больше другого, их произведение равно P x(x + k) = P
Сумма двух чисел равна s, произведение равно P x(s − x) = P
Стороны прямоугольника отличаются на k, площадь равна S x(x + k) = S
Периметр прямоугольника равен P, площадь равна S x(P/2 − x) = S
Каждый с каждым: n участников, всего N встреч n(n − 1)/2 = N
Тело брошено вверх со скоростью v₀, высота h v₀t − 5t² = h
Прямоугольный треугольник: катеты и гипотенуза x² + (выражение второго катета)² = (гипотенуза)²

🎯 Устная проверка: составь уравнение

Пока без решения! Прочитай условие, введи переменную и составь уравнение. Рассуждай так: «Пусть x — меньшее число (ширина, сторона), тогда … — большее». Сверь модель с ответом.

а) (№ 557) Произведение двух натуральных чисел, одно из которых на 6 больше другого, равно 187.

б) (№ 558) Длина прямоугольника на 4 см больше ширины, а площадь равна 60 см².

в) (№ 560) Периметр прямоугольника равен 62 м, а площадь равна 210 м².

г) (№ 562) Произведение двух последовательных натуральных чисел больше их суммы на 109.

Показать уравнения-модели
а) Пусть меньшее число x, тогда большее (x + 6): x(x + 6) = 187.
б) Пусть ширина x см, тогда длина (x + 4) см: x(x + 4) = 60.
в) Пусть меньшая сторона x м. Полупериметр 62 : 2 = 31 м — сумма смежных сторон, значит вторая сторона (31 − x) м: x(31 − x) = 210.
г) Пусть первое число x, тогда второе (x + 1): x(x + 1) = (x + x + 1) + 109, то есть x² + x = 2x + 110.
⚠️ Ловушки текстовых задач. 1) Площадь треугольника — это ПОЛОВИНА произведения катетов: S = ab/2, не забывай делить на 2. 2) В турнирных задачах каждая пара встречается один раз — делим n(n − 1)/2. 3) Уравнение даёт сторону, а спрашивают изгородь или периметр — не забудь удвоить сумму. 4) За x удобнее брать МЕНЬШУЮ величину — тогда остальные выражаются со знаком «+». 5) Ответ — это не x, а то, о чём спрашивали: оба катета, оба числа, периметр. 6) В задачах про высоту иногда подходят ОБА корня — не отбрасывай их по привычке.

🛠 Блок 2. Закрепление

От теории к практике! Решаем задачи из учебника (§ 7, п. 22, №№ 557–570). План один: пусть x → уравнение → дискриминант → отбор корней → ответ на вопрос задачи.

🟢 Базовый уровень

Задание 1 (№ 557)

Произведение двух натуральных чисел, одно из которых на 6 больше другого, равно 187. Найдите эти числа.

Показать подробное решение
Шаг 1: Пусть меньшее число равно x, тогда большее равно (x + 6). Произведение: x(x + 6) = 187.
Шаг 2: Раскроем скобки и приведём к стандартному виду: x² + 6x − 187 = 0.
Шаг 3: D = 6² − 4·1·(−187) = 36 + 748 = 784, √784 = 28. x = (−6 ± 28)/2: x₁ = (−6 − 28)/2 = −17, x₂ = (−6 + 28)/2 = 11.
Шаг 4: По смыслу задачи числа натуральные, поэтому x = 11. Большее число: 11 + 6 = 17.
Проверка: 11 · 17 = 187 ✅; 17 − 11 = 6 ✅
Ответ: 11 и 17 ✅
🟢 Базовый уровень

Задание 2 (№ 558)

Найдите периметр прямоугольника, длина которого на 4 см больше ширины, а площадь равна 60 см².

Показать подробное решение
Шаг 1: Пусть ширина равна x см, тогда длина равна (x + 4) см. Площадь: x(x + 4) = 60.
Шаг 2: x² + 4x − 60 = 0. D = 4² − 4·1·(−60) = 16 + 240 = 256, √256 = 16.
Шаг 3: x = (−4 ± 16)/2: x₁ = −10, x₂ = 6. Длина не бывает отрицательной, значит ширина 6 см, а длина 6 + 4 = 10 см.
Шаг 4: Спрашивали периметр! P = 2·(6 + 10) = 2·16 = 32 см.
Проверка: 6 · 10 = 60 см² ✅; 10 − 6 = 4 см ✅
Ответ: периметр равен 32 см ✅

Задание 3 (№ 559)

Огородный участок, имеющий форму прямоугольника, одна сторона которого на 10 м больше другой, требуется обнести изгородью. Определите длину изгороди, если известно, что площадь участка равна 1200 м².

Показать подробное решение
Шаг 1: Пусть меньшая сторона участка равна x м, тогда большая равна (x + 10) м. Площадь: x(x + 10) = 1200.
Шаг 2: x² + 10x − 1200 = 0. D = 10² − 4·1·(−1200) = 100 + 4800 = 4900, √4900 = 70.
Шаг 3: x = (−10 ± 70)/2: x₁ = −40, x₂ = 30. По смыслу x > 0, значит стороны участка 30 м и 40 м.
Шаг 4: Изгородь идёт по границе участка, то есть её длина равна периметру: 2·(30 + 40) = 2·70 = 140 м.
Проверка: 30 · 40 = 1200 м² ✅; 40 − 30 = 10 м ✅
Ответ: длина изгороди 140 м ✅

Задание 4 (№ 560)

Периметр прямоугольника равен 62 м. Найдите его стороны, если площадь прямоугольника равна 210 м².

Показать подробное решение
Шаг 1: Пусть меньшая сторона равна x м. Полупериметр 62 : 2 = 31 м — это сумма смежных сторон, поэтому вторая сторона равна (31 − x) м.
Шаг 2: Площадь: x(31 − x) = 210, отсюда 31x − x² = 210, то есть x² − 31x + 210 = 0.
Шаг 3: D = (−31)² − 4·1·210 = 961 − 840 = 121, √121 = 11. x = (31 ± 11)/2: x₁ = 10, x₂ = 21.
Шаг 4: Оба корня дают одну и ту же пару сторон: при x = 10 вторая сторона 21 м, при x = 21 — вторая 10 м. Стороны прямоугольника 10 м и 21 м.
Проверка: 2·(10 + 21) = 62 м ✅; 10 · 21 = 210 м² ✅
Ответ: стороны равны 10 м и 21 м ✅

Задание 5 (№ 561)

Найдите катеты прямоугольного треугольника, если известно, что их сумма равна 23 см, а площадь данного треугольника равна 60 см².

Показать подробное решение
Шаг 1: Пусть один катет равен x см, тогда другой равен (23 − x) см. Помни: площадь прямоугольного треугольника — половина произведения катетов!
Шаг 2: x(23 − x)/2 = 60, отсюда 23x − x² = 120, то есть x² − 23x + 120 = 0.
Шаг 3: D = (−23)² − 4·1·120 = 529 − 480 = 49, √49 = 7. x = (23 ± 7)/2: x₁ = 8, x₂ = 15.
Шаг 4: Оба корня подходят: катеты 8 см и 15 см (при x = 15 второй катет 23 − 15 = 8 — та же пара).
Проверка: 8 + 15 = 23 см ✅; 8 · 15 : 2 = 60 см² ✅
Ответ: катеты равны 8 см и 15 см ✅

Задание 6 (№ 565)

В прямоугольном треугольнике один из катетов на 3 см меньше гипотенузы, а другой на 6 см меньше гипотенузы. Найдите гипотенузу.

Показать подробное решение
Шаг 1: Пусть гипотенуза равна x см. Тогда катеты равны (x − 3) см и (x − 6) см. По теореме Пифагора: (x − 3)² + (x − 6)² = x².
Шаг 2: Раскроем скобки: x² − 6x + 9 + x² − 12x + 36 = x². Перенесём всё влево: x² − 18x + 45 = 0.
Шаг 3: D = (−18)² − 4·1·45 = 324 − 180 = 144, √144 = 12. x = (18 ± 12)/2: x₁ = 3, x₂ = 15.
Шаг 4: Отбор по смыслу: при x = 3 катеты были бы 0 и −3 см — так не бывает. Значит, гипотенуза 15 см, а катеты 12 см и 9 см.
Проверка: 12² + 9² = 144 + 81 = 225 = 15² ✅
Ответ: гипотенуза равна 15 см ✅

Задание 7 (№ 566)

В кинотеатре число мест в ряду на 8 больше числа рядов. Сколько рядов в кинотеатре, если всего в нём имеется 884 места?

Показать подробное решение
Шаг 1: Пусть в кинотеатре x рядов, тогда мест в каждом ряду (x + 8). Всего мест: x(x + 8) = 884.
Шаг 2: x² + 8x − 884 = 0. D = 8² − 4·1·(−884) = 64 + 3536 = 3600, √3600 = 60.
Шаг 3: x = (−8 ± 60)/2: x₁ = −34, x₂ = 26. Число рядов — натуральное, значит x = 26.
Шаг 4: Рядов 26, мест в ряду 26 + 8 = 34.
Проверка: 26 · 34 = 884 ✅; 34 − 26 = 8 ✅
Ответ: 26 рядов ✅

Задание 8 (№ 570)

При розыгрыше первенства школы по футболу было сыграно 36 матчей, причём каждая команда сыграла с каждой по одному разу. Сколько команд участвовало в розыгрыше?

Показать подробное решение
Шаг 1: Пусть участвовало n команд. Каждая сыграла с каждой по одному разу, значит матчей n(n − 1)/2 (у каждой пары — один матч).
Шаг 2: n(n − 1)/2 = 36, отсюда n² − n = 72, то есть n² − n − 72 = 0.
Шаг 3: D = (−1)² − 4·1·(−72) = 1 + 288 = 289, √289 = 17. n = (1 ± 17)/2: n₁ = −8, n₂ = 9.
Шаг 4: Число команд — натуральное, значит n = 9.
Проверка: 9 · 8 : 2 = 36 матчей ✅
Ответ: 9 команд ✅

7. (№ 564) От прямоугольного листа картона длиной 26 см отрезали с двух сторон квадраты, сторона каждого из которых равна ширине листа. Площадь оставшейся части равна 80 см². Найдите ширину листа картона. Покажите, что задача имеет два решения.

8. (№ 568) Старинная задача. Квадрат пятой части обезьян, уменьшенной на 3, спрятался в гроте. Одна обезьяна, влезшая на дерево, была видна. Сколько было обезьян?

9. (№ 573) Найдите три последовательных целых числа, сумма квадратов которых равна 869.

✅ Показать ответы для самопроверки
Ответы:
1. Числа 11 и 12 (x² − x − 110 = 0, D = 441; проверка: 132 − 23 = 109 ✅)
2. Сторона квадрата 30 см (x² + 120x − 4500 = 0, D = 32400; проверка: 30 · 150 = 4500 ✅)
3. Десятиугольник, n = 10 (n² − 5n − 50 = 0, D = 225; проверка: 35 − 10 = 25 ✅)
4. 16 или 48 обезьян (x² − 64x + 768 = 0, D = 1024; подходят оба корня! 4 + 12 = 16 ✅; 36 + 12 = 48 ✅)
5. 10 участников (n² − n − 90 = 0, D = 361; проверка: 10 · 9 : 2 = 45 ✅)
6. Сторона квадрата 10 см ((60 − 2x)(40 − 2x) = 800, D = 900; корень x = 40 невозможен: 2x > ширины листа)
7. Ширина 5 см или 8 см (w² − 13w + 40 = 0, D = 9; оба решения верны: 16·5 = 80 ✅ и 10·8 = 80 ✅)
8. 50 обезьян (x² − 55x + 250 = 0, D = 2025; корень x = 5 отбрасываем: пятая часть минус 3 — отрицательна)
9. Числа 16, 17, 18 или −18, −17, −16 (x² + 2x − 288 = 0, D = 1156; оба корня — целые числа, подходят оба!)

🏗 Блок 3. Практическое применение

🚀 Задача для инженера-испытателя

Инженер испытывает катапульту для запуска метеозонда: макет взлетает вертикально вверх со скоростью 30 м/с. Высота полёта меняется по закону h(t) = 30t − 5t², где t — время в секундах, h — высота в метрах (g ≈ 10 м/с²). В какие моменты времени зонд окажется на высоте 40 м?

Показать решение инженера
Шаг 1: Подставим h = 40 в закон полёта: 30t − 5t² = 40. Перенесём всё влево: −5t² + 30t − 40 = 0.
Шаг 2: Умножим обе части на −1 и разделим на 5: t² − 6t + 8 = 0. Коэффициенты: a = 1, b = −6, c = 8.
Шаг 3: D = (−6)² − 4·1·8 = 36 − 32 = 4 > 0 — два корня. √4 = 2, t = (6 ± 2)/2: t₁ = 2, t₂ = 4.
Шаг 4: Оба корня имеют смысл! Зонд проходит отметку 40 м дважды: на подъёме (через 2 с) и на спуске (через 4 с). Максимальная высота — 45 м на третьей секунде, поэтому 40 м реально достижимы.
Проверка: h(2) = 30·2 − 5·2² = 60 − 20 = 40 м ✅; h(4) = 30·4 − 5·4² = 120 − 80 = 40 м ✅
Ответ: через 2 с (вверх) и через 4 с (вниз) ✅

💼 Задача для продюсера онлайн-школы

Продюсер набирает учебные группы на курс математики: в каждой группе учеников на 3 больше, чем самих групп, а всего записалось 130 человек. Сколько групп набралось и сколько в каждой учеников?

Показать решение продюсера
Шаг 1: Пусть групп x, тогда учеников в каждой группе (x + 3). Всего записалось: x(x + 3) = 130.
Шаг 2: x² + 3x − 130 = 0. D = 3² − 4·1·(−130) = 9 + 520 = 529 > 0, √529 = 23.
Шаг 3: x = (−3 ± 23)/2: x₁ = −13, x₂ = 10. Число групп — натуральное, значит x = 10.
Шаг 4: Групп 10, учеников в каждой 10 + 3 = 13.
Проверка: 10 · 13 = 130 человек ✅; 13 − 10 = 3 ✅
Ответ: 10 групп по 13 учеников ✅

🌟 Главное, что нужно запомнить

  • Схема решения: текст задачи → переменная x → уравнение-модель → дискриминант → отбор корней → ответ на вопрос задачи.
  • «Пусть x — …»: за x обычно берут меньшую неизвестную величину; остальные выражают через неё со знаком «+» или «−».
  • Источники уравнений: теорема Пифагора (c² = a² + b²), площадь (S = ab, у треугольника S = ab/2), периметр (P = 2(a + b)), закон движения h = v₀t − 5t², формула турнира n(n − 1)/2.
  • Отбор корней: длина > 0, время ≥ 0, число предметов — натуральное. Корень, не имеющий смысла, отбрасывают.
  • Оба корня подходят: если тело проходит высоту дважды (подъём и спуск) или обе конфигурации возможны — в ответе два числа.
  • Проверка по условию: подставь ответ в исходную ситуацию (площадь, сумма, равенство сторон) — уравнение могло быть составлено неверно.
  • Ответ — не x: если спрашивали изгородь — считай периметр; если спрашивали два числа — назови оба.
  • 💡 Лайфхак: сначала реши уравнение «в числах», а потом интерпретируй. Дискриминант и формула корней из урока 21 работают одинаково и в геометрии, и в физике, и в бизнесе.

💡 Методическая подсказка (для учителя / родителя)

🎯 Типичные ошибки:

  • Нет отбора корней: в ответ пишут оба корня, включая отрицательный (№ 557: −17 и 11). Отрабатывайте вопрос: «Может ли длина быть −16?»
  • Наоборот, зря отброшен второй корень: в задачах, где оба корня имеют смысл (№ 567 и № 573, задачи про высоту), ученики отбрасывают второй корень по привычке. Учите перечитывать условие: «сколько всего», «целые числа».
  • Ответ = x: найдя x = 30 (№ 559), ученик пишет «30 м» вместо длины изгороди 140 м. Требуйте в конце перечитать вопрос задачи.
  • Площадь треугольника: забывают делить на 2 (№ 561): уравнение x(23 − x) = 60 вместо x(23 − x)/2 = 60 — корни не подойдут, и это хороший сигнал к поиску ошибки в модели.
  • Турниры: пишут n² = 36 вместо n(n − 1)/2 = 36. Объясните комбинаторный смысл: n команд × (n − 1) соперников, и каждый матч посчитан дважды.
  • Периметр: путают полупериметр с периметром (№ 560): 62 — это 2(a + b), поэтому сумма смежных сторон 31, а не 62.

🪜 Подмостки для слабых учеников:

  • Карточка-шаблон из шести строк: «Пусть x — …»; «Тогда … — …»; «По условию …» (уравнение); «Решаю: D = …»; «Отбор: x > 0, значит …»; «Ответ: …».
  • Начинайте с задач № 557, № 558, где уравнение имеет вид x(x + k) = P — самая простая модель.
  • Таблицу «Типовые модели» из блока 1 распечатайте как памятку: ученик находит ситуацию-близнец и берёт готовую заготовку уравнения.
  • Чертите рисунок к каждой геометрической задаче (прямоугольник, треугольник, лист с вырезами) — модель становится очевидной.

🚀 Вызов для сильных учеников:

  • № 564: докажите, что задача имеет два решения, и начертите оба случая в масштабе 1:2 (остаток 16 × 5 и 10 × 8).
  • № 572: свяжите коробку с рисунком из учебника (лист 60 × 40, вырезы x); объясните, почему корень x = 40 невозможен физически, хотя и подходит уравнению.
  • № 573: обнаружьте оба множества ответов (16, 17, 18 и −18, −17, −16) и объясните, почему слово «целых» в условии меняет всё.
  • Старинные задачи № 567 и № 568 — из трактата Бхаскары (Индия, XII век): сравните ответы обеих задач и обсудите, почему в № 568 корень x = 5 «не выживает» по смыслу.
