🧠 Изучение нового материала

👋 Привет! До сих пор мы решали уравнения, где все числа были известны. Но в реальной науке и инженерии часто встречаются ситуации, когда некоторые коэффициенты не заданы конкретными числами, а обозначены буквами. Такие буквы называются параметрами.

Определение:
Параметр — это буква, которая обозначает фиксированное, но произвольное число. Переменная (обычно x) — это то, что мы ищем.

💡 Простой пример: Уравнение $ax = 5$.
Здесь $x$ — неизвестное, а $a$ — параметр. Чтобы его решить, мы не можем просто разделить на $a$, не подумав! Ведь параметр $a$ может оказаться равен нулю, а на ноль делить нельзя.

Что значит «решить уравнение с параметром»?
Это значит для любого допустимого значения параметра найти множество корней уравнения или доказать, что при этом значении параметра корней нет.

🛠 Алгоритм исследования

Рис. 1. Универсальный алгоритм решения линейных уравнений с параметром.

📖 Разбор примеров из учебника

Пример 1. Решим уравнение $bx - 3x = b^3 - 3b^2 + 4b - 12$ с параметром $b$.

Решение:
1. Вынесем $x$ за скобки в левой части:
$(b - 3)x = b^3 - 3b^2 + 4b - 12$
2. Разложим правую часть на множители способом группировки:
$b^3 - 3b^2 + 4b - 12 = b^2(b - 3) + 4(b - 3) = (b - 3)(b^2 + 4)$
3. Уравнение принимает вид: $(b - 3)x = (b - 3)(b^2 + 4)$.
4. Исследуем случаи:
• Случай 1: $b - 3 \neq 0$, то есть $b \neq 3$. Делим обе части на $(b - 3)$:
$x = \frac{(b - 3)(b^2 + 4)}{b - 3} \Rightarrow \mathbf{x = b^2 + 4}$.
• Случай 2: $b - 3 = 0$, то есть $b = 3$. Подставляем в уравнение:
$0 \cdot x = 0 \cdot (3^2 + 4) \Rightarrow 0 \cdot x = 0$.
Это верное равенство при любом $x$.

Ответ: если $b \neq 3$, то $x = b^2 + 4$; если $b = 3$, то $x$ — любое число. ✅

Пример 2. Решим уравнение $ax^2 + (a - 1)x - (a - 1)^2 = 0$ с параметром $a$.

Решение:
1. Случай 1: $a = 0$. Уравнение становится линейным:
$0 \cdot x^2 + (0 - 1)x - (0 - 1)^2 = 0 \Rightarrow -x - 1 = 0 \Rightarrow \mathbf{x = -1}$.
2. Случай 2: $a \neq 0$. Уравнение является квадратным. Найдём дискриминант:
$D = (a - 1)^2 - 4 \cdot a \cdot (-(a - 1)^2) = (a - 1)^2 + 4a(a - 1)^2 = (a - 1)^2(1 + 4a)$.
3. Анализируем $D$: поскольку $(a - 1)^2 \ge 0$, знак $D$ зависит от $(1 + 4a)$.
• Если $1 + 4a < 0$ (то есть $a < -0.25$), то $D < 0$, корней нет.
• Если $a = -0.25$, то $D = 0$, один корень: $x = \frac{-(a - 1)}{2a} = \frac{-(-1.25)}{-0.5} = -2.5$.
• Если $a > -0.25$ и $a \neq 0$, то $D > 0$, два корня: $x = \frac{-(a - 1) \pm |a - 1|\sqrt{1 + 4a}}{2a}$.
Ответ: при $a = 0$: $x = -1$; при $a < -0.25$: корней нет; при $a = -0.25$: один корень $x = -2.5$; при $a > -0.25$ и $a \neq 0$: два корня по формуле. ✅

🛠 Закрепление

Реши задачи, а затем нажми на них, чтобы проверить себя. Главное правило: всегда начинай с поиска значений параметра, при которых коэффициент при переменной обращается в ноль!

🟢 База №733. Реши уравнение с параметром $b$: $bx + 2x = 3b + 6$

Решение:

1. Вынесем $x$ за скобки в левой части и разложим правую часть:
$x(b + 2) = 3(b + 2)$

2. Исследуем случаи:
• Случай 1: $b + 2 \neq 0$, то есть $b \neq -2$. Делим обе части на $(b + 2)$:
$x = \frac{3(b + 2)}{b + 2} \Rightarrow \mathbf{x = 3}$.
• Случай 2: $b + 2 = 0$, то есть $b = -2$. Подставляем:
$x \cdot 0 = 3 \cdot 0 \Rightarrow 0 \cdot x = 0$.
Уравнение верно при любом $x$.

Ответ: если $b \neq -2$, то $x = 3$; если $b = -2$, то $x$ — любое число. ✅

🔵 Средний №735. Реши уравнение с параметром $a$: $ax - 2x = a^3 - 2a^2 - 9a + 18$

Решение:

1. Вынесем $x$ за скобки слева: $x(a - 2) = a^3 - 2a^2 - 9a + 18$.

2. Разложим правую часть способом группировки:
$a^3 - 2a^2 - 9a + 18 = a^2(a - 2) - 9(a - 2) = (a - 2)(a^2 - 9) = (a - 2)(a - 3)(a + 3)$.

3. Уравнение принимает вид: $x(a - 2) = (a - 2)(a - 3)(a + 3)$.

4. Исследуем случаи:
• Если $a - 2 \neq 0$ ($a \neq 2$), делим на $(a - 2)$: $x = (a - 3)(a + 3) = \mathbf{a^2 - 9}$.
• Если $a - 2 = 0$ ($a = 2$), получаем $0 \cdot x = 0$, значит, $x$ — любое число.

Ответ: если $a \neq 2$, то $x = a^2 - 9$; если $a = 2$, то $x$ — любое число. ✅

🟣 Продвинутый №738(в). При каком значении параметра $t$ уравнение $tx^2 - 6x + 1 = 0$ имеет единственный корень?

Решение:

1. Случай 1: $t = 0$. Уравнение становится линейным:
$0 \cdot x^2 - 6x + 1 = 0 \Rightarrow -6x = -1 \Rightarrow \mathbf{x = \frac{1}{6}}$.
В этом случае корень единственный. Значит, $t = 0$ нам подходит!

2. Случай 2: $t \neq 0$. Уравнение квадратное. Оно имеет единственный корень, когда дискриминант $D = 0$.
$D = (-6)^2 - 4 \cdot t \cdot 1 = 36 - 4t$.
Приравниваем к нулю: $36 - 4t = 0 \Rightarrow 4t = 36 \Rightarrow \mathbf{t = 9}$.

3. Итоговый анализ: уравнение имеет ровно один корень в двух случаях: когда оно вырождается в линейное ($t = 0$) и когда у квадратного уравнения нулевой дискриминант ($t = 9$).

Ответ: при $t = 0$ и $t = 9$. ✅

🏗 Практика: задача из реальной жизни (STEAM)

🚀 Программирование и алгоритмы: Ты пишешь функцию на Python, которая решает уравнение $kx = 10$ для расчёта траектории дрона. Если ты просто напишешь `x = 10 / k`, программа «упадёт» с ошибкой ZeroDivisionError, когда $k = 0$.
Вопрос: Как должен выглядеть алгоритм (псевдокод), чтобы программа корректно обрабатывала все возможные значения параметра $k$?

Показать алгоритм и объяснение

Решение:

Алгоритм должен явно проверять «опасное» значение параметра перед выполнением деления:

if k == 0:
    print("Решений нет (или x - любое число, в зависимости от правой части)")
else:
    x = 10 / k
    print("Единственный корень: x =", x)

Вывод: Математическое исследование случаев ($k = 0$ и $k \neq 0$) — это не просто абстрактная теория, а основа написания устойчивого, безошибочного кода в IT! ✅

📝 Итоги урока

Главное запомнить:

  • Параметр — это фиксированное, но неизвестное нам число. Мы должны дать ответ для любого его значения.
  • Никогда не дели на выражение с параметром, не проверив сначала случай, когда это выражение равно нулю.
  • Если уравнение содержит $x^2$ с параметром при нём (например, $ax^2$), обязательно рассмотри случай $a = 0$ отдельно, так как уравнение перестаёт быть квадратным.
  • Ответ в задачах с параметром всегда формулируется как набор условий: «Если параметр равен..., то...; если параметр не равен..., то...».

💡 Методическая подсказка для учителя

Самая распространённая ошибка учеников при решении уравнений с параметром — автоматическое деление на выражение с параметром без анализа случая равенства его нулю (например, сразу писать $x = 3$ для уравнения $(b-3)x = 3(b-3)$). Рекомендуется требовать от учеников писать фразу «Рассмотрим два случая: коэффициент равен нулю и не равен нулю» перед каждым таким шагом. Задача №738 отлично демонстрирует, что «единственный корень» у уравнения с $x^2$ может быть не только при $D=0$, но и при вырождении в линейное уравнение.
