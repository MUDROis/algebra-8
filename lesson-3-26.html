Решение дробных рациональных уравнений

Урок 26 • Глава 3, §9

📖 Материал по учебнику «Алгебра 8 класс» (§ 9, п. 26). Навигация — внизу страницы, полный список уроков — на главной странице курса.

🧠 Изучение нового материала

👋 Привет! Мы уже умеем решать целые уравнения (где обе части — целые выражения). Но что делать, если в уравнении появляются дроби с переменной в знаменателе? Такие уравнения называются дробными рациональными.

Главное правило:
На ноль делить НЕЛЬЗЯ!
Поэтому любой знаменатель, содержащий переменную, не должен обращаться в ноль.

🛠 Алгоритм решения дробного рационального уравнения

Шаг 1. Найти ОДЗ (область допустимых значений): определить, при каких значениях переменной знаменатели обращаются в ноль, и исключить эти значения.

Шаг 2. Найти общий знаменатель всех дробей, входящих в уравнение.

Шаг 3. Умножить обе части уравнения на этот общий знаменатель. Мы получим целое уравнение, равносильное исходному (при условии соблюдения ОДЗ).

Шаг 4. Решить полученное целое уравнение и проверить каждый найденный корень: не обращает ли он в ноль общий знаменатель? Если обращает — это посторонний корень, его нужно вычеркнуть.

Рис. 1. Числовая прямая: красные «выколотые» точки — значения, запрещённые ОДЗ. Зелёная точка — допустимый корень.

🛠 Закрепление

Реши задачи, а затем нажми на них, чтобы проверить себя. Помни: сначала всегда пиши ОДЗ!

🟢 База №631(б). Реши уравнение: x² / (x - 4) = (5x - 6) / (x - 4)

Решение:

1. ОДЗ: знаменатель не равен нулю: x - 4 ≠ 0, следовательно, x ≠ 4.

2. Умножим обе части уравнения на общий знаменатель (x - 4):
x² = 5x - 6

3. Перенесём всё в левую часть и решим квадратное уравнение:
x² - 5x + 6 = 0.
По теореме Виета: x₁ = 2, x₂ = 3.

4. Проверка по ОДЗ: ни 2, ни 3 не равны 4. Оба корня подходят.

Проверка подстановкой:
При x = 2: 4 / (-2) = (10 - 6) / (-2) → -2 = -2. Верно! ✅
При x = 3: 9 / (-1) = (15 - 6) / (-1) → -9 = -9. Верно! ✅

Ответ: 2; 3.

🔵 Средний №632(г). Реши уравнение: 10 / (2x - 3) = x - 1

Решение:

1. ОДЗ: 2x - 3 ≠ 0, следовательно, x ≠ 1,5.

2. Умножим обе части на (2x - 3):
10 = (x - 1)(2x - 3)

3. Раскроем скобки и приведём к стандартному виду:
10 = 2x² - 3x - 2x + 3
2x² - 5x - 7 = 0

4. Найдём дискриминант: D = (-5)² - 4 · 2 · (-7) = 25 + 56 = 81.
x = (5 ± √81) / (2 · 2) = (5 ± 9) / 4.
x₁ = 14 / 4 = 3,5; x₂ = -4 / 4 = -1.

5. Проверка по ОДЗ: 3,5 ≠ 1,5 и -1 ≠ 1,5. Оба корня подходят.

Ответ: -1; 3,5.

🟣 Продвинутый Пример 3 из учебника: 2 / (x² - 4) - 1 / (x² - 2x) = (4 - x) / (x² + 2x)

Решение:

1. Разложим все знаменатели на множители:
x² - 4 = (x - 2)(x + 2)
x² - 2x = x(x - 2)
x² + 2x = x(x + 2)

2. ОДЗ: x ≠ 2, x ≠ -2, x ≠ 0.

3. Общий знаменатель: x(x - 2)(x + 2). Умножим на него обе части уравнения:
2 · x - 1 · (x + 2) = (4 - x)(x - 2)

4. Раскроем скобки:
2x - x - 2 = 4x - 8 - x² + 2x
x - 2 = -x² + 6x - 8

5. Перенесём всё влево:
x² - 5x + 6 = 0.
По теореме Виета: x₁ = 2, x₂ = 3.

6. Проверка по ОДЗ:
x = 2 — посторонний корень (обращает знаменатель в ноль, см. ОДЗ). ❌
x = 3 — подходит. ✅

Ответ: 3.

🏗 Практика: задача из реальной жизни

🚀 Навигация и логистика: Моторная лодка прошла 24 км по течению реки и 24 км против течения, затратив на весь путь 3,5 часа. Скорость течения реки равна 2 км/ч. Найди собственную скорость лодки.

Показать пошаговое решение

Решение:

1. Пусть x (км/ч) — собственная скорость лодки. Тогда:
Скорость по течению: (x + 2) км/ч. Время: 24 / (x + 2) ч.
Скорость против течения: (x - 2) км/ч. Время: 24 / (x - 2) ч.

2. Составим уравнение по условию (сумма времён равна 3,5 ч):
24 / (x + 2) + 24 / (x - 2) = 3,5

3. ОДЗ: x ≠ -2 и x ≠ 2. (Физический смысл также требует x > 2).

4. Представим 3,5 как дробь 7/2. Общий знаменатель: 2(x - 2)(x + 2). Умножим на него обе части:
24 · 2(x - 2) + 24 · 2(x + 2) = 7(x - 2)(x + 2)
48x - 96 + 48x + 96 = 7(x² - 4)
96x = 7x² - 28

5. Приведём к стандартному виду:
7x² - 96x - 28 = 0.

6. Найдём дискриминант: D = (-96)² - 4 · 7 · (-28) = 9216 + 784 = 10000.
√D = 100.
x = (96 ± 100) / 14.
x₁ = 196 / 14 = 14;
x₂ = -4 / 14 = -2/7.

7. Проверка: x = -2/7 не подходит по физическому смыслу (скорость не может быть отрицательной) и не входит в ОДЗ задачи. x = 14 подходит.

Ответ: собственная скорость лодки равна 14 км/ч.

📝 Итоги урока

Главное запомнить:

  • Дробное рациональное уравнение содержит переменную в знаменателе.
  • ОДЗ — это закон. Его нужно находить до начала решения, чтобы потом отсеять посторонние корни.
  • При умножении на общий знаменатель мы переходим к целому уравнению, но множество корней может расшириться. Поэтому проверка (или сверка с ОДЗ) обязательна!
  • Никогда не сокращай слагаемые в числителе и знаменателе — сокращать можно только множители.

💡 Методическая подсказка для учителя

Самая распространённая ошибка учеников на этом уроке — забывание проверить корни на принадлежность ОДЗ, что приводит к записи постороннего корня в ответ. Рекомендуется требовать от учеников писать «ОДЗ: ...» отдельной строкой в начале решения каждого дробного уравнения. Также обратите внимание на ошибку при переносе: при умножении на общий знаменатель каждое слагаемое умножается целиком, ученики часто забывают умножить свободный член (как в №632г).
