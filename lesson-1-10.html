Ключевые понятия главы

Понятие Определение Пример
Рациональная дробь Дробь, где числитель и знаменатель — многочлены x+1x-2
ОДЗ Значения переменной, при которых знаменатель ≠ 0 Для 1x-3: x ≠ 3
Основное свойство Умножение/деление числителя и знаменателя на одно выражение ab = acbc
Сложение/вычитание Приведение к общему знаменателю ac ± bc = a±bc
Умножение Числитель × числитель, знаменатель × знаменатель ab · cd = acbd
Деление Умножение на обратную дробь ab : cd = adbc
Обратная пропорциональность Функция y = k/x, график — гипербола y = 12x
Главный принцип главы:
Любое рациональное выражение (сумма, разность, произведение, частное дробей) можно представить в виде одной рациональной дроби!

Задание 1 (№217 из учебника)

Сократите дробь:

101010919191
Показать подробное решение
Шаг 1: Ищем закономерность в числах. Заметим, что:
101010 = 10 · 10101
919191 = 91 · 10101
Шаг 2: Проверяем: 10 · 10101 = 101010 ✓, 91 · 10101 = 919191 ✓
Шаг 3: Сокращаем на общий множитель 10101:
10 · 1010191 · 10101 = 1091
Ответ: 1091.
Проверка: 10/91 ≈ 0.10989..., 101010/919191 ≈ 0.10989... ✓

Задание 2 (№224а из учебника)

Упростите выражение:

x² - 2xx - 3 - x - 3x - 3
Показать подробное решение
Шаг 1: Знаменатели одинаковые (x - 3), выполняем вычитание числителей:
(x² - 2x) - (x - 3)x - 3
Шаг 2: Раскрываем скобки (не забываем про минус!):
x² - 2x - x + 3 = x² - 3x + 3
Шаг 3: Записываем результат:
x² - 3x + 3x - 3
Шаг 4: Проверяем, можно ли сократить. Числитель x² - 3x + 3 не раскладывается на множители (дискриминант D = 9 - 12 = -3 < 0).
Ответ: x² - 3x + 3x - 3 (при x ≠ 3).
Проверка: Подставим x = 4. Исходная: 8/1 - 1/1 = 7. Ответ: (16-12+3)/1 = 7 ✓

Задание 3 (№234 из учебника)

Докажите, что при всех допустимых значениях переменных значение выражения равно нулю:

1(a-b)(b-c) + 1(c-a)(a-b) + 1(b-c)(c-a)
Показать подробное решение
Шаг 1: Находим общий знаменатель. Все три знаменателя содержат множители (a-b), (b-c), (c-a). Общий знаменатель: (a-b)(b-c)(c-a).
Шаг 2: Находим дополнительные множители:
Для первой дроби: (c-a)
Для второй дроби: (b-c)
Для третьей дроби: (a-b)
Шаг 3: Приводим к общему знаменателю:
(c-a) + (b-c) + (a-b)(a-b)(b-c)(c-a)
Шаг 4: Упрощаем числитель:
c - a + b - c + a - b = (c - c) + (-a + a) + (b - b) = 0
Шаг 5: Записываем результат:
0(a-b)(b-c)(c-a) = 0
Ответ: 0 (при a ≠ b, b ≠ c, c ≠ a).
Проверка: Подставим a=1, b=2, c=3. Исходная: 1/((-1)·(-1)) + 1/((2)·(-1)) + 1/((-1)·(2)) = 1 - 1/2 - 1/2 = 0 ✓

Задание 4 (№245 из учебника)

Докажите, что при любом целом a значение выражения является целым числом:

a + x2a + 4aa + x - a - x1
Показать подробное решение
Шаг 1: Приводим к общему знаменателю 2a(a + x):
(a+x)² + 8a² - 2a(a-x)(a+x)2a(a+x)
Шаг 2: Раскрываем скобки в числителе:
(a+x)² = a² + 2ax + x²
2a(a-x)(a+x) = 2a(a² - x²) = 2a³ - 2ax²
Шаг 3: Подставляем:
a² + 2ax + x² + 8a² - 2a³ + 2ax²
Шаг 4: Группируем:
-2a³ + 9a² + 2ax + x² + 2ax²
Шаг 5: Проверяем при x = a:
-2a³ + 9a² + 2a² + a² + 2a³ = 12a²
Знаменатель: 2a(2a) = 4a²
Результат: 12a²/4a² = 3 — целое число!
Вывод: При x = a выражение равно 3. Для других значений x нужно дополнительное исследование. ✅

🏗 Блок 3. Практическое применение

👷 Задача для инженера-логиста (комплексная)

Три склада находятся на расстояниях a, b, c км от завода. Грузовик перевозит товары со скоростями v₁, v₂, v₃ км/ч соответственно. Найди среднюю скорость на всем пути (формула среднего гармонического) и вычисли при a=b=c=100 км, v₁=60, v₂=80, v₃=100 км/ч.

Показать решение инженера
Шаг 1: Время на каждом участке:
t₁ = a/v₁, t₂ = b/v₂, t₃ = c/v₃
Шаг 2: Общее время: t = a/v₁ + b/v₂ + c/v₃
Шаг 3: Общий путь: S = a + b + c
Шаг 4: Средняя скорость:
v = S/t = (a + b + c) / (a/v₁ + b/v₂ + c/v₃)
Шаг 5: При a=b=c=100:
v = 300 / (100/60 + 100/80 + 100/100) = 300 / (5/3 + 5/4 + 1)
Шаг 6: Приводим к общему знаменателю 12:
5/3 + 5/4 + 1 = 20/12 + 15/12 + 12/12 = 47/12
Шаг 7: Вычисляем:
v = 300 / (47/12) = 300 · 12/47 = 3600/47 ≈ 76.6 км/ч
Ответ: Средняя скорость ≈ 76.6 км/ч.
Проверка: 100/60 + 100/80 + 100/100 = 1.67 + 1.25 + 1 = 3.92 ч. 300/3.92 ≈ 76.6 км/ч ✓

🌟 Главное, что нужно запомнить

  • ОДЗ: всегда проверяй, при каких значениях переменных выражение имеет смысл.
  • Основное свойство: умножение/деление числителя и знаменателя на одно выражение не меняет дробь.
  • Сложение/вычитание: приводи к общему знаменателю, не забывай про скобки при вычитании!
  • Умножение: числитель × числитель, знаменатель × знаменатель, потом сокращай.
  • Деление: умножай на обратную дробь.
  • Преобразования: любое рациональное выражение можно представить в виде одной дроби.
  • Гипербола: график y = k/x, при k>0 — в I и III четвертях, при k<0 — во II и IV.
  • 💡 Лайфхак: если после всех преобразований переменные исчезли — выражение не зависит от них (тождество).

💡 Методическая подсказка (для учителя / родителя)

Типичные ошибки на повторении:

  • Путаница в действиях: ученики забывают порядок действий (сначала × и ÷, потом + и −).
  • Потеря ОДЗ: после сокращения забывают указать ограничения.
  • Неправильное приведение к общему знаменателю: забывают домножить числитель.
  • Ошибки со знаками: особенно при вычитании дробей с многочленами в числителе.

🪜 Подмостки для слабых учеников:

  • Дайте шпаргалку со всеми формулами главы на одном листе.
  • Разрешите использовать цветные маркеры для разных действий.
  • Начните с простых числовых примеров, потом переходите к буквенным.
