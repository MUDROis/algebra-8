📈 Функция y = √x и её график

Глава 2, § 14

🧠 Блок 1. Изучение нового

🪝 Разминка: от квадрата к корню

Пусть длина стороны квадрата равна a см, а его площадь — S см². Зависимость площади от стороны: S = a².
А если наоборот? Зная площадь, найти сторону: a = √S.
Это и есть функция y = √x! Сегодня мы изучим её свойства и построим график. 📐

📌 Ключевые понятия

ПонятиеОпределениеПример
Функция y = √x Каждому неотрицательному x ставится в соответствие его арифметический квадратный корень √4 = 2, √9 = 3
Область определения Множество неотрицательных чисел: x ≥ 0 √(−4) не существует
Область значений Множество неотрицательных чисел: y ≥ 0 Корень всегда ≥ 0
График Ветвь параболы в первой координатной четверти, начинается в начале координат Кривая, идущая вверх вправо

📘 Таблица значений функции

y 00,711,41,7 22,22,42,62,83

📘 Свойства функции y = √x

Свойство 1. Проходит через начало координат

Если x = 0, то y = √0 = 0.
Точка (0; 0) лежит на графике.

Свойство 2. График в первой четверти

Если x > 0, то y = √x > 0.
Все точки графика, кроме (0; 0), расположены в первой координатной четверти.

Свойство 3. Функция возрастает

Большему значению аргумента соответствует большее значение функции. График идёт вверх (слева направо).
Пример: √6 > √3, так как 6 > 3.

💡 Симметрия: график y = √x симметричен графику y = x² (при x ≥ 0) относительно прямой y = x.
Это связано с тем, что если точка (a; b) лежит на графике y = x², то точка (b; a) лежит на графике y = √x.

🟢 Базовый Задание 1 (№ 350 из учебника)

Принадлежит ли графику функции y = √x точка:

а) A(64; 8)    б) B(10000; 100)    в) C(−81; 9)    г) D(25; −5)
Показать решение
а) Точка A(64; 8):
Подставляем x = 64 в функцию: y = √64 = 8
Полученное значение совпадает с ординатой точки.
Ответ: точка принадлежит графику ✅
б) Точка B(10000; 100):
y = √10000 = 100
Совпадает с ординатой точки.
Ответ: точка принадлежит графику ✅
в) Точка C(−81; 9):
x = −81 < 0 — функция не определена при отрицательных x.
Ответ: точка не принадлежит графику ❌
г) Точка D(25; −5):
y = √25 = 5, а не −5.
Арифметический корень всегда неотрицателен!
Ответ: точка не принадлежит графику ❌

Итог: принадлежат графику точки A и B; не принадлежат — C и D. Всё верно! ✅

🔵 Средний Задание 2 (№ 351 из учебника)

Пересекает ли график функции y = √x прямая? Если пересекает, то в какой точке?

а) y = 1    б) y = 10    в) y = 100    г) y = −100
Показать решение
а) Прямая y = 1:
Решаем: √x = 1
x = 1² = 1
Ответ: пересекает в точке (1; 1) ✅
б) Прямая y = 10:
√x = 10
x = 10² = 100
Ответ: пересекает в точке (100; 10) ✅
в) Прямая y = 100:
√x = 100
x = 100² = 10000
Ответ: пересекает в точке (10000; 100) ✅
г) Прямая y = −100:
√x = −100 — невозможно, так как √x ≥ 0 при любом допустимом x.
Ответ: не пересекает ❌

Вывод: любая горизонтальная прямая y = c при c ≥ 0 пересекает график ровно в одной точке. При c < 0 — не пересекает. Отлично! ✅

🟣 Продвинутый Задание 3 (№ 353а из учебника)

Имеют ли общие точки графики функций y = √x и y = x? Если да, найдите координаты этих точек.

Показать решение
Шаг 1. Общие точки — это решения системы:
y = √x
y = x
Приравниваем: √x = x
Шаг 2. Возводим обе части в квадрат (при x ≥ 0):
x = x²
x² − x = 0
x(x − 1) = 0
Шаг 3. Корни:
x = 0 или x = 1
Шаг 4. Находим координаты точек:
При x = 0: y = √0 = 0 → точка (0; 0)
При x = 1: y = √1 = 1 → точка (1; 1)
Шаг 5. Проверка:
Точка (0; 0): √0 = 0 ✅
Точка (1; 1): √1 = 1 ✅

Ответ: графики имеют две общие точки: (0; 0) и (1; 1). Блестяще! 🏆

🏗 Блок 3. Практическое применение

👷 Задача для ландшафтного дизайнера

Дизайнер создаёт три квадратные клумбы с площадями 4 м², 9 м² и 16 м². Найдите сторону каждой клумбы и определите, сколько погонных метров бордюра нужно закупить для ограждения всех трёх клумб.

Показать решение дизайнера
Шаг 1. Сторона квадрата равна a = √S.
Это и есть функция y = √x!
Шаг 2. Находим стороны:
Клумба 1: a₁ = √4 = 2 м ✅
Клумба 2: a₂ = √9 = 3 м ✅
Клумба 3: a₃ = √16 = 4 м ✅
Шаг 3. Периметр каждой клумбы (P = 4a):
P₁ = 4 · 2 = 8 м
P₂ = 4 · 3 = 12 м
P₃ = 4 · 4 = 16 м
Шаг 4. Общий бордюр:
P = 8 + 12 + 16 = 36 м
Шаг 5. Проверка:
2² = 4 ✅, 3² = 9 ✅, 4² = 16 ✅
4 · 2 + 4 · 3 + 4 · 4 = 8 + 12 + 16 = 36 ✅

Ответ: стороны клумб — 2 м, 3 м, 4 м; бордюра нужно 36 м. Дизайнер доволен! 🌳

🌟 Главное, что нужно запомнить

  • ✅ Функция y = √x определена при x ≥ 0 и принимает значения y ≥ 0.
  • ✅ График — ветвь параболы в первой координатной четверти, начинается в точке (0; 0).
  • ✅ Функция возрастает: большему x соответствует больший y.
  • ✅ Горизонтальная прямая y = c при c ≥ 0 пересекает график ровно в одной точке (c²; c).
  • ✅ При c < 0 прямая y = c не пересекает график.
  • ✅ График y = √x симметричен графику y = x² (при x ≥ 0) относительно прямой y = x.
  • 💡 Лайфхак: чтобы проверить, принадлежит ли точка (a; b) графику, подставь a в функцию и сравни результат с b.

💡 Методическая подсказка (для учителя / родителя)

Типичные ошибки:

  • Забывают, что √x ≥ 0: пишут √25 = ±5, а не √25 = 5.
  • Пытаются вычислить √(−a) для положительного a.
  • Путают графики y = x² и y = √x.
  • При проверке принадлежности точки подставляют y вместо x.

🪜 Подмостки для слабых учеников:

  • Дайте таблицу квадратов 1² … 20² для быстрого поиска корней.
  • Начните с полных квадратов: √1, √4, √9, √16, √25.
  • Постройте график по точкам на клетчатой бумаге — визуализация помогает понять форму кривой.
  • Используйте цветные маркеры: один для оси x, другой для оси y.
