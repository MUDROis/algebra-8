🧠 Блок 1. Изучение нового

🪝 Разминка: а что, если число не полный квадрат?

Мы умеем находить √64 = 8, √0,49 = 0,7 — это полные квадраты. Но что делать с √2, √7, √18? Калькулятор выдаёт бесконечную дробь. Как найти значение корня вручную, с нужной точностью? Сегодня освоим метод последовательных приближений! 🎯

📌 Ключевая идея

Чтобы найти √a, нужно последовательно сужать интервал, в котором заключено это число:
① Найти два целых числа, между которыми лежит √a
② Уточнить десятые
③ Уточнить сотые
④ И так далее до нужной точности

📘 Пример. Находим √2 с точностью до тысячных

Алгоритм последовательных приближений

  1. Находим целую часть: ищем n такое, что n² ≤ a < (n+1)²
  2. Уточняем десятые: возводим в квадрат n,1; n,2; n,3; …
  3. Уточняем сотые: возводим в квадрат n,a1; n,a2; …
  4. Повторяем до нужной точности
Шаг 1. Целая часть.
1² = 1 < 2, а 2² = 4 > 2
Значит, 1 < √2 < 2
Записываем: √2 = 1, …
Шаг 2. Десятые.
Возводим в квадрат: 1,1² = 1,21; 1,2² = 1,44; 1,3² = 1,69; 1,4² = 1,96; 1,5² = 2,25
Так как 1,4² = 1,96 < 2, а 1,5² = 2,25 > 2,
то 1,4 < √2 < 1,5
Записываем: √2 = 1,4 …
Шаг 3. Сотые.
1,41² = 1,9881 < 2
1,42² = 2,0164 > 2
Значит, 1,41 < √2 < 1,42
Записываем: √2 = 1,41 …
Шаг 4. Тысячные.
1,414² = 1,999396 < 2
1,415² = 2,002225 > 2
Значит, 1,414 < √2 < 1,415
Ответ: √2 ≈ 1,414
⚠️ Важно: в практических расчётах обычно используют калькулятор или таблицы. Но метод последовательных приближений помогает оценить результат и проверить, не ошибся ли калькулятор!

🟢 Базовый Задание 1 (№ 329 из учебника)

Подберите два последовательных целых числа, между которыми заключено число:

а) √27    б) √40    в) √120    г) √9,2    д) √0,4    е) √167
Показать решение
а) √27:
5² = 25 < 27 < 36 = 6²
Значит, 5 < √27 < 6 ✅
б) √40:
6² = 36 < 40 < 49 = 7²
Значит, 6 < √40 < 7 ✅
в) √120:
10² = 100 < 120 < 121 = 11²
Значит, 10 < √120 < 11 ✅
г) √9,2:
3² = 9 < 9,2 < 16 = 4²
Значит, 3 < √9,2 < 4 ✅
д) √0,4:
0² = 0 < 0,4 < 1 = 1²
Значит, 0 < √0,4 < 1 ✅
е) √167:
12² = 144 < 167 < 169 = 13²
Значит, 12 < √167 < 13 ✅

Ответы: 5 и 6; 6 и 7; 10 и 11; 3 и 4; 0 и 1; 12 и 13. Всё верно! ✅

🟣 Продвинутый Задание 3 (№ 339 из учебника)

Свободно падающее тело в безвоздушном пространстве проходит S м за t с, где t = √(2S/g), g = 10 м/с². Вычислите t с точностью до 0,1 с, если:

а) S = 175 м    б) S = 225 м
Показать решение
а) S = 175 м:
t = √(2·175/10) = √(350/10) = √35
Оцениваем: 5² = 25 < 35 < 36 = 6²
Уточняем: 5,9² = 34,81 < 35, 6² = 36 > 35
Значит, √35 ≈ 5,9
Ответ: t ≈ 5,9 с ✅
б) S = 225 м:
t = √(2·225/10) = √(450/10) = √45
Оцениваем: 6² = 36 < 45 < 49 = 7²
Уточняем: 6,7² = 44,89 < 45, 6,8² = 46,24 > 45
Значит, √45 ≈ 6,7
Ответ: t ≈ 6,7 с ✅

Проверка: 5,9² = 34,81 ≈ 35 ✅, 6,7² = 44,89 ≈ 45 ✅
Ты справился! 🎉

🏗 Блок 3. Практическое применение

👷 Задача для садового дизайнера

Дизайнер планирует разбить квадратную клумбу площадью 50 м². Нужно найти длину стороны клумбы и определить, сколько погонных метров бордюра понадобится для ограждения. Точность — до 0,1 м.

Показать решение дизайнера
Шаг 1. Сторона квадрата:
a = √S = √50
Шаг 2. Оцениваем целую часть:
7² = 49 < 50 < 64 = 8²
Значит, 7 < √50 < 8
Шаг 3. Уточняем десятые:
7,0² = 49,00 < 50
7,1² = 50,41 > 50
Значит, 7,0 < √50 < 7,1
Шаг 4. Уточняем сотые:
7,07² = 49,9849 < 50
7,08² = 50,1264 > 50
Значит, √50 ≈ 7,1 м (с точностью до 0,1)
Шаг 5. Периметр (длина бордюра):
P = 4a = 4 · 7,1 = 28,4 м
Шаг 6. Проверка:
7,1² = 50,41 ≈ 50 ✅ (погрешность 0,41 м², что приемлемо при округлении до 0,1)
4 · 7,1 = 28,4 ✅

Ответ: сторона клумбы ≈ 7,1 м, бордюра нужно ≈ 28,4 м. Дизайнер доволен! 🌳

🌍 Где нужны приближённые значения корней?
• Строительство: расчёт диагоналей, сторон по площади
• Физика: время падения t = √(2h/g), период маятника T = 2π√(l/g)
• География: расстояние до горизонта d ≈ √(2Rh)
• IT: алгоритмы машинного обучения, графика, шифрование

🌟 Главное, что нужно запомнить

  • ✅ Метод последовательных приближений: находим целую часть → десятые → сотые → тысячные.
  • ✅ На каждом шаге ищем два числа, между которыми лежит √a: одно даёт квадрат меньше a, другое — больше.
  • ✅ Для сравнения выражений вида √a − b сравниваем a и b²:
    если a > b², то √a > b, и наоборот.
  • ✅ В практических расчётах используем калькулятор, но метод приближений помогает оценить результат.
  • ✅ Чем больше знаков точности, тем уже интервал и точнее результат.
  • 💡 Лайфхак: чтобы быстро оценить √a, найди ближайшие полные квадраты. Например, √50 — между √49 = 7 и √64 = 8, ближе к 7.

💡 Методическая подсказка (для учителя / родителя)

Типичные ошибки:

  • При сравнении √a и b забывают возвести b в квадрат.
  • Неправильно определяют направление неравенства для отрицательных чисел.
  • Округляют промежуточные результаты слишком рано, теряя точность.
  • Путают √(a+b) и √a + √b.

🪜 Подмостки для слабых учеников:

  • Дайте таблицу квадратов 1² … 20² для быстрой ориентировки.
  • Начните с полных квадратов: √16, √25, √36, потом переходите к неполным.
  • Используйте числовую прямую: отмечайте интервалы и сужайте их визуально.
  • Разрешите калькулятор для проверки, но требуйте ручную оценку.

🚀 Вызов для сильных учеников:

  • № 330 из учебника: найдите цифры разрядов для √3, √5, √6.
  • № 338 из учебника: формула стороны правильного восьмиугольника a₈ = R√(2−√2).
  • № 340 из учебника: период колебаний маятника T = 2π√(l/g).
  • № 343 из учебника: упростите √(x²) + x при x ≥ 0 и при x < 0.
