Неполные квадратные уравнения

Урок 20 • Глава 3, §7

📖 Материал по учебнику «Алгебра 8 класс». Навигация — внизу страницы, полный список уроков — на главной странице курса.

🧠 Блок 1. Изучение

🪝 Разминка: от x² = a к новому типу уравнений

Архитектор проектирует квадратный атриум площадью 144 м². Если сторона атриума равна x, площадь задаёт уравнение x² = 144. Такое уравнение ты уже умеешь решать (урок 12): x = ±12, а по смыслу задачи сторона равна 12 м. Но вот усложнение: в центре атриума размещают фонтан, и свободная площадь описывается уравнением 3x² − 48 = 0. Здесь есть и x², и число, но нет слагаемого с x. Это уравнение нового типа — неполное квадратное. Сегодня научимся решать любые такие уравнения — все три вида.

🎯 Устная проверка (№ 510 из учебника)

Является ли квадратным уравнение? Рассуждай так: в квадратном уравнении наибольшая степень переменной равна 2, и коэффициент при x² не равен нулю.

Показать ответы устного задания
а) 3,7x² − 5x + 1 = 0 — да: наибольшая степень переменной равна 2.
б) 48x² − x³ − 9 = 0 — нет: есть x³, наибольшая степень равна 3.
в) 2,1x² + 2x − 2/3 = 0 — да.
г) x + x² − 1 = 0 — да: переставим слагаемые и получим x² + x − 1 = 0.
д) 7x² − 13 = 0 — да, это неполное квадратное уравнение.
е) −x² = 0 — да, это неполное квадратное уравнение.

📚 Ключевые термины

Термин Определение простым языком
Квадратное уравнение Уравнение вида ax² + bx + c = 0, где x — переменная, a, b и c — некоторые числа, причём a ≠ 0. Его ещё называют уравнением второй степени.
Коэффициенты a, b, c a — первый коэффициент (число при x²), b — второй коэффициент (число при x), c — свободный член (число без x).
Приведённое квадратное уравнение Уравнение, у которого первый коэффициент равен 1: x² + bx + c = 0.
Неполное квадратное уравнение Квадратное уравнение, в котором хотя бы один из коэффициентов b или c равен нулю.
Корень уравнения Значение переменной x, при котором уравнение обращается в верное равенство.
Стандартный вид Запись ax² + bx + c = 0, где слагаемые упорядочены: сначала x², потом x, потом число.

⚠️ Главные правила

Правило 1: Определение (учебник, п. 20).
Квадратным уравнением называется уравнение вида ax² + bx + c = 0, где x — переменная, a, b и c — некоторые числа, причём a ≠ 0.
ax² + bx + c = 0,   a ≠ 0
Правило 2: Почему a ≠ 0?
Если a = 0, слагаемое ax² исчезает, и остаётся линейное уравнение bx + c = 0 — оно решается по-другому и квадратным не является. А вот b или c равняться нулю могут — тогда уравнение называют неполным.
Правило 3: Откуда название «квадратное».
В каждом уравнении вида ax² + bx + c = 0 (a ≠ 0) наибольшая степень переменной x — квадрат. Левая часть — многочлен второй степени, поэтому уравнение называют квадратным (или уравнением второй степени).
Правило 4: Приведённое уравнение.
Если коэффициент при x² равен 1, квадратное уравнение называют приведённым. Например, приведёнными являются уравнения x² − 11x + 30 = 0, x² − 6x = 0, x² − 8 = 0.

🧩 Неполные квадратные уравнения: три вида

Если в квадратном уравнении ax² + bx + c = 0 хотя бы один из коэффициентов b или c равен нулю, такое уравнение называют неполным квадратным уравнением. Так, уравнения −2x² + 7 = 0, 3x² − 10x = 0 и −4x² = 0 — неполные: в первом b = 0, во втором c = 0, в третьем b = 0 и c = 0. Неполные квадратные уравнения бывают трёх видов.

📐 Вид 1: ax² + c = 0 (c ≠ 0) — «нет слагаемого с x»

Как решать (по учебнику). Переносим свободный член в правую часть и делим обе части на a (a ≠ 0): получаем уравнение x² = −c/a, равносильное исходному. Так как c ≠ 0, то −c/a ≠ 0, и возможны два случая:
• если −c/a > 0 — уравнение имеет два корня: x₁ = −√(−c/a) и x₂ = √(−c/a);
• если −c/a < 0 — уравнение не имеет корней: квадрат числа не может быть отрицательным.

Пример 1 (из учебника). Решим −3x² + 15 = 0. Перенесём свободный член в правую часть и разделим обе части на −3: −3x² = −15, откуда x² = 5. Значит, x = √5 или x = −√5. Ответ: √5; −√5.

Пример 2 (из учебника). Решим 4x² + 3 = 0. Перенесём 3 в правую часть и разделим обе части на 4: 4x² = −3, откуда x² = −3/4. Так как квадрат числа не может быть отрицательным числом, получившееся уравнение не имеет корней, а значит, не имеет корней и равносильное ему уравнение 4x² + 3 = 0. Ответ: корней нет.

📐 Вид 2: ax² + bx = 0 (b ≠ 0) — «нет свободного члена»

Как решать (по учебнику). Раскладываем левую часть на множители: x(ax + b) = 0. Произведение x(ax + b) равно нулю тогда и только тогда, когда хотя бы один из множителей равен нулю: x = 0 или ax + b = 0. Решая уравнение ax + b = 0 (a ≠ 0), находим ax = −b, x = −b/a. Значит, корни уравнения ax² + bx = 0 — числа 0 и −b/a: такое уравнение всегда имеет два корня.

Пример 3 (из учебника). Решим 4x² + 9x = 0. Разложим левую часть на множители: x(4x + 9) = 0. Отсюда x = 0 или 4x + 9 = 0. Решим уравнение 4x + 9 = 0: 4x = −9, x = −9/4 = −2¼. Ответ: 0; −2¼.

⚠️ Ловушка минуса и потерянного корня. Второй корень равен −b/a = −9/4: не потеряй минус при делении. И никогда не дели обе части на x — так корень x = 0 исчезнет! Только вынесение x за скобку.

📐 Вид 3: ax² = 0 — «нет и слагаемого с x, и числа»

Как решать (по учебнику). Уравнение ax² = 0 равносильно уравнению x² = 0 и поэтому имеет единственный корень 0.

Графическая картина: корни уравнения x² + c = 0 — это точки пересечения параболы y = x² + c с осью x. Парабола либо пересекает ось в двух точках, либо не пересекает её вовсе, либо касается в одной точке.

Правило 5: Проверка. Найденные корни подставляй в ИСХОДНОЕ уравнение — каждый по очереди. При возведении в квадрат знаки «плюс» и «минус» исчезают, поэтому проверка обоих корней вида ±√ часто выполняется одной строкой.

🛠 Блок 2. Закрепление

От теории к практике! Решаем задачи из учебника (§ 7, п. 20). Сначала определи вид уравнения, потом выбирай способ решения.

🟢 Базовый уровень

Задание 1 (№ 513 а)

Решите уравнение: 4x² − 9 = 0

Показать подробное решение
Шаг 1: Выпишем коэффициенты: a = 4, b = 0, c = −9. Здесь b = 0 — это неполное квадратное уравнение вида ax² + c = 0.
Шаг 2: Перенесём −9 в правую часть: 4x² = 9. Разделим обе части на 4: x² = 9/4.
Шаг 3: Число 9/4 > 0, значит, уравнение имеет два корня: x = 3/2 или x = −3/2, то есть x = ±1,5.
Проверка: 4·(1,5)² − 9 = 4·2,25 − 9 = 9 − 9 = 0 ✅ Для x = −1,5 — то же самое: (−1,5)² = 2,25.
Ответ: x₁ = 1,5; x₂ = −1,5 ✅
🟢 Базовый уровень

Задание 2 (№ 515 а)

Решите уравнение: 3x² − 4x = 0

Показать подробное решение
Шаг 1: Коэффициенты: a = 3, b = −4, c = 0. Здесь c = 0 — это неполное квадратное уравнение вида ax² + bx = 0.
Шаг 2: Разложим левую часть на множители: x(3x − 4) = 0.
Шаг 3: Произведение равно нулю, когда хотя бы один множитель равен нулю: x = 0 или 3x − 4 = 0. Из второго уравнения 3x = 4, x = 4/3.
Проверка: 3·0² − 4·0 = 0 ✅ и 3·(4/3)² − 4·(4/3) = 3·16/9 − 16/3 = 16/3 − 16/3 = 0 ✅
Ответ: x₁ = 0; x₂ = 4/3 ✅
🔵 Средний уровень

Задание 3 (№ 515 в)

Решите уравнение: 10x² + 7x = 0

Показать подробное решение
Шаг 1: Коэффициенты: a = 10, b = 7, c = 0 — неполное квадратное уравнение вида ax² + bx = 0.
Шаг 2: Вынесем x за скобки: x(10x + 7) = 0.
Шаг 3: x = 0 или 10x + 7 = 0. Из второго уравнения 10x = −7, x = −7/10 = −0,7.
Проверка: 10·(−0,7)² + 7·(−0,7) = 10·0,49 − 4,9 = 4,9 − 4,9 = 0 ✅
Ответ: x₁ = 0; x₂ = −0,7 ✅
🔵 Средний уровень

Задание 4 (№ 514 а)

Решите уравнение 2x² − 17 = 0 и укажите приближённые значения корней с точностью до 0,1.

Показать подробное решение
Шаг 1: Коэффициенты: a = 2, b = 0, c = −17 — неполное квадратное уравнение вида ax² + c = 0.
Шаг 2: Перенесём −17 вправо и разделим обе части на 2: 2x² = 17, x² = 8,5.
Шаг 3: Число 8,5 > 0, значит, x = √8,5 или x = −√8,5. Число √8,5 — иррациональное: с помощью калькулятора находим √8,5 ≈ 2,9155, поэтому с точностью до 0,1 корни x ≈ ±2,9.
Проверка: подставим точное значение: 2·(√8,5)² − 17 = 2·8,5 − 17 = 17 − 17 = 0 ✅ (приближённое значение 2,9 лишь округление: 2·(2,9)² − 17 = −0,18).
Ответ: x ≈ 2,9; x ≈ −2,9 ✅
🟣 Продвинутый уровень

Задание 5 (№ 517)

Верно ли утверждение:
а) неполное квадратное уравнение x² − 19 = 0 не имеет корней;
б) неполное квадратное уравнение x² + 19 = 0 не имеет корней;
в) неполное квадратное уравнение x² + 19x = 0 не имеет корней?

Показать подробное решение
а) Для уравнения x² − 19 = 0: x² = 19, число 19 > 0, значит, корни есть: x = ±√19. Утверждение неверно. ❌
б) Для уравнения x² + 19 = 0: x² = −19. Квадрат числа не может быть отрицательным, значит, корней нет. Утверждение верно. ✅
в) Для уравнения x² + 19x = 0: разложим на множители, x(x + 19) = 0, отсюда x = 0 или x = −19 — корни есть. Утверждение неверно. ❌
Вывод: верно только утверждение б). Запомни: уравнения вида ax² + bx = 0 (b ≠ 0) всегда имеют два корня, а у вида ax² + c = 0 корней нет только при −c/a < 0.

🏗 Блок 3. Практическое применение

📐 Задача для архитектора (№ 523 из учебника)

Теннисный корт представляет собой прямоугольную площадку, длина которой вдвое больше ширины, а площадь равна 800 м². Найдите длину и ширину корта.

Показать решение архитектора
Шаг 1: Пусть ширина корта равна x м, тогда длина равна 2x м. Площадь прямоугольника: x · 2x = 800.
Шаг 2: Получаем неполное квадратное уравнение: 2x² − 800 = 0 (вид ax² + c = 0, где a = 2, b = 0, c = −800).
Шаг 3: 2x² = 800, x² = 400, отсюда x = 20 или x = −20.
Шаг 4: Корень x = −20 не подходит по смыслу задачи: ширина не может быть отрицательной. Значит, ширина равна 20 м, а длина 2·20 = 40 м.
Проверка: 20 · 40 = 800 м² ✅
Ответ: ширина — 20 м, длина — 40 м ✅

🪨 Задача для инженера-геолога (№ 526 из учебника)

Путь свободно падающего тела вычисляется по формуле s = gt²/2, где t (с) — время, g ≈ 10 м/с², s (м) — пройденный путь. Через сколько секунд от начала падения камень достигнет дна шахты глубиной 80 м?

Показать решение инженера
Шаг 1: Подставим s = 80 и g = 10 в формулу: 10t²/2 = 80, то есть 5t² = 80. Это неполное квадратное уравнение вида ax² + c = 0 (a = 5, c = −80).
Шаг 2: Разделим обе части на 5: t² = 16.
Шаг 3: Число 16 > 0, значит, t = 4 или t = −4. Время не может быть отрицательным, поэтому t = 4 с.
Проверка: s = 10·4²/2 = 10·16/2 = 80 м ✅
Ответ: через 4 секунды ✅

🌟 Главное, что нужно запомнить

  • Квадратное уравнение: ax² + bx + c = 0, где a ≠ 0. Числа a, b, c — коэффициенты: a — первый, b — второй, c — свободный член. При a = 1 уравнение называют приведённым.
  • Неполное квадратное уравнение — уравнение, в котором хотя бы один из коэффициентов b или c равен нулю.
  • Вид 1 (b = 0): ax² + c = 0 → x² = −c/a. Если −c/a > 0 — два корня: ±√(−c/a); если −c/a < 0 — корней нет.
  • Вид 2 (c = 0): ax² + bx = 0 → x(ax + b) = 0 → всегда два корня: x = 0 и x = −b/a.
  • Вид 3 (b = 0 и c = 0): ax² = 0 → единственный корень x = 0.
  • Проверка: подставь каждый корень в исходное уравнение — должно получиться верное равенство.
  • 💡 Лайфхак: сначала приведи уравнение к стандартному виду и выпиши коэффициенты a, b, c — сразу станет ясно, какой из трёх видов перед тобой.

💡 Методическая подсказка (для учителя / родителя)

🎯 Типичные ошибки:

  • Потеря корня x = 0: в уравнениях вида ax² + bx = 0 ученики делят обе части на x вместо разложения на множители. Требуйте вынесения x за скобку.
  • Потеря «минуса»: второй корень уравнения ax² + bx = 0 равен −b/a — следите за знаком при делении.
  • Забытый второй корень: в виде ax² + c = 0 корни имеют оба знака: x = ±√(−c/a).
  • «Корни» из отрицательного числа: при −c/a < 0 ученики пишут ±√(−c/a) вместо «корней нет». Напомните: квадрат числа не бывает отрицательным.
  • Неверное деление: при решении ax² + c = 0 делят на a только слагаемое ax², а не обе части целиком.

🪜 Подмостки для слабых учеников:

  • Алгоритм-памятка из трёх шагов: приведи к стандартному виду → выпиши a, b, c → определи вид и решай по правилу.
  • Отрабатывайте виды по нарастанию: сначала вид 3 (ax² = 0), затем вид 2 (ax² + bx = 0), затем вид 1 (ax² + c = 0).
  • Используйте цветные маркеры, как на схеме урока: a — синим, b — голубым, c — красным.
  • Для № 514 дайте готовое приближение √8,5 ≈ 2,92, чтобы ученик сосредоточился на методе, а не на вычислениях.

🚀 Вызов для сильных учеников:

  • Придумайте несколько неполных квадратных уравнений вида ax² + c = 0, у которых корни равны ±4 (например, x² − 16 = 0, 2x² − 32 = 0, −3x² + 48 = 0). Сколько всего таких уравнений?
  • Известно, что −5 — корень уравнения x² + bx = 0. Найдите b и второй корень (ответ: b = 5, корни 0 и −5).
  • Задача повышенного уровня № 530: найдите значение выражения (9 + 6x + x²)/(x + 3) + √x при x = 0,36 и при x = 49 (ответы: 3,96 и 59). Не забудьте про ОДЗ: x ≥ 0.
